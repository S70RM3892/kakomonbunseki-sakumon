# 京大化学 作問設計図

`analysis/trend.md` の結果を、作問に使える形に落としたもの。作った問題は `sakumon/problems/` に 1 題 1 ファイルで置く。

## 京大の「その場学習」問題の骨格

過去 20 年の L2 問題はほぼ次の 5 段で組まれている。

1. **既習の入口**: 教科書知識の空欄・反応式で始める(易)。受験生を題材に乗せる。
2. **新ルールの提示**: 3〜8 行+図 1 枚で、未習の概念・式・反応を定義する。名称は伏せることが多い(「ラングミュア」「NMR」「部分速度因子」とは書かない)。
3. **単純適用**: 与えたルールをそのまま 1 回使う問(標準)。ここで読解できたかを確認。
4. **既習事項との連立**: 新ルール+平衡/物質収支/異性体の数え上げを組み合わせる(やや難)。
5. **逆向き・拡張**: 結果から元の構造・条件を逆算する、またはルールが破れる条件を考えさせる(難)。差がつく問。

守るべき制約:

- 新ルールは **1 大問につき 1〜2 個**まで。それ以上は京大らしくない。
- 新ルールなしでは 3〜5 が解けないこと(essential)。飾りにしない。
- 知っている受験生が読まずに解けてはいけない。条件を一つひねる(例: 過ヨウ素酸で「連続 3 つの OH」の扱いを指定する)。
- 答は数値・構造式で一意に決まること。論述は多くても 1 問、字数制限つき。
- 数値は有効数字 2〜3 桁、√2 や log の値は冒頭で与える。

## 型A: 理論(モデル・式の提示型)

先例: 2011 II(吸着)、2013 II(ミクロ電離定数)、2014 II(前駆平衡)、2024 II(ガス吸収)、2026 II(吸着+解離)

構造: 仮定を箇条書きで与える → 文字式を空欄で導出させる → 線形化やグラフの傾き・切片に読み替える → 数値データで定数を決める → 条件を変えたときの挙動を選択。

未出題で作りやすい題材:

| 題材 | 与えるもの | 連立させる既習事項 |
|---|---|---|
| 酵素反応(ミカエリス・メンテン) | 定常状態近似 | 反応速度、平衡定数、逆数プロット |
| ネルンスト式 | E と濃度の関係式 | 濃淡電池、溶解度積(2019 I(b) の発展) |
| 逐次反応 A→B→C | 中間体濃度の時間変化 | 一次反応の半減期 |
| 多段抽出 | 分配係数 | 物質収支、等比数列(2006 I の発展) |
| 蒸気圧の温度依存 | ln p と 1/T の直線関係 | 蒸発エンタルピー、沸点 |
| 浸透圧のビリアル補正 | Π/c 対 c のプロット | 高分子の分子量決定 |
| 会合コロイド(ミセル) | 臨界ミセル濃度 | 束一性、平衡 |

## 型B: 有機(反応規則の提示型)

先例: 2016 III(水素化分解)、2019 III(イミド)、2022 IV・2025 IV(過ヨウ素酸)、2024 III(付加の立体化学)、2026 III(アセタール交換)

構造: 反応例を 2〜3 本、構造式で示す → 単純な基質の生成物を書かせる → 生成物の組(種類数・物質量比)から未知化合物を逆算 → 立体異性体の数え上げ。

未出題で作りやすい題材:

| 題材 | 与える規則 | 逆算に使う既習事項 |
|---|---|---|
| アルドール反応 | α 炭素がカルボニルに付加 | ヨードホルム、銀鏡、脱水 |
| ディールス・アルダー反応 | ジエン+アルケン → 六員環(シン付加) | オゾン分解・KMnO4 開裂、シス/トランス |
| バイヤー・ビリガー酸化 | ケトン → エステル(酸素の挿入位置の規則) | エステル加水分解、構造決定 |
| グリニャール反応 | R–MgX のカルボニルへの付加 | アルコールの級数、酸化 |
| ピナコール転位 | 1,2-ジオール → ケトン | 過ヨウ素酸との対比 |
| エポキシドの開環 | アンチ付加でジオール | 2024 III の立体化学と接続、メソ体 |
| ベックマン転位 | オキシム → アミド | ナイロン 6、アミド加水分解 |

## 型C: 天然高分子(表記法+分解反応の提示型)

先例: 2019 IV・2020 IV・2022 IV(フィッシャー投影式)、2025 IV(過ヨウ素酸+シクロデキストリン)、2026 IV(糖鎖表記+メチル化)

構造: 表記法を定義 → 既知の糖で確認 → 分解反応を与える → 断片の種類と量から結合位置・配列・重合度を決める。

未出題で作りやすい題材:

| 題材 | 与えるもの |
|---|---|
| メチル化分析の本格版 | 全 OH メチル化 → 加水分解 → 遊離 OH の位置から結合位置と分岐を決定(アミロペクチンの分岐度) |
| エドマン分解+特異的酵素 | N 末端から 1 残基ずつ切る反応、トリプシン・キモトリプシンの切断規則 |
| 臭化シアン切断 | メチオニンの C 末端側で切断 |
| 糖のオサゾン生成 | C1・C2 の情報が消える → エピマーの同定 |
| 核酸の塩基特異的切断 | 断片長から配列決定 |

## 優先順位

1. まず「繰り返し出る準・範囲内」(`analysis/trend.md` の表)を確実に解ける問題群を作る。再出題の実績があるので得点への寄与が最大。
2. 次に型A・型B を未出題題材で作り、**初見ルールを 5 分で把握して使う**訓練にする。
3. 1 題あたりの目安は 20〜25 分(理科 2 科目 180 分、化学 4 題)。

## 1 題のファイル形式

ファイル名は `problems/sNN-qK_題材.md`(NN = セット番号、K = 大問番号 1〜4)。1 セット = 大問 4 題(I 無機・理論、II 理論、III 有機、IV 高分子)。
`node build-pdf.mjs` で `pdf/セット別/`(セット順)と `pdf/大問別/`(大問ごと)に、問題と解答を別々の PDF として出力する(物理と同じ方式)。
図は `problems/figures/make_figures.py` で SVG を生成する(`python3 make_figures.py`)。
問題 PDF は京大の問題冊子の体裁(表題「化学」、見出し「化学問題 Ⅰ」、枠つき空欄、問 1、図番号、ページ番号)に寄せて組む。md 側の書き方は `build-pdf.mjs` の冒頭を参照。問題文は本番と同じく読点に全角コンマ(,)を使う。構造式の結合は数式中で `\text{–}` と書く。

```
---
set: 1
daimon: 1
field: 無機理論
title: 題材名
---
# タイトル(型 / 題材 / 想定時間 / 難易度)
## 問題
## 解答
## 解説(与えられた規則をどこでどう使うか)
## 出典・検証(与えた事実の典拠URL、数値の検算)
```

問題文中で与える範囲外の事実(反応、式、定数)は、必ず信頼できる典拠で確認してから使う。確認できなかったものは「出典・検証」に未検証と明記する。
