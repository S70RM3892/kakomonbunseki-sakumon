# 京大化学 2006〜2026 横断分析(2009年度を除く20年分)

検証したい仮説:「最近、高校範囲を超えた知識をその場で教え、それを使わせる問題が出ている」

判定基準は `CODEBOOK.md`(L2 = 範囲外の概念・式・反応を問題文が定義し、それを使わせる)。
年度別の根拠は `years/YYYY.md`、集計元は `data/YYYY.json`。

## 結論

1. **仮説は半分正しい。** 「その場で教えて使わせる」問題(L2)は増えているが、**昔からあった**。増えたのは主に **有機・高分子(大問 III・IV)** 側。
2. 理論(大問 I・II)の L2 は 2011年(ラングミュア吸着)、2013年(ミクロ電離定数)の時点で既に本格的で、頻度は緩やかにしか増えていない。
3. 毎年出るわけではない。2021・2023年は L2 ゼロ、2024・2026年は 4 題中 3 題が L2 を含む。**隔年で濃淡がある**ので「出る前提」で準備し、出なければ儲けもの、が正しい構え。
4. 京大自身が公式の出題意図で「導入文で与えられた反応に関する情報をもとに…」と明言している(2025 IV、2026 III・IV。`official-intent.md`)。偶然ではなく意図された出題形式。

つまり 2 系統ある。

- **理論型**: 未習の「モデル・式」を与える → 立式 → 既習の平衡・物質収支と連立。問われるのは文字式の運用力。
- **有機型**: 未習の「反応規則・表記法」を与える → 生成物予測/逆算で構造決定。問われるのは規則の正確な適用と場合分け。

## 形式面の変化

- リード文は 2020 年以降 2 割ほど長い(年 118 行 → 140 行)。小問数は 43 → 50 に微増。
- 論述は減少(06–12: 13 問、13–19: 18 問、20–26: 4 問)。代わりに計算(答のみ)と構造式が増加。**読んで、正確に処理して、答だけ書く**試験になっている。
- 大問 IV は 2013 年以降ほぼ一貫して「天然高分子(糖・アミノ酸・ペプチド・脂質)を題材にした構造決定」。

## この分析の限界

- 判定は年度ペアごとに別々の読解担当(AI エージェント)が行った。L1/L2 の境界(分配平衡、ヘミケタール、Ga の結晶モデルなど)は担当によって振れている。件数の細かい差に意味はなく、**傾向の向き**だけを読むこと。
- 各年度の解答数値は自力で解いたもので、公式解答・赤本との照合はしていない。作問に使う前に照合が要る。
- 2009 年度は未入手。
- 「高校範囲」は現行課程の教科書本文を基準にしたが、教科書会社による差がある。
