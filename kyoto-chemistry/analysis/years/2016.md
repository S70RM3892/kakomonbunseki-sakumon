## 大問I(無機・理論/金属とチタン)

### (a) 金属の性質とチタン

- 流れ: Au・Ag・Cu・Fe の性質を空欄で確認し、チタンの結晶格子(室温で Zn・Mg と同じ型、880 ℃ で転移)、密度、高温水蒸気との反応へ進む。
  - 問1: 空欄ア〜キ(元素記号、語句)
  - 問2: チタンの密度(ク)
  - 問3: Cu と希硝酸、Ti と高温水蒸気の反応式
  - 問4: 硝酸銀水溶液の電気分解の両極の反応式、発生気体の体積
- その場で与えられた知識: なし(L0)。チタンに関する事実(モル体積 10.6 cm³、4 価の酸化物になる)は問題文にあり、既習事項の適用で解ける。
- 解法の核心・差がつく点: ア = Au、イ = Ag、ウ = Cu、エ = イオン化傾向、オ = Fe、カ = 六方最密構造、キ = 体心立方格子。ク = 4.5。Ti + 2H2O → TiO2 + 2H2。O2 は 0.015 mol で 0.34 L。
- 作問メモ: 「教科書で扱いの小さい元素(チタン)を主役に据え、既習元素との共通点(同じ結晶格子)を手がかりに空欄を埋めさせる」型。(b) への導入を兼ねる。

### (b) 水素吸蔵を利用した HI 分解の平衡定数

- 流れ: チタンが水素を吸収すること、1000 ℃ での水素分圧(常用対数)と H/Ti 原子数比の平衡関係(図1)を示す。容器 A(2.0 L、チタン)と容器 B(1.0 L、HI 1.0×10⁻² mol)を水素透過膜でつなぎ、平衡後の H/Ti が 0.10 だった。
  - 問5: HI の分解反応の平衡定数(導出過程つき、有効数字 2 桁)
- その場で与えられた知識:
  - **L2 水素吸蔵平衡の図と水素透過膜(データ読解)**: 「チタンは固体にもかかわらず水素を吸収する」と述べ、log₁₀P と H/Ti 比の曲線を与える。膜は「水素のみが透過できる」と説明。吸収された水素量は無視できると但し書き。問5 では、H/Ti = 0.10 を図で読んで水素分圧 1.0×10⁴ Pa を得ることが出発点で、これなしには何も計算できない。
  - 軽量の L2。新しいルールは「固体中の水素量と気相の水素分圧が 1 対 1 に対応する」「膜を通して水素分圧だけが等しくなる」の 2 点で、残りは既習の平衡計算。L1 と見る立場もありうる。
- 解法の核心・差がつく点: H2 は 3.0 L 全体に広がり、I2 と HI は B の 1.0 L にとどまる。H2 総量 = 1.0×10⁴×3.0/(8.31×10³×1273) = 2.84×10⁻³ mol = I2 の量。HI 残量 4.33×10⁻³ mol。B 内の H2 は総量の 1/3。2HI ⇄ H2 + I2 として K ≒ 0.14。
- 作問メモ: 「未習の平衡現象を図で与え、それを測定器(圧力計)として使って既習の平衡定数を求めさせる」型。設問 1 つ・誘導なし・導出記述という形式で、状況整理の力を直接見る。選択透過膜で成分ごとに占める体積を変える仕掛けは再利用しやすい。

## 大問II(理論/電離平衡と電気泳動)

### (a) サリチル酸の電離

- 流れ: サリチル酸の H2A、HA⁻、A²⁻ の構造、Ka1 = 10⁻²·⁸、Ka2 = 10⁻¹³·⁴、存在比率-pH 図(図2)を示す。
  - 問1: pH 3.8 での電離度
  - 問2: m-ヒドロキシ安息香酸(Ka1 = 10⁻⁴·¹、Ka2 = 10⁻⁹·⁸)との酸の強さの違いを構造から説明(論述)
- その場で与えられた知識:
  - L1 存在比率-pH 図: 計算結果として図で与える。
  - L1 分子内水素結合と酸の強さ: 説明は一切なく、数値と構造式から考察させる。
- 解法の核心・差がつく点: 問1 は [HA⁻]/[H2A] = 10 から 10/11 = 0.91。問2 は、隣り合う -COO⁻ と -OH の分子内水素結合で 1 価イオンが安定化し第一電離は進みやすく、同じ水素結合のため第二電離は起こりにくいこと、メタ体ではそれができないことを、両段階について書く。
- 作問メモ: 「異性体 2 つの電離定数を並べ、第一段階と第二段階で大小が逆転する理由を構造から書かせる」型。知識を与えず数値の対比だけで考察を促す。

### (b) 毛細管電気泳動と平均荷電数

- 流れ: 毛細管電気泳動の装置(図4)と操作を説明。1 価の弱酸 HZ(Ka = 10⁻⁵·⁰)で、泳動速度が Z⁻ の存在比率に比例することを述べ、2 価の酸では平均荷電数に比例すると一般化する。
  - 問3: Z⁻ がほとんど存在しない pH の上限(ア)、Z⁻ の移動方向(イ)(語群選択)
  - 問4: 存在比率 x、y、z(%)からサリチル酸の平均荷電数を表す式
  - 問5: サリチル酸と m-ヒドロキシ安息香酸の平均荷電数-pH 曲線を描き、−0.5 と −1.5 になる pH を記入
  - 問6: 2 つを泳動速度の差で分離するのに最も適した pH(6 択)
- その場で与えられた知識:
  - **L2 毛細管電気泳動(実験手法の提示)**: 緩衝液を満たした毛細管の両端を電極槽に浸し、試料ゾーンを作って直流電圧をかけると移動する、と図と文で説明。問3・問6 の前提。
  - **L2 平均荷電数と速度の比例モデル(モデルの提示)**: 「電離平衡が常に保たれるため、試料ゾーン全体の速度は Z⁻ の存在比率に比例する」「Y²⁻ は HY⁻ の 2 倍の速さで移動するため、符号を付けた価数に存在比率を乗じて算出される平均荷電数に比例する」と定義。問4 はこの定義の式化、問5 はその作図、問6 はその差の比較で、定義なしにはどれも答えられない。
- 解法の核心・差がつく点: ア = 2.0、イ = 陽極。平均荷電数 = −(y+2z)/100。曲線は pH = pKa1 で −0.5、pH = pKa2 で −1.5 を通る 2 段の階段状。差が最大なのは、サリチル酸がほぼ −1、メタ体がほぼ −2 になる pH 11.6(差 約 0.97)。pH 3.5 でも差 約 0.63 あるので、概算で比べる必要がある。
- 作問メモ: 「1 価の場合で新しい規則を導入 → 2 価に一般化して新しい量を定義 → 式 → グラフ → 最適条件の選択」という 4 段の階段。(a) で準備した 2 物質のデータをそのまま (b) で使い回す構成で、前半が後半の素材になっている。本格的な L2 の雛形。

## 大問III(有機/エステルとエーテル)

### (a) フマル酸・マレイン酸のジエステル

- 流れ: 同じ分子式で不斉炭素を 1 個ずつもつ A、B を加水分解すると、A から C・D・E、B から F・G・H が 1 mol ずつ生じる。C の酸化生成物 I、D の元素分析、E・F(C4H4O4 の幾何異性体)、F の脱水生成物 J、G(C2H6O)、H のヨードホルム陰性を与える。
  - 問1: E、G、I の化合物名
  - 問2: A の分子式
  - 問3: A、H、J の構造式
- その場で与えられた知識: なし(L0)。
- 解法の核心・差がつく点: I = アセトン、C = 2-プロパノール、D = C4H10O で不斉炭素をもつ 2-ブタノール、E = フマル酸、F = マレイン酸、J = 無水マレイン酸、G = エタノール、A = C11H18O4。H は C5H12O で不斉炭素をもちヨードホルム陰性 → 2-メチル-1-ブタノール。
- 作問メモ: 「同じ分子式の 2 つのエステルを並行して加水分解し、片方の情報からもう片方の未知成分の分子式を引き算で出す」型。

### (b) 芳香族エーテルの C–O 結合切断

- 流れ: 植物由来資源の活用という文脈で、ジフェニルエーテル + H2 → フェノール + ベンゼン(図1)を示す。同様の構造の L(C14H14O)は M(C7H8O)と N だけを生じ、M は臭素化で C7H5Br3O になる。
  - 問4: M、N の構造式
  - 問5: 空欄ア(配向性)
  - 問6: L の構造異性体で、同様の反応で N を生じるものの数
  - 問7: L の構造式
  - 問8: M の異性体のうち沸点最低のものの構造式と、それを他と区別する方法(試薬 5 つから 1 つ選んで説明)
- その場で与えられた知識:
  - **L2 芳香族エーテルの水素化分解(反応の提示)**: 「炭素-酸素結合を切断する反応が研究されている」として反応式を図で与え、「図1 と同様に」適用を指示。問4 で N = トルエンと決め、問7 で L を決め、問6 で数え上げる根拠になる。軽量の L2(類推で 1 回適用)。
  - L1 o,p-配向性: フェノールの臭素化と「同様に」として空欄で問う。
- 解法の核心・差がつく点: N = トルエン。M は Br が 3 個入るので o 位 2 つと p 位が空いた m-クレゾール。どちらの C–O が切れても M と N しか生じないので、L は 2 つの環がともに m-トリルの対称なエーテル。問6 は 5。問8 はアニソールが沸点最低で、ナトリウムを加えて水素が発生しないことで区別する(塩化鉄(III) ではベンジルアルコールと区別できない)。
- 作問メモ: 「研究紹介として単純な新反応を 1 つ与え、『生成物が 2 種だけ』という条件から対称性を読ませる」型。新反応は入口にすぎず、後半は異性体の数え上げ・沸点・検出反応という既習事項で締める。

## 大問IV(高分子(天然)/甘味物質とペプチド)

### (a) 甘味に関連する 8 化合物の識別

- 流れ: グルコース、フルクトース、スクロース、マルトース、セロビオース、マルトトリオース、ネオテーム、クルクリンのどれかである A〜H を、ニンヒドリン、ビウレット、加熱、酵素分解、燃焼、酸加水分解の 6 実験で識別する。
  - 問1: 空欄ア〜ウの組合せ(8 択)
  - 問2: A〜H の化合物名
  - 問3: フェーリング液を還元しない糖
- その場で与えられた知識:
  - L1 三糖: 「単糖と二糖が脱水縮合したもの」と定義。燃焼データから C18H32O16 を導くのに使う。
  - ネオテーム、クルクリンは「ジペプチドをもとに合成した甘味料」「植物から抽出されたタンパク質」と説明され、それ以上は不要(novel_context)。
- 解法の核心・差がつく点: E = クルクリン、B = ネオテーム。A は C:H = 18:32 でマルトトリオース、C と G は 12:22 の二糖で、G = マルトース、C = セロビオース。H = グルコース、D = スクロース、F = フルクトース。問1 は選択肢 5。問3 はスクロースのみ。
- 作問メモ: 「共通テーマ(甘味)で糖とペプチド・タンパク質を混ぜ、検出反応で分類してから定量データで細分する」型。未知物質は一言の説明をつけて分類上の位置だけ知らせる。

### (b) 人工環状ペプチド

- 流れ: ペプチド医薬の改変(親水性アミノ酸への置換、D 型の導入、環状化)を説明し、シクロスポリンを改変した環状ペプチド I の立体構造式(図1)を示す。
  - 問4: 構成アミノ酸の総数
  - 問5: 1 つ含まれる D-アミノ酸を図2 の向きで描くときの空欄エ、オ
  - 問6: 環状ペプチドが鎖状のものより水に溶けにくい理由
  - 問7: 最も疎水性の高いアミノ酸をアスパラギン酸に置換して得られる 2 種の構造異性体を、前後を含むトリペプチドとして描く
- その場で与えられた知識:
  - L1 立体表記と D/L: くさびと破線の意味を説明し、D 型は L 型の鏡像異性体と述べる。絶対配置の規則は与えないが、「他と違う 1 つを探して写す」ことで解ける。
  - L1 側鎖 -COOH でのペプチド結合: 説明なし。「2 種類得られた」という結果から気づかせる。
- 解法の核心・差がつく点: 11 残基(グリシン 4、システイン、ロイシン、グルタミン、アラニン、トレオニン、セリン、グルタミン酸)。問6 は末端の -NH2 と -COOH がないこと。問7 はロイシンを置換し、アスパラギン酸の α 位と β 位のどちらの -COOH でグリシンとつながるかで 2 種。
- 読み取りの注意: 図1 のくさび・破線は細部の判別に自信がない。アラニン残基だけ表記が逆に見えるため D 体はアラニン(エ = CH3、オ = H)と読んだが、確証は弱い。
- 作問メモ: 「大きな実在分子の構造式を丸ごと見せ、数える・例外を探す・一部を改変する、の 3 操作を問う」型。知識ではなく図の読解と空間把握で差をつける。創薬という文脈が設問(水溶性を上げる置換)に直結している。
