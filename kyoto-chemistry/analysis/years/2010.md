## 大問I(無機・理論/ポリリン酸、リン酸塩の電離平衡と緩衝液)

### (a) ポリリン酸

- 流れ: リン酸の過冷却・潮解、加熱による脱水縮合(ピロリン酸の式を例示)、鎖状・環状ポリリン酸の生成。
  - 問1: 空欄(凝固、潮解)
  - 問2: n 分子からできる鎖状ポリリン酸の組成式
  - 問3: 環状で分子量最小のものの分子式(3分子、4分子。四員環は不可)
- その場で与えられた知識: なし(L0)。ポリリン酸は見慣れないが、脱水縮合の数え上げで解ける。
- 解法の核心・差がつく点: 鎖状は H(n+2)PnO(3n+1)。3分子は H3P3O9。4分子は環をつくった後もさらに架橋でき、P4O10 に行き着く。既知の十酸化四リンの構造と結びつくかが差。
- 作問メモ: 「有機の縮合の考え方を無機オキソ酸に移す → 一般式 → 極限まで縮合させると既知の物質になる」。

### (b) リン酸塩の平衡

- 流れ: 3段階の電離定数を与え、NaH2PO4 と Na2HPO4 の液性を加水分解定数との比較で判定。Na2HPO4 の [H+] を、加水分解(5)と不均化(6)の2平衡から導く。最後にリン酸緩衝液。
  - 問4: 空欄 ウ・エ(液性)、オ(考慮する式の番号)
  - 問5: I・II(x, y による濃度の式)
  - 問6: A〜D(K1, K2, K3, Kw による式)
  - 問7(i): 等量混合緩衝液の [H+]
  - 問7(ii): pH 7.0 にする塩酸の体積と Δ[H+]/Δ[Cl-](計算過程つき)
- その場で与えられた知識:
  - 加水分解定数 Kw/Ka と液性判定(L1)。式(4)(5)を示して定数を表させる。
  - 不均化平衡を使った酸性塩の [H+] の導出(L1)。考える平衡、文字の置き方、近似まで本文が指示。
  - 道具は質量作用の法則と Kw だけで、新概念ではないため L2 にしていない。
- 解法の核心・差がつく点: 空欄 D。[OH-] = x と [H+] = K2[H2PO4-]/[HPO4^2-] を組み合わせ、2つの関係式を足して (x+y/2)^2 をつくると [H+] = √(K2K3 + 10 K2 Kw)。問7(ii) は Δ[H+]/Δ[Cl-] ≒ 3.6×10^-6 で緩衝作用の強さを数値で実感させる。
- 作問メモ: 「定番の結果(酸性塩の pH)を、近似の根拠を1つずつ示しながら自分で導かせる」「最後に、加えた酸のうち [H+] の増加に回る割合を計算させて緩衝作用を定量化」。

## 大問II(理論・高分子(合成)/プロピレンの溶解平衡と溶液重合)

- 流れ: 理想気体、ヘンリーの法則、浸透圧 Π = mRT を前提に3つの実験。
  - 実験1: 1.0 L 容器に 10 atm のプロピレン、溶媒 300 mL を入れると 8.0 atm。
  - 実験2: 開始剤にあたる物質 C を含む溶媒で重合。浸透圧は一定、圧力は図3のように減少。
  - 実験3: 10 L 容器、溶液 3.0 L、10 atm を保って 10 時間。浸透圧 0.082 atm。
  - 問1: 溶媒中のプロピレン濃度(0.60 mol/L)
  - 問2: 1.0 時間後のポリプロピレンの質量(計算過程つき、約 4.3 g)
  - 問3: v = k[A] の k(約 0.17 /h)
  - 問4(i): 実験3 の生成量(約 5.3×10^2 g)
  - 問4(ii): 分子量(約 5.3×10^4)
- その場で与えられた知識: なし(L0)。Π = mRT と v = k[A] は式として書かれるが教科書事項。
- 解法の核心・差がつく点: 気相と溶液の両方が圧力に比例するので A の総量が圧力に比例すること。v が「容器 1.0 L あたり」で定義されていること。実験3 は圧力一定で [A] が一定(0 次的に進む)こと。浸透圧一定から高分子の分子数が一定で、鎖が伸びるだけと読むこと。
- 作問メモ: 「気液平衡で濃度を圧力から読む → 圧力の時間変化を反応量に変換 → 条件を変えた実験へ速度定数を持ち越す → 浸透圧で分子数を数え、分子量へ」。基本法則4つを1つの装置でつなぐ融合型。

## 大問III(有機/エステルの構造決定、芳香族置換の位置選択性)

### (a) 構造決定

- 流れ: 冒頭で官能基選択的反応を説明。A(C26H22O4)の加水分解で B:C = 2:1。B はナフタレン D の H 1個を COOH に換えたもの。C は組成式 C2H5O で不斉炭素1個。C を同物質量の無水酢酸で G に、酸化で H(分子量 -2)、加水分解で I と酢酸、I はヨードホルム陽性。
  - 問1: B の2つの異性体の構造式
  - 問2: C, G, I の構造式
  - 問3: 空欄 ア(Na との反応で生じる水素、1 mol)
  - 問4: F(無水フタル酸)とメタノールの生成物
- その場で与えられた知識:
  - 反応速度差による官能基選択性(L2、軽量)。「官能基の反応速度の差を利用して特定の官能基を反応させられる。同じ物質量の無水酢酸では第一級部位が速く、第一級のヒドロキシ基を選択的にアセチル化できる」という一般則を冒頭に置く。
  - 使い方: G で第一級 OH だけをエステルにし、残った第二級 OH が酸化されてケトンになる、と読む。この規則がないと、第二級側がアセチル化された経路でも I がヨードホルム陽性になり得るため、G と I が決まらない。
- 解法の核心: C = 1,3-ブタンジオール、G = 4位アセチル体、I = 4-ヒドロキシ-2-ブタノン。
- 作問メモ: 「冒頭に未習の選択性ルールを1文で置く → 多官能性化合物の一方だけを保護 → 残りを変換 → 保護を外して検出反応」。保護基の考え方を名前を出さずに体験させる型。

### (b) 置換基効果の数値モデル

- 流れ: 配向性と活性化・不活性化を「置換基効果」として導入。トルエンの塩素化はベンゼンの 335 倍速く、異性体組成は o 59.7%、m 0.5%、p 39.8%。位置ごとの速度定数に分けて考える。
  - 問5: 空欄 イ(2ko)、ウ(2km)、エ(kp/k = 800)
  - 問6: m-キシレンの一塩素化生成物 J, K, L の生成量の順
  - 問7: m-キシレンはベンゼンの何倍速いか(計算過程つき)
- その場で与えられた知識:
  - 配向性・置換基効果(L1)。前提の説明。
  - 位置別速度定数モデル(L2)。「ベンゼンは等価な6点で全体 6k、トルエンは5点の速度定数の和。異性体の組成は各位置の速度定数を全体で割ったもの」と説明し、組成の式を空欄つきで示す。問5 で ko/k などを求めるのに必須。
  - 加成則(L2)。問6 の設問文で「m-キシレンの4位の k4/k は ko/k と kp/k の積として近似できることがわかっている」と与える。問6・問7 に必須。
- 解法の核心・差がつく点: 2位は o×o が1か所、4・6位は o×p が2か所、5位は m×m が1か所。K > J > L、約 2.2×10^5 倍。等価な位置の数の数え方と、ベンゼンは 6k で割ることを忘れない。
- 作問メモ: 「定性的に知っている規則(配向性)を、実測データから数値パラメータに変換 → 簡単な合成則を与える → 未知の基質の生成物分布と反応性を予測」。データ → パラメータ抽出 → 外挿 の3段構成は L2 型作問のひな形として使いやすい。

## 大問IV(高分子(天然)/DNA の水素結合と糖、グリセロリン脂質)

### (a) DNA

- 流れ: DNA の構成と塩基対。アミノ基の N-H、カルボニル基の C=O の極性から水素結合を説明する空欄8個(問1)。問2 はリボースの六員環構造と鎖状構造の図を手がかりに、五員環の β-デオキシリボースを描く。
- その場で与えられた知識: リボースの環状・鎖状構造の図と、デオキシリボースの定義(L1)。
- 解法の核心: 鎖状に戻して4位の OH で閉環し直す。置換基の上下を図1 と同じ描き方で移し、1位 OH を上(β)にする。
- 作問メモ: 「教科書に結果だけ載っている構造を、別の形(六員環・鎖状)から自分で組み立てさせる」。

### (b) グリセロリン脂質

- 流れ: グリセロリン脂質の共通構造 A(図3)にセリン B(図4)が縮合した C。1位に C14 飽和脂肪酸、2位に脂肪酸 D。2位だけを加水分解する酵素で 15.5 g の C から 6.04 g の D。D の水素付加物は分子量 312。
  - 問3: セリン水溶液の NaOH による滴定曲線を4択+理由(酢酸の曲線を参考図として提示)
  - 問4: C や脂肪酸に関する正誤(正しいものをすべて)
  - 問5(i): D の分子量(302)
  - 問5(ii): D の分子式(C20H30O2)
- その場で与えられた知識: アミノ酸の滴定曲線の読み方(L1)。グリセロリン脂質は図で構造が与えられ、使うのはエステルの知識だけなので L0 相当。
- 解法の核心・差がつく点: C の式量を部品の和から水4分子を引き、Na 分を足して 473 + M とおく。飽和体 C20H40O2 との差 10 から二重結合5個。問4 は不斉炭素が2個あること、セッケンが2分子できること。
- 作問メモ: 「生体分子の骨格を図で与え、部品の式量の足し引きで未知の部品を決める」「位置特異的な酵素で一部だけ切る設定」。
- 注: 問3 は二段階の曲線 (う) が意図と考えたが確信はない。(う) は pH 約1から始まっており、双性イオンの水溶液としては不自然。図の読み取りと出題意図の両方が不確か。
