## 大問I(理論/陽イオン交換樹脂のイオン交換平衡)

- 流れ
  - (a) リード文: スルホン酸型樹脂Aの説明。1000gあたり官能基2.50mol。A 30.0g に 0.100mol/L 食塩水500mL を加えると全量520mL。溶液を回収し蒸発乾固すると固形物1.17g。濃度の約束(溶液相は溶液1Lあたり、樹脂相は樹脂1Lあたり)を明記。
  - 問1: 官能基の名称(スルホ基)。
  - 問2: R-SO3H + Na+ ⇄ R-SO3Na + H+ の空欄4つ。
  - 問3: 平衡時の4成分の濃度。残留NaCl 0.0200mol → [Na+]=0.0400、[H+]=0.0600、樹脂相(20mL)で R-SO3H 2.25、R-SO3Na 1.50 mol/L。
  - 問4: K=1.00。
  - (b) リード文: 官能基量 x、Na+ の初期量 y、反応後 y1 として K を文字式で表し、さらに「x を2回に分けて使う方が効率的」として2回目の残量 y2 を導く。
  - 問5: 空欄オ〜コ。オ=2y、カ=x−y、y1=y²/(x+y)、y2=y³/(x+y)²。
  - 問6: y2/y=1.00% となる1回あたりの樹脂量。(x+y)/y=10 → x=0.450mol → 180g。
- その場で与えられた知識
  - L1: イオン交換を平衡として扱うモデル。樹脂相の濃度を「樹脂の体積1Lあたり」で表すと約束し、問3で「化学平衡の法則が成立するとしたとき」と指示。問3・4と(b)全体の前提。**L2との境界**: 教科書・標準問題集では樹脂は量論でしか扱わないが、新たに与えられるのは濃度の取り方だけで、使う法則は既習なので L1 に倒した。
  - L1: 分割処理の方が効率的という多段操作の考え方(下線部④で結論を与える)。分配平衡の繰り返し抽出と同型。
- 解法の核心・差がつく点
  - 蒸発で HCl が揮発し NaCl だけ残ると読むこと、樹脂体積 20mL を全量から出すこと。
  - (b) の2回目では、1回目に生じた H+(y−y1)が溶液に残っている。これを入れると y2 が綺麗な形になり、入れ忘れると問6が3次方程式になって行き詰まる。
- 作問メモ
  - 「数値実験で平衡定数を決める(a)→ 同じ系を文字式で一般化し、操作の最適化(分割使用)を論じる(b)」の二段構成。
  - 不均一系でも「相ごとの濃度の定義」を一文与えれば平衡計算に持ち込める。K が 1 になるよう数値を調整して後半の式を簡単にしている。

## 大問II(理論/黒鉛層間へのLi挿入と鉛蓄電池の充電)

- 流れ
  - (a) リード文: 黒鉛の層状構造(図1)、層間に原子・分子を挿入できること、リチウム二次電池の負極充電反応、最大挿入時の配置(図2)。
  - 問1: ア 共有、イ ファンデルワールス力、ウ nC+Li++e−→LiCn、エ 6。
  - 問2: LiCn と水の反応式(「金属リチウムと似た性質」のヒント)。
  - (b) リード文: リチウム二次電池で鉛蓄電池を充電(図3)。負極の質量が2.30g減少。電極Iの実際の質量減少は9.80g。
  - 問3: 電極I・IIの充電反応式。
  - 問4: 電子0.331mol、電極Iの理論質量減少10.6g。
  - 問5: 充電に利用された割合 約92.4%。
- その場で与えられた知識
  - L1: 黒鉛層間化合物 LiCn(インターカレーション)。「層間距離が容易に変化し挿入・脱離できる」「炭素 n mol に Li+ 1mol が取り込まれ LiCn」と説明。リチウムイオン電池自体は現行教科書本文にあるので L1。
- 解法の核心・差がつく点
  - 図2の数え上げ: Li は六角形3個に1個、六角形1個あたり C は2個 → LiC6。
  - 図3の電池記号から電極I・IIの正負を判定すること。
- 作問メモ
  - 「身近な先端材料(Liイオン電池)を導入 → 図から組成を数えさせる → 既習の電池(鉛蓄電池)とつないで電気量計算、理論値と実測値のずれから効率」という型。
  - 新素材パートは図の読み取りと類推(アルカリ金属と水)だけで解けるよう設計されている。
- 読み取りの注記: 図3の電池記号は左が長い線(正極)と読んだ。スキャンに手書きの書き込みがあり若干不確か。逆なら理論値15.9g、効率61.6%。

## 大問III(有機/アミド C15H20N2O2 の構造決定と触媒)

- 流れ
  - リード文: A を加水分解すると B(C4H6O2、鎖式)、C(ベンゼン誘導体)、D(C4H11N)。酸性でエーテルに移るのはBだけ、塩基性ではDだけ。B は白金存在下で水素を吸収しEに。Eを硫酸とともに2-メチル-1-プロパノール中で加熱しエステル。触媒の一般論の空欄。
  - 問1: ア カルボキシ、イ 触媒、ウ 活性化エネルギー、エ 反応速度、オ 均一触媒。
  - 問2: B 0.200g が吸収する水素の体積(0.0521L)。
  - 問3: エステルの分子式 C8H16O2。
  - 問4: B の構造をすべて(立体異性体含め4種)。
  - 問5: C の構造をすべて(アミノ安息香酸 o, m, p)。
  - 問6: C4H11N のうち D になり得ないもの(第三級アミン)。
- その場で与えられた知識: なし(L0)。
- 解法の核心・差がつく点
  - 分子式の引き算で C=C7H7NO2。「どちらの条件でもエーテルに移らない」=両性。
  - 「なり得ないものを答えよ」という逆向きの問い(アミド形成には N–H が必要)。
- 作問メモ
  - 「3成分の加水分解生成物 + 抽出挙動で官能基を絞る + 『条件に合うものをすべて』『合わないものをすべて』」という網羅型の異性体問題。途中に触媒の知識問題を挿む。

## 大問IV(天然高分子/糖の環状・鎖状構造と立体配置、RNA)

- 流れ
  - リード文: グルコースの鎖状A、六員環B・C、4位OHが付加した五員環(空欄ア)、鎖状の縦書き表示A'。リボースも平衡混合物で、RNA中では五員環D。3位と5位のOHがリン酸ジエステル結合でつながる。
  - 問1(a): くさび表記Eと C1 の配置が同じなのは B か C か(→ C)。
  - 問1(b): B の C3 の配置と同じなのは F か G か(→ G)。
  - 問2: フェーリング液の還元に直接関与する構造(A)。
  - 問3: 五員環グルコース(β型)の構造を描く。
  - 問4: リボースの鎖状構造を A' にならって描く。
  - 問5: リボース2分子とリン酸1分子からなる、RNAと同じ結合様式のリン酸ジエステルの構造。
- その場で与えられた知識
  - L1: グルコースの五員環構造。「4位のOH基がCHO基に付加した五員環構造も微量含まれる」の一文のみ。問3で描かせる。
  - L1: 鎖状構造の縦書き表示(フィッシャー投影式に相当)。「AはふつうA'のように表される」と図を並べるだけで投影の約束は説明しない。問4でリボースに適用。
  - L1: リン酸エステル。問5で「リン酸はOH基1〜3個とエステル結合を形成でき、モノ・ジ・トリエステルを生じる」と定義し、ジメチルエステルを記入例に示す。
  - 上2つは **L2との境界**。教科書本文にない構造・表記を問題文に依拠して描かせるが、説明はごく短く、フルクトースの五員環や乳酸のくさび表記からの類推で処理できるため L1 とした。
- 解法の核心・差がつく点
  - 問1は視点を取り直して前後関係を判定する空間把握。暗記では対応できない。
  - 問4は A(ハース式)と A'(縦書き)の対応から「環の下側のOH=縦書きの右側」を自分で抽出してリボースに移す。
- 作問メモ
  - 「既知の分子(グルコース)で2つの表記の対応を見せる → 未知側の分子(リボース)に同じ変換をさせる」という対応関係抽出型。
  - 「同じ立体配置はどちらか」を二択で問う形式は、知識ゼロで立体把握だけを測れる。
