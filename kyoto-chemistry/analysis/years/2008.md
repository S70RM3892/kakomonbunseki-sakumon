## 大問I(理論・無機/イオン結晶 NaCl・KCl をめぐる小問集合)

### (a) NaCl の格子面とへき開

- 流れ: NaCl の単位格子を示し、3点を通る平面を「格子面」と定義。面 abc(立方体の面)と面 abd(面対角線3本がつくる斜めの面)について 1 nm^2 あたりのイオン数を求めさせ、面 abc に平行に割れやすい理由を問う。
  - 問1: MgO のイオン式
  - 問2: 単位格子内のイオン数、1 nm^3 あたりの数、各面 1 nm^2 あたりの Na+・Cl- の数(6個の数値)
  - 問3: 面 abc に平行な面で割れやすい理由(論述)
- その場で与えられた知識: 格子面(L1)。用語の定義のみで、作業は幾何的な数え上げ。
- 解法の核心・差がつく点: 面 abc は Na+ と Cl- が同数(各 6.4 個)、面 abd は片方のイオンのみ(7.5 個と 0 個)。斜めの面は Na+ 層と Cl- 層が交互に重なり強く引き合う。面 abc に平行な面は中性で、ずれると同符号が向き合って反発する。正三角形内の頂点 1/6・辺上 1/2 の数え方が差になる。
- 作問メモ: 「結晶内の特定の面を定義 → 面密度を数えさせる → 巨視的性質(へき開)の理由を書かせる」。数値が論述の根拠になる構成。
- 注: a,b,d の位置と頂点のイオン種は図からの読み取りに依存。数値は公式解答で未確認。

### (c) KCl の溶解熱と自発性

- 流れ: 反応の方向は「エネルギー」と「乱雑さ」の兼ね合いで決まると説明。表2 に 6 本の熱化学方程式。問6 で溶解熱の計算と、自然に溶ける理由の論述。
- その場で与えられた知識: ボルン・ハーバー型サイクル(L1)。乱雑さの説明は当時は範囲外寄りだが、現行課程では教科書で扱うため項目に挙げていない。
- 解法の核心: 合計 -17 kJ(吸熱)。吸熱でも乱雑さの増大が勝つ、と2要因を対比して書く。
- 作問メモ: 「計算結果が直感に反する(吸熱なのに進む)→ リード文の原理で説明させる」。現行課程ならエンタルピー・エントロピーの語で作り直せる。

### (d) 沸点上昇

## 大問II(理論/弱酸の分配平衡と電離平衡、二相系でのペプチド合成)

### (a) 分配平衡

- 流れ: 弱酸 AH の電離定数 → 水と混ざらない有機溶媒 X を加えた二相系。非電離の AH だけが X に移り、濃度比は 8.0 で一定((3)式)。物質収支を立てて pH を求め、NaOH 添加後の pH、さらに P = [AH]X/([AH]aq+[A-]aq) の pH 依存へ。
  - 空欄 I: 0.20 mol/L 弱酸の pH(2.5)
  - 空欄 ア・イ: X 中、水中の物質量の式
  - 空欄 II: X を等体積加えた後の pH(3.0)
  - 空欄 III: NaOH 添加後の pH(5.0)
  - 空欄 ウ: P を Ka と [H+] で表す
  - 空欄 エ: [H+]≪Ka のときの log P の式
  - 問1: pH と log P のグラフを6択から選ぶ((か))
- その場で与えられた知識:
  - 分配平衡(L1): 「X 中と水中の非電離 AH の濃度比は一定」と(3)式で与える。「分配係数」の語は出ない。
  - 見かけの分配比 P(L1): (7)式で定義。両極限へ誘導。
  - どちらも問題文だけで完結し、知らなくても解ける。新演習レベルで定番なので L1。構造は L2 型の境界例。
- 解法の核心・差がつく点: II は 9[AH]aq + [H+] = 0.20 と Ka の連立。III は「NaOH と等量が電離」として残りの AH を二相に配る。グラフは P=8.0 を log P≒0.9 に直すこと((お) が引っかけ)。
- 作問メモ: 「既習の平衡(電離)に、その場で与える第2の平衡(分配)を重ね、物質収支で連立 → 新しい量を定義 → 極限での挙動 → グラフ選択」。京大理論の典型的な誘導型。

### (b) 二相系のペプチド合成

- 流れ: 疎水化したアミノ酸誘導体 RCOOH と R'NH2 は X 中では反応しない。水にのみ溶ける物質 C を加えると、X 中の RCONHR' が増え、最終的にほぼ全量が生成物になる。
  - 問2(1): C のような物質の名称(触媒)
  - 問2(2): 反応速度が増す理由
  - 問3: X 中で反応しないのに X 中の生成物が増え、ほぼ完全に進む理由(疎水性・親水性をふまえて)
- その場で与えられた知識: なし(L0)。(a) の分配の考え方を定性的に使う。
- 解法の核心: 反応の場は水相。生成物は電離する基がなく疎水的なので X へ抜け、水相の平衡が右へずれ続ける。原料は X から水相へ補給される。
- 作問メモ: 「前半で定量的に扱ったモデルを、後半で未知の現象の定性的説明に転用させる」。知識ゼロ追加で思考力を問える。

## 大問III(有機/C4H8O の構造決定と混合物定量、芳香族エステルの構造決定)

### (a)

- 流れ: A は臭素付加・Na と反応・不斉炭素あり、B はエーテルで臭素付加、C は臭素付加なし。A の酸化で D、D の水素付加で C。
  - 問1: A, C の構造式
  - 問2: B の可能な構造式すべて(幾何異性体込み)
  - 問3: D の付加重合体の構造式
  - 問4: 混合物のモル百分率(臭素付加による質量増と水素発生量から)
- その場で与えられた知識: なし(L0)。
- 解法の核心: A = 3-ブテン-2-オール、C = 2-ブタノン、D = メチルビニルケトン。B は5種。組成は A 40%、B 25%、C 35%。
- 作問メモ: 「同一分子式の3化合物を官能基反応の有無で区別 → 混合物の定量」。構造決定と計算を1つの設定で両立。

### (b)

- 流れ: エステル E の加水分解で F 2 mol と G(C8H6O4)1 mol。G は加熱で酸無水物。F は H(C8H10)の異性体 I のスルホン化(異性体は全く生じない)→ アルカリ融解で得る。
  - 問5: G, I の構造式
  - 問6: I 53 g から得られる J の質量
  - 問7: E の構造式
- その場で与えられた知識: なし(L0)。
- 解法の核心: 「異性体が全く生じない」= p-キシレン。F は 2,5-ジメチルフェノール。
- 作問メモ: 「生成物が1種類という対称性の情報で置換位置を決めさせる」。

## 大問IV(高分子(天然)/タンパク質の塩析・透析・電荷による分離)

### (a)

- 流れ: 塩析の仕組み(疎水性領域の水和水が奪われる)を説明。問1 で変性との違い。
- その場で与えられた知識: なし(L0)。説明は教科書より詳しいが設問には不要。

### (b)

- 流れ: 等電点の定義 → 硫安で塩析 → 透析(pH 7.0 と pH 3.0 の緩衝液)→ 負電荷のタンパク質だけを結合する樹脂を詰めた注射器に通す。
  - 問2: 透析で濃縮液がどう変わったか(半透膜の役割を含めて)
  - 問3: pH 3.0 の試料を通したときの結果を4択+理由
- その場で与えられた知識: 電荷で結合を分ける樹脂によるタンパク質分離(L1)。樹脂の性質は問題文で完結。
- 解法の核心: pH 7.0 で A(等電点 5.0)が負で結合、B は通過するので B の等電点は 7.0 以上。pH 3.0 では両方正で通過(え)。
- 作問メモ: 「実験操作の手順を追わせ、1つ目の条件の結果から未知の性質を逆算 → 2つ目の条件の結果を予測」。図で装置を見せ、名称(クロマトグラフィー)は出さない。
