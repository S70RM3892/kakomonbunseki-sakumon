## 全体

- 冊子 19〜36 ページ、大問4題・100点。I, III, IV は (a)(b) の2部構成、II は単一テーマ(計7パート)。
- **L2 は 4パート。** I(a) 体心立方格子の八面体隙間・四面体隙間、II ガス吸収の速度式と連続装置の定常収支、III(a) 非等価な炭素原子の数、III(b) 付加反応の立体化学。大問 I〜III のすべてに「その場で教えて使わせる」要素がある。
- L2 ゼロの 2023年度と対照的。与え方は、II が式+装置図(化学工学)、III が図解ルール+「例にならって適用」。リード文と図が長く、化学だけで18ページある。
- IV は範囲外の題材(環状ペプチド、非天然アミノ酸)を使うが、解くのは既習の量的関係と呈色反応の推理。
- 論述・導出過程要求はなし。答のみの計算、空欄、選択、構造式で構成。

## 大問I(a)(理論/チタンの結晶と水素が入る隙間)

- 流れ: 水素を吸収する Ti を完全な六方最密構造とみなし、八面体隙間(6原子で囲まれる)・四面体隙間(4原子で囲まれる)を図1で定義。水素吸収量が増えると体心立方格子に変わり、そこでも2種の隙間が考えられると述べる。図2で一辺1の体心立方格子に座標を設定。
  - 問1: 八面体隙間・四面体隙間に入る原子の最大半径(0.41r、0.22r)
  - 問2: Ti 原子1個あたりの隙間の数(八面体1、四面体2)
  - 問3(i): 体心立方の八面体隙間での Ti-H 距離2種(0.50、0.71)
  - 問3(ii): z=0 面の正方形内にある八面体隙間の位置すべて(5点)
  - 問3(iii): 同じ面内の四面体隙間の位置すべて(4点)
- その場で与えられた知識:
  - L1 最密構造の八面体隙間・四面体隙間と限界半径。図1と本文で定義。
  - **L2 体心立方格子の八面体隙間・四面体隙間**(モデルの提示)。リード文は「体心立方格子の場合も八面体隙間と四面体隙間が考えられる」と述べるだけ。位置は教えず、問3の設問文で「八面体隙間では H と周囲の4つの Ti が同一平面上にあり、距離に異なる2つの値がある」「四面体隙間では距離は1つの値のみ」という性質を条件として与え、受験生に位置を探させる。問3全体で必須。
- 解法の核心・差がつく点: 問2は単位格子の暗記では出ず、最密充填の層の重なりから数える。体心立方の八面体隙間は面心と辺の中点(歪んだ八面体)、四面体隙間は面上の (1/2, 1/4, 0) 型の位置。「距離が1つの値だけ」という条件から四面体隙間を逆算できるかが山場。完答は難しい。
- 作問メモ: 既習の構造で概念(隙間)を定義し、未習の構造に持ち込んで探索させる型。位置を教えない代わりに「距離が何種類あるか」という検算可能な条件を設問文に埋め込み、座標で答えさせることで立体把握を採点可能にしている。L2 としては「ルール適用」より「幾何的探索」寄りの境界例。

## 大問I(b)(理論/パラジウムの水素吸収量の測定)

- 流れ: 容器1・容器2(Pd 入り)とバルブ A・B からなる装置(図3)で、操作1(Ar で圧力変化を測る)、操作2(H2 を導入し平衡後の圧力を測る)、操作3(容器1の H2 を O2 と反応させ水 10.0 g を得る)を行う。温度と体積は与えられない。
  - 問4: 操作2後に気体として残った H2 の総物質量(約0.83 mol)
  - 問5: 吸収された H 原子と Pd 原子の数の比(約0.74)
  - 問6: 吸収された H をすべて H2 として放出したときの体積(約6.9 L)
- その場で与えられた知識: なし(L0)。
- 解法の核心・差がつく点: 操作1は吸収されない Ar で容器2の空間体積(容器1の半分)を較正する操作だと読めるか。操作3の水の量から V1/RT を決め、導入量と残存量の差を吸収量とする。温度・体積が未知でも比で解ける。
- 作問メモ: 未知数(体積、温度)を伏せたまま、複数の操作の情報を組み合わせると消去できるように設計した実験読解型。「吸収されない気体で体積を測る」という実際の測定法の論理をそのまま問題にしている。

## 大問II(理論/ガス吸収操作)

- 流れ: 不純物気体 A を吸収液で除去する操作を考える。ヘンリーの法則 P_A = H[A]max(式1)と吸収速度式 v_A = k([A]max - [A])(式2)を与える。操作1は密閉容器内で吸収液を霧状に散布する回分操作、操作2は気体と吸収液を連続的に流す装置(図1)、操作3は A が水と反応して AH+ と OH- を生じる場合(式4, 5)に塩酸を吸収液とする操作。
  - 問1: ア(熱運動)、イ(大きくなる)、ウ・エ(吸収量と吸収液の体積)、オ(W = G(f0 - f_A)/g_A)
  - 問2: 液滴の直径を2倍にしたときの最終吸収量(1倍)、液滴1個あたりの吸収速度(4倍)、全体の吸収速度(1/2倍)
  - 問3: 操作1での v_A と [A] の関係、吸収量と時間の関係のグラフ選択
  - 問4: f0 から f_f まで下げるのに必要な W/G の最小値(h(f0 - f_f)/f_f)
  - 問5: 操作3で除去された A の物質量(7.0×10^-3 mol)
  - 問6: 用いた塩酸の pH(2.6)
- その場で与えられた知識:
  - L1 ヘンリーの法則の P_A = H[A]max 形とヘンリー定数の温度依存。
  - **L2 吸収速度式 v_A = k([A]max - [A])**(式の提示)。「吸収液の単位表面積および単位時間あたりに吸収される A の物質量は次式で与えられる」とし、「その時点の P_A に対して溶解できる最大の濃度と、その時点での濃度との差に比例する。P_A が変化するので [A]max も時間とともに変化する」と補足。問2(い・う)と問3で必須。単位表面積あたりという定義を読み取り、液滴の表面積・個数と結びつける。
  - **L2 連続式吸収装置の定常状態と平衡関係 f_A = h g_A**(モデルの提示)。図1で流量 G, W とモル分率 f0, f_A, g_A を定義し、「継続すると f_A と g_A は一定となり変化しなくなった」「単位時間あたりに供給される A と排出される A の物質量が等しい」と説明。問1(オ)と問4で必須。
- 解法の核心・差がつく点: 問2は「体積一定で直径2倍 → 個数 1/8、1個の表面積4倍」。問3(i)は [A] が増えると P_A が下がり [A]max も直線的に下がるので右下がりの直線。問4は出口の液が出口の気体と平衡になるとき g_A が最大で W が最小。問6は最終溶液の電荷のつり合い [Cl-] = [AH+](pH 7 なので [H+] = [OH-])に気づけるか。
- 作問メモ: 化学工学の単位操作を題材に、未習の速度式と流通系の収支をその場で与える典型的な L2 型。1つの大問の中で、平衡(ヘンリー)→ 速度(式2)→ 連続操作(収支)→ 反応を伴う吸収(電離平衡)と、与えた道具を段階的に既習事項へ接続している。答えは選択肢・文字式・数値が混在し、読解量で難度を作る。

## 大問III(a)(有機/非等価な炭素原子の数による構造決定)

- 流れ: 2-メチルプロパンとシクロヘキセン(図1)を例に、「結合している原子と原子団が同じ炭素原子は化学的に等価」と定義し、非等価な炭素原子の種類の数が構造決定の重要な情報だと述べる。互いに構造異性体である化合物(あ)〜(お)の情報(元素分析、銀鏡反応、ヨードホルム反応、水素付加、ナトリウムとの反応、非等価炭素の数)を与える。
  - 問1: (あ)の分子式(C5H10O)
  - 問2: (あ)〜(お)の構造式
- その場で与えられた知識:
  - **L2 化学的に等価/非等価な炭素原子とその種類の数**(概念定義)。2つの例で数え方を示し、鎖状にも環状にも使えると説明。(う)は「水素付加で非等価な炭素の種類が1つ減る」、(え)(お)は「3種類」、(か)は「すべて等価」という条件として使われ、これなしでは構造が絞れない。13C NMR のシグナル数に相当する情報だが NMR の語は出ない。
  - L2 の中では軽い。定義は分子の対称性の確認にすぎず、新しい反応や式ではない。
- 解法の核心・差がつく点: (あ)(い)は同じ骨格のアルデヒドとメチルケトン。直鎖か枝分かれかは(う)の条件で決まる(3-メチル-3-ブテン-2-オールは5種→水素付加で4種)。(え)(お)は不飽和度1を環で使うことに気づく(テトラヒドロピラン、シクロペンタノール)。
- 作問メモ: 機器分析(NMR)のデータを、装置名を出さずに「数え方のルール」として定義し、従来の化学的手がかり(呈色・沈殿反応)と並べて構造決定に使わせる型。測定原理を教えずに、得られる情報の形だけを教える。

## 大問III(b)(有機/アルケンへの付加反応の立体化学)

- 流れ: Br2 の付加は2つの Br がアルケン平面をはさんで反対側から、白金触媒による H2 の付加は同じ側から起こると述べ、図2で一般式(R1〜R4)とくさび形表記の生成物、単結合を180°回転させた例を示す。図3はシス形・トランス形の 2-ペンテンへの臭素付加、図4は生成物から原料アルケンを予想する<考え方>の図解。
  - 問3: 図5のアルケン5種のうち、臭素付加で不斉炭素を2つもつ化合物を与えるもの((て)(に))
  - 問4: 水素付加で不斉炭素をもつ化合物を与えるもの((と))
  - 問5: 図3の生成物(さ)(す)の空欄ア〜エ(H、CH3、CH3、H)
  - 問6: 図4の(そ)の空欄オ〜キ(CH3、CH2CH3、CH3)
  - 問7: 原料アルケン(た)(つ)の構造式(シス-トランスを区別)
- その場で与えられた知識:
  - **L2 付加反応の立体化学(アンチ付加・シン付加)**(反応の提示)。名称は出さず、「反対側から付加する」「同じ側から付加する」と文章で述べ、図2で置換基の位置対応を示す。問5〜問7で必須。
  - L1 くさび形表記と C-C 単結合の回転による描き直し。図2の枠内と図4の<考え方>で図解。
  - 問3・問4は立体化学のルールを使わず、不斉炭素の有無の判定だけで解ける。
- 解法の核心・差がつく点: 図2を「アルケンの上側の置換基が破線、下側の置換基が太線に来る」という対応表として使う。問6は誘導どおり180°回転。(つ)は生成物の左側の炭素を自分で回して H を上に向ける必要があり(120°の回転に相当)、誘導がないので差がつく。
- 作問メモ: 範囲外の反応ルールを一般式の図で与え、(1) 具体例への順方向の適用、(2) 手順を図解した逆方向の推論、(3) 誘導なしの逆方向、と段階的に自立させる型。立体配置を空欄の置換基で答えさせ、採点を容易にしている。
- 注: スキャン画像のため、図4(ち)の太線・破線の区別は図2・図3との整合から判断した。

## 大問IV(a)(高分子(天然)/グラミシジン S の組成決定)

- 流れ: 鎖状ペンタペプチド(図1)で N 末端残基・C 末端残基を定義し、両端がつながった環状ペプチド(図2)を説明。グラミシジン S は5種のアミノ酸 A1〜A5 からなるペンタペプチドが2つ結合した環状デカペプチド(図3)。構成アミノ酸はバリン、ロイシン、フェニルアラニン、プロリン(構造と分子量は図4)と未知のアミノ酸 X。実験1(加水分解)、実験2(窒素定量)、実験3(ニンヒドリン陽性)。
  - 問1: 条件を満たすアミノ酸配列の数(24通り)
  - 問2: 加水分解で消費される水の質量(10.8 mg)
  - 問3: グラミシジン S の分子量(1140)
  - 問4: X の分子量(132)
  - 問5: X の窒素原子数(2)
  - 問6: X の構造(側鎖 -CH2CH2CH2NH2)
- その場で与えられた知識:
  - L1 環状ペプチド(末端をもたない)。図1・図2で説明。構造の説明にとどまり、新しい式や反応はない。
- 解法の核心・差がつく点: 環状なのでペプチド結合は10個、加水分解に水10分子。問1は向きを区別した円順列。問6は実験3(末端がないのにニンヒドリン陽性)から側鎖に -NH2 があると読む。
- 作問メモ: 実在の天然物(抗生物質)を題材に、既習の量的関係を「環状」という一ひねりで問い直す型。未知アミノ酸を分子量・窒素数・呈色反応から組み立てさせる点は 2023年度 IV と共通。

## 大問IV(b)(高分子(天然)/アミノ酸配列の決定)

- 流れ: A1〜A5 を使った3種の鎖状トリペプチド P1(A5-A3-A4)、P2(A4-A1-A5)、P3(A3-A2-A1)を分子量の大きい順に並べる。実験4(ニンヒドリン: P2・P3 のみ陽性)、実験5(キサントプロテイン: P1・P2 のみ陽性)。
  - 問7: A1〜A5 の決定(A1=バリン、A2=X、A3=ロイシン、A4=フェニルアラニン、A5=プロリン)
- その場で与えられた知識:
  - L1 ニンヒドリン反応の紫色呈色には遊離の -NH2 が必要で、N 末端がプロリンのペプチドは呈色しない。問題文は説明せず、図4のプロリンの構造から受験生が推論する。
- 解法の核心・差がつく点: P1 だけがニンヒドリン陰性 → N 末端 A5 がプロリンで、P1 に X がない。ここに気づけば、あとはキサントプロテイン反応と分子量の不等式(A3 > A1、A2 + A3 < 280)で一意に決まる。
- 作問メモ: 配列を記号のまま与え、呈色反応の陽性・陰性と分子量の順序だけで割り当てを決めさせる論理パズル型。教科書知識(ニンヒドリンはアミノ基の検出)を、例外的な構造(プロリン)に当てはめて推論させる点が鍵で、「教えない」ことで難度を作っている。
