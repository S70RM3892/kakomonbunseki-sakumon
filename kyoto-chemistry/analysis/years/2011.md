## 大問I(理論+無機/鉄の酸化物と不定比化合物、Fe(OH)3 の溶解度積)

### (a) 最大レベル L2・標準

- 流れ: 鉄の酸化物 A(赤鉄鉱 Fe2O3)、B(モル質量232、Fe3O4)、C(Fe(1-x)O)を紹介。C は NaCl 型だが鉄原子の一部が欠損(原子空孔)し、x は連続的に変化、電気的中性は保たれ、欠損により格子定数 a が減少する、と説明。最後に製鉄に触れる。
  - 問1: Fe の酸化数(+3, +2)
  - 問2: B の組成式(Fe3O4)
  - 問3: Fe3+ : Fe2+ = 2 : 1
  - 問4: 定比例の法則
  - 問5: O が 23.0% のときの x(≈0.043)
  - 問6: x=0.060, 0.080 の a から直線外挿して x=0 の FeO の密度(a=4.33×10^-8 cm、≈5.9 g/cm3)
  - 問7: a が変化する別の原因を鉄の酸化数に着目して論述(中性を保つため一部が Fe3+ になり、イオンが小さくなる)
  - 問8: Fe2O3 + 3CO → 2Fe + 3CO2
- その場で与えられた知識:
  - **L2 原子空孔をもつ不定比化合物(概念定義)**: 「結晶中の鉄原子の一部が欠損している。原子が欠損した部分を原子空孔とよぶ」と図2で定義し、x の連続変化、電気的中性の保持、a の減少とその原因(配列のゆがみ、格子間位置への移動)を説明。問5〜7 で使用。問7 は本文の「電気的中性」を手がかりに Fe3+ の生成を自分で推論させる。
  - L1 定比例の法則に従わない化合物(問4 の空欄の文脈)。
- 解法の核心・差がつく点: 問6 の「直線的に変化すると仮定」を外挿として処理できるか。問7 で x>0 なら電荷の埋め合わせに Fe3+ が必要、と本文の一文から引き出せるか。
- 判定メモ: 計算道具は既習(組成・密度)なので L2 としては軽い。L1 との境界。
- 作問メモ: 「教科書の理想結晶 → 現実の結晶は欠陥をもつ」と1段ずらし、(1) 組成計算 (2) 実測データの外挿 (3) 本文に埋めたヒントからの原因論述、の3点セットにする型。

### (b) L0・標準

- 流れ: 鉄を 0.10 mol/L 硫酸 150 mL に溶かし(H2 22.4 mL)、酸化して Fe3+ とし、NaOH 水溶液 50.0 mL を加えたところで Fe(OH)3 が沈殿しはじめる。
  - 問9: 鉄の質量(0.056 g)
  - 問10: 沈殿開始の pH(導出要求。[Fe3+]=5.0×10^-3、[OH-]^3=2×10^-36、pH=2.1)
- その場で与えられた知識: なし。
- 差がつく点: NaOH の濃度が与えられていないことに惑わされず、体積 200 mL と Ksp だけで決まると見抜く。
- 作問メモ: 「不要に見える/足りなく見えるデータ」を置き、Ksp の条件式だけで閉じることを見抜かせる小問。

## 大問II(理論/吸着平衡:ラングミュア吸着式と表面積測定)

### (a) 最大レベル L2・標準

- 流れ: 多孔質物質の表面に吸着点が N0 個あり、各点は1分子だけ吸着、相互作用なし、と仮定。吸着速度 ra は P と空き吸着点数に比例、脱離速度 rd は吸着分子数に比例。平衡で ra=rd、K=ka/kd。
  - 問1 ア: N0−N、イ: N、ウ: N = N0KP/(1+KP)
  - 問1 エ: 傾き 1/N0、オ: 切片 1/(KN0)、カ: P2/N2 − P1/N1
- その場で与えられた知識:
  - **L2 ラングミュア型単分子層吸着モデル(モデルの提示)**: 仮定(吸着点、1点1分子、相互作用なし)を文章で列挙し、速度式を空欄つきで誘導。名称は出さない。ア〜ウで必須。
  - **L2 吸着等温式の線形化(式の提示)**: 「P/N を P の関数と考えると図1のような直線関係」と図示し、傾き・切片と2点から N0 を出す式を作らせる。エ〜カおよび (b) 問4 で必須。
- 解法の核心: 反応速度と化学平衡(正反応速度=逆反応速度)の考え方を吸着に移す。式(3)を P/N = P/N0 + 1/(KN0) に変形。
- 作問メモ: 「大学の式を、高校の速度論の言葉で仮定から誘導させる」型。空欄は 速度式 → 平衡式 → 線形化 → 2点法 と一本道で、最後の式が (b) の道具になる。

### (b) 最大レベル L2・やや難

- 流れ: 容器I(試料入り)と容器II(50 mL)を弁でつないだ装置(図2)。100 K。実験1: He を II に入れ(1.5×10^4 Pa)弁を開く(1.0×10^4 Pa)。実験2: N2 で同様(1.7×10^4 → 0.80×10^4 Pa)。実験3: 減圧して 0.16×10^4 Pa、吸着量が 2.0×10^-4 mol 減少。
  - 問2: 有効体積(25 mL)
  - 問3: 0.80×10^4 Pa での吸着量(3.0×10^-4 mol)
  - 問4: 1 g あたりの表面積(N0=6.0×10^-4 mol → 約 7.2×10^2 m2/g)
- その場で与えられた知識:
  - **L2 定容法によるガス吸着量測定(実験手法の提示)**: 「試料の体積を除いた容器Iの体積(有効体積)」を定義し、He は吸着されず N2 は (3) 式に従って吸着されると明示。問2〜4 の全体で必須。
- 解法の核心: He の実験は体積決定、N2 の実験は「導入量 − 気相残量 = 吸着量」。実験3 から2点目 (P2, N2)=(0.16×10^4, 1.0×10^-4) を作り、(a) のカの式に代入。
- 作問メモ: (a) 理論式の導出 → (b) その式を使う測定実験、という二段構成。実験を「較正(He)→ 本測定 → 2点目の取得」と役割分担させ、各実験の意味を読み取らせる。

## 大問III(有機/C9H10 芳香族炭化水素と不飽和エステルの構造決定)

### (a) 最大レベル L1・標準

- 流れ: 環を1つだけもつ C9H10 の A〜E に水素付加すると F, G, H。A, B, C → F(B と C は幾何異性体)、D → G(フェノールの工業的製法に利用=クメン)、E → H。E を酸化すると I とギ酸、I を空気酸化すると PET 原料 J。J は K(C10H14O2)のヨードホルム反応でも得られる。J の異性体 L を加熱すると M(C8H4O3)、M とアニリンで N(C14H11NO3)。
  - 問1: A〜E 以外の該当化合物の数(2: o-, m-メチルスチレン)
  - 問2: G(クメン)、M(無水フタル酸)
  - 問3: A(アリルベンゼン)、E(p-メチルスチレン)、K(p-C6H4(CH(OH)CH3)2)、N(フタル酸モノアニリド)
- その場で与えられた知識:
  - L1 C=C の酸化開裂(ビニル基 → COOH + ギ酸)。結果だけ記述。
  - L1 酸無水物+アニリンの開環(分子式から判断)。
- 差がつく点: 異性体の漏れのない数え上げ、K をジケトンではなく二価アルコールと決める分子式の確認。
- 作問メモ: 「水素付加後の骨格が何種類に集約されるか」で側鎖骨格を分類させ、工業的に有名な化合物(クメン、テレフタル酸、無水フタル酸)をアンカーにする型。

### (b) L0・やや難

- 流れ: エステル O を加水分解して芳香族カルボン酸 P(C12H14O2)とアルコール Q(C4H8O)を得るが途中で止まり、混合物 25.0 g。水素 4.48 L を消費。P は不斉炭素1つ、水素化物 R は不斉炭素なしでパラ二置換。Q の水素化物 S は分枝型で、酸化すると銀鏡反応陽性の T。
  - 問4: 用いた O の物質量(0.10 mol)
  - 問5: 加水分解率(33%)
  - 問6: P に関する正誤(正しいのは ア, エ)
  - 問7: P = p-HOOC-C6H4-CH(C2H5)CH=CH2、Q = CH2=C(CH3)CH2OH
- その場で与えられた知識: なし。
- 解法の核心: C=C の総数は加水分解の進行によらない(O 1分子に2個)ので H2 量から O の仕込み量が決まり、質量の増分 0.6 g が付加した水。
- 読み取りメモ: P の分子式の H の添字がスキャンでかすれている。条件との整合から C12H14O2 と読んだ。
- 作問メモ: 「反応が途中で止まった混合物」に対し、進行度によらない保存量(不飽和結合数)と進行度に比例する量(質量増)を1つずつ与えて連立させる型。

## 大問IV(天然高分子/ホモガラクツロナン、アミロースの酵素分解)

### (a) 最大レベル L1・標準

- 流れ: ホモガラクツロナンはガラクツロン酸が α1,4 結合した多糖。ガラクトースはグルコースの4位 OH が逆向き、その6位が COOH になったものがガラクツロン酸、と定義。
  - 問1: 繰り返し単位を8つの構造式から選択
  - 問2: COOH の20%がメチルエステル、残りの50%が電離(pH 4.2)。pH 6.0 にしたときの変化を表から選択(エステルは増減なし、電離型増加、非電離型減少)
- その場で与えられた知識: L1 ガラクツロン酸の構造定義(文章のみ)。
- 差がつく点: グルコースのハース式の正確な記憶と、α1,4 結合で隣の環が反転して描かれる表記の読み取り。
- 読み取りメモ: 問1 の選択肢は細部まで照合していないため正答記号は未確定。
- 作問メモ: 「既習の糖構造 + 文章による差分定義(○位の向きが逆、○位が COOH)」で未習糖を作り、構造式の選択で立体の理解を試す型。

### (b) 最大レベル L1・やや難

- 流れ: 実験材料(アミロース、α-アミラーゼ、β-アミラーゼ、セロハン膜、フェーリング液)を定義つきで列挙。実験1: アミロース x g を水 100 mL に溶かし浸透圧測定(1500 Pa、27 ℃、密度 1.028)、α-アミラーゼで完全にマルトース化し、凝固点降下(0.310 K)。実験2: β-アミラーゼで1時間処理後、透析し外液 20.0 mL のフェーリング反応(沈殿 1.60×10^-4 mol)。
  - 問3: アミロースの質量(約 8.10 g)
  - 問4: 平均分子量(約 1.28×10^5)
  - 問5: 平均重合度(約 790)
  - 問6: (i) 塩析 (ii) 硫酸アンモニウムの作用(35字)
  - 問7: Cu2O
  - 問8: β-アミラーゼによるグルコース数の減少率(約 29%)
- その場で与えられた知識: L1 α-/β-アミラーゼの切断様式(材料欄で定義)。
- 解法の核心: 凝固点降下 → マルトースの物質量 → グルコース単位の総量 → 質量。浸透圧 → 分子の個数。両者の比が重合度。問8 は透析で拡散したマルトースを全体積に換算。
- 注意: 溶媒量や透析後の全体積の取り方で数値が動く。上の値は自分の概算。
- 作問メモ: 「同じ試料を、粒子数を測る方法(浸透圧)と単位数を測る方法(完全分解後の凝固点降下)の2通りで測り、比から重合度」を出す型。実験操作を箇条書きで与え、各操作の目的(熱処理=酵素失活、透析=低分子の分離)を読み取らせる。
