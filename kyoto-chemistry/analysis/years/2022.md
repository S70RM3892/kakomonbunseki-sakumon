# 京大化学 2022年度

## 全体

- 冊子 17〜38 ページ(24、34 ページは白紙)。4題100点。全大問が (a)(b) の2パート構成(計8パート)。
- 前半(I(a)、II、III)は溶解度・分配平衡・浸透圧・アミド化など既習〜受験定番を丁寧な誘導で運用させる。
- **L2 は 3 パートに出現: I(b)(HCrO4- を含む三者平衡と優勢領域図)、IV(a)(フィッシャー投影式、エンジオール中間体による異性化)、IV(b)(反応剤 X による酸化的 C–C 切断規則、メチルグリコシド)。**
- L2 の与え方は「名称や機構は伏せ、規約・ルールを図と1〜3文で示す」形。IV(b) はルール表の逐次適用と逆推定が問題の本体。
- 最高レベル: I(a) L1 / I(b) L2 / II(a) L1 / II(b) L0 / III(a) L1 / III(b) L1 / IV(a) L2 / IV(b) L2

## 大問I(無機・理論/2族水酸化物の水和物、クロム酸の平衡)

### (a) 2族元素の水酸化物と質量減少分析

- 流れ: 2族元素の一般論(空欄ア〜エ)。表1に Ca(OH)2、Sr(OH)2、Ba(OH)2 の 20℃・80℃ の溶解度。80℃ の水 100 g に各 5.0 g を加え 20℃ に冷却、沈殿を乾燥して質量測定。沈殿のうち2つは n 水和物(式(1))。昇温時の質量減少曲線(図1 A〜C、減少率が数値で記入)。
  - 問1: ア(高く)、イ(大きい)、ウ(アルカリ土類金属)、エ(H2)
  - 問2: 図1 (A)〜(C) と元素の対応(B–Ca、A–Sr、C–Ba)
  - 問3: オ(4.8 g)、カ(9.2 g)
- その場で与えられた知識:
  - [L1] 昇温質量減少分析(熱重量分析): 「温度を一定速度で上げて質量変化を測る。水和水が一段階で脱水、さらに無水物が一段階で酸化物と水に分解。減少分から n が求まる」と仮定込みで説明。水和物の加熱減量は受験定番なので L1。
  - [L1] 水和物として析出する場合の溶解度計算: 式(1)のみ。計算法は自力(硫酸銅五水和物と同型)。
- 解法の核心・差がつく点: 一段のみ 24.3% 減=18/74 → Ca(OH)2 は無水。二段目の減少率=18/(水和物の式量)から式量 266(Sr、n=8)、315(Ba、n=8)。カは析出物が水を持ち去る方程式。与えられた 2.3 g(Ba)で検算できる。
- 作問メモ: 「溶解度表だけでは答が合わない → 水和物だった」という矛盾提示から、別の測定データで n を決めて再計算させる型。グラフに数値を書き込み、読取り誤差ではなく解釈で差をつける。

### (b) クロム酸塩の製造とクロム酸の平衡図

- 流れ: クロム鉱石 FeCr2O4 を O2・Na2CO3 と加熱して Na2CrO4 と Fe2O3 にする(下線部)。pH2 以上での平衡(式(2)〜(5)、K1、K2)。[Cr]TOTAL の定義と式(6)。pH–log[Cr]TOTAL の図2(線 A、B、C と3領域、交点 D)。
  - 問4: 下線部の化学反応式(4FeCr2O4 + 8Na2CO3 + 7O2 → 8Na2CrO4 + 2Fe2O3 + 8CO2)
  - 問5: キ(1)、ク([H+])、ケ(2K2[H+]^2)
  - 問6: コ(1.3×10^-6)、サ(1.7×10^-2)、シ(2.6×10^-14 mol^3/L^3、単位つき)、ス(6.7×10^-2)
- その場で与えられた知識:
  - [L2] HCrO4- を介する段階的平衡: 「クロム酸は式(2)のように完全に電離する。生じた HCrO4- はさらに式(3)のように一部が電離し CrO4^2- を生じる。また HCrO4- は式(4)に従って一部が Cr2O7^2- になる」と式・平衡定数つきで提示。教科書にあるのは式(5)だけ。問5・問6すべての前提。
  - [L2] 優勢領域図: 「各領域に表示されたイオンが最も多く存在する。線 A は HCrO4- と CrO4^2- が、線 B は HCrO4- と Cr2O7^2- が、線 C は CrO4^2- と Cr2O7^2- が同じ濃度になる線」と読み方を定義。問6では、この定義(等濃度)を K1、K2 の式に代入して各線上の濃度を出す。
  - [L1] クロム鉄鉱の酸化焙焼: 反応物と主生成物を言葉で与え、CO2 は自分で補って係数を合わせる。
- 解法の核心・差がつく点: Cr 原子基準の収支で Cr2O7^2- を2倍すること。線 B 上では K2[HCrO4-]^2=[HCrO4-] から 1/K2。点 D では3種がすべて 1/K2 なので [Cr]TOTAL=4/K2。シの単位(mol^3/L^3)。
- 作問メモ: 「教科書の1本の平衡式を、中間種を入れた複数の平衡に分解 → 物質収支式 → 見慣れない領域図の境界線を『2種が等濃度』と定義して数値化」という型。図の読み方さえ教えれば計算は質量作用の法則だけで済むよう設計されている(L2 だが適用の計算負荷は軽い)。

## 大問II(理論/分配平衡、浸透圧)

### (a) 弱酸のトルエン–水間分配

- 流れ: 分配係数 P の定義(図1)。弱酸 HA(Ka=2.5×10^-5)は水層で電離、トルエン層で二量化(Kc)。pH4.0 の緩衝液 0.10 L とトルエン 0.10 L で分配し、トルエン層の HA 量 a、水層の HA+A- の総量 b を測る(下線部)。仮定の列挙と式(3)〜(5)の誘導。
  - 問1: トルエンを蒸発させた残留物 m g から b を表す(b = n - m/M)
  - 問2: ア(0.25)、イ(Kc[HA]t^2)、ウ(([HA]t + 2Kc[HA]t^2)/(1.25[HA]w))、エ(1.6)、オ(80)、カ(13)
  - 問3: 図2(b と a/b の3点)から P_HA(切片 1.5 → 1.9)
  - 問4: 緩衝液を純水に替えた場合の キ(電離度は小さくなる)、ク(会合度は大きくなる)、ケ(a/b は大きくなる)
- その場で与えられた知識:
  - [L1] 分配係数: 冒頭で定義。受験定番。
  - [L1] 無極性溶媒中の二量化平衡と会合度: 式(2)と仮定を明示。会合度は問4で定義。
- 解法の核心・差がつく点: a は単量体換算(二量体×2)。pH 固定なので [A-]/[HA] が一定 → b の 80% が HA。a/b が b の一次式になり、切片が 0.8P。
- 作問メモ: 「単純な分配則が成り立たない状況(相ごとに化学種が違う)を、各相の平衡を足して線形関係に落とし、グラフの切片・傾きから定数を取り出す」型。最後に条件(緩衝液→純水)を変えて定性的に問う。

### (b) U字管と浸透圧

- 流れ: 断面積 4.0 cm^2 の U 字管、NaCl 水溶液 100 mL と純水 100 mL、液面差 5.0 cm(図3)。
  - 問5: 移動した水の体積(10 cm^3)
  - 問6: 元の濃度 x(1.1×10^-4 mol/L)
  - 問7: (i) 温度を上げる(長くなる)、(ii) 断面積を大きくする(短くなる)、(iii) 両側にショ糖を等量追加(短くなる)
- その場で与えられた知識: なし(L0)。
- 解法の核心・差がつく点: 流入による希釈(110 mL)と NaCl の電離。問7は平衡後の濃度変化まで考えるかどうか。
- 作問メモ: 定番設定に「条件を1つだけ変えたらどうなるか」の3択を付け、希釈効果の理解を問う。

## 大問III(有機/酸クロリドとアミンによるアミド)

### (a) アミンと酸クロリドの構造決定

- 流れ: アラミド繊維の合成(図1)から酸クロリド・第一級アミンを定義し、一般反応(図2)を提示。アミン A、B、C と酸クロリド D の情報(あ)〜(う)。
  - 問1: ア(アラミド)、イ(HCl)
  - 問2: A(アニリン)、D(塩化アセチル)
  - 問3: B として考えられる構造すべて(プロピルアミン、イソプロピルアミン)
  - 問4: C(C6H5–CH(NH2)–COOCH3)
- その場で与えられた知識:
  - [L1] 酸クロリド+第一級アミン → アミド+HCl: 用語を定義し図2に一般式。教科書でも界面重合で登場する反応。
- 解法の核心・差がつく点: C は「酢酸・メタノール・ベンゼン環をもつアミノ酸」に分解されるアミドの元のアミン=アミノ酸メチルエステル。不斉炭素1個の条件で一意。
- 作問メモ: 高分子の反応(縮合重合)を低分子の一般反応に読み替えさせ、構造決定パズルにする型。

### (b) 酸ジクロリドからのジアミド

- 流れ: アミン F と酸ジクロリド G → ジアミド H(C8H16N2O2)→ 部分加水分解で F と I → フェノールとエステル化して J(C12H15NO3)。F、G、H は不斉炭素なし、I、J は1個。
  - 問5: F(エチルアミン)、G(ClCO–CH(CH3)–COCl)
  - 問6: J(C6H5O–CO–CH(CH3)–CO–NH–C2H5)
- その場で与えられた知識:
  - [L1] 酸ジクロリドの定義((a)の拡張)。
- 解法の核心・差がつく点: 分子式の逆算(J → I=C6H11NO3 → F=C2H7N)と、「対称な H では不斉でない炭素が、片側だけ変換すると不斉になる」ことへの気づき。
- 作問メモ: 「対称分子の片側だけを変換して不斉を生む」ことを構造決定の鍵にする型。情報は分子式と不斉炭素の数だけで短い。

## 大問IV(高分子(天然)/糖の立体化学と酸化的開裂)

### (a) 投影式・異性化・二糖

- 流れ: 説明文でアルドースの一般式、L-グリセルアルデヒドのくさび表記と投影式(図1)。グルコースをアルカリ処理するとエンジオール中間体を経てグルコース・アルドース A・フルクトースの平衡混合物(図2)。
  - 問1: 炭素数4のアルドースが五員環をつくったときの異性体の数(鏡像異性体を区別。8)
  - 問2: アルドース A の鎖状構造を図1(iii)の表記で(C2 の −OH が左のマンノース)
  - 問3: 二糖 B、C、D を図3(ア)〜(オ)から選ぶ(還元性、構成糖がアルドース/ケトース、D は2種のアルドースが1箇所の −OH の立体だけ異なる)。自分の読取りでは B=(オ)、C=(ア)、D=(ウ)
- その場で与えられた知識:
  - [L2] フィッシャー投影式: 「左右方向の結合は紙面の手前側に向かう結合を、上下方向の結合は紙面の奥側に向かう結合を示す」と規約を1文で説明(名称は出さない)。問2の答案はこの表記で書く。
  - [L2] エンジオール中間体を介するアルカリ異性化: 1文と図2で提示。中間体で C2 の立体が消えることから A を推論させる(問2)。
  - [L1] アルドースの一般式と四炭糖の環化。
- 解法の核心・差がつく点: エンジオールでは C1=C2 が二重結合で C2 の立体情報が失われる → 戻ると C2 エピマーも生じる。問1は環化で C1 が不斉になることを含め 2^3。問3は還元末端(ヘミアセタール/ヘミケタールの OH)が残るかどうかで仕分け。
- 作問メモ: 「未習の立体表記の規約を教え、反応中間体の図から『どこの立体が失われるか』を読ませ、その表記で答えさせる」型。規約の導入→即適用が短い手数で完結する。
- 読取り上の注意: 図3のハース式は解像度の制約で各 OH の上下を完全には確認できていない(結合位置・環の大きさ・還元末端の有無・ガラクトース型の判別は可能)。

### (b) 反応剤 X による酸化的切断

- 流れ: 反応剤 X は図4の網かけ部分構造(隣接ジオール、α-ヒドロキシアルデヒド、ジアルデヒド、α-ヒドロキシケトンなど6パターン)がある場合にのみ C–C 結合を切断し、生成物に同じ部分構造があれば切断が続く。例: L-グリセルアルデヒド 1 mol → ギ酸 2 mol + ホルムアルデヒド 1 mol。メチル β-グルコシド E(図5)は X で F と G(F の分子量が大)を与える。環構造をとる五炭糖アルドース H のメチル β-グリコシド I は F のみを与える。
  - 問4: グルコース・フルクトース(鎖状構造で考える)の最終生成物の構造式と物質量比(グルコース: HCOOH : HCHO = 5 : 1、フルクトース: HCOOH : HCHO : CO2 = 3 : 2 : 1)
  - 問5: G の構造式(ギ酸)
  - 問6: β型の I として考えられる構造をすべて(フラノシドで C2・C3 の OH の向きが異なる4種)
- その場で与えられた知識:
  - [L2] 反応剤 X の切断規則: 本文と図4の6つの一般式で提示。「網かけ部分構造が存在する場合にのみ C–C 結合の切断が起こる。生成物に網かけ部分構造が含まれる場合にはさらに続けて切断が起こる」。問4〜問6すべてで使用、これなしでは解けない。
  - [L2] メチルグリコシド(非還元糖): 「β型グルコースの C1 の −OH が −OCH3 に置き換わった化合物 E は β型の非還元糖」と図5で提示。開環しないので環内の隣接ジオールだけが切れることは規則から自分で導く。
- 解法の核心・差がつく点: 鎖状糖では CHO と CHOH がギ酸、CH2OH がホルムアルデヒド、ケトンの炭素が CO2。E では C2–C3 と C3–C4 が切れ C3 がギ酸として抜ける。I が「F のみ」=ギ酸が出ない → 隣接ジオールが1組だけ → 五員環(C1–O–C4)。F に残る不斉は C1 と C4(E の C5 に対応)だけなので C2・C3 は自由 → 4種。
- 作問メモ: 「試薬名・機構を伏せ、部分構造→生成物のルール表だけを与える」→「鎖状分子への逐次適用(量比の数え上げ)」→「環状分子への適用」→「生成物から構造を逆推定」と段階的に難度を上げる型。その場学習型の典型で、作問の雛形として使いやすい。
- 補足: 問6の「4種」は自分で解いた結果で、公式解答との照合はしていない。
