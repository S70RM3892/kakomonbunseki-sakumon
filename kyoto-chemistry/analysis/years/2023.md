- **L2 はゼロ。** I(b)・II・III が L1、I(a)・IV が L0。範囲外の式・反応・測定法をその場で教えて使わせる問題は、この年度にはない。
- 負荷の作り方は2通り。(1) II: 準範囲外の法則(ラウールの法則)を1文で与え、あとは文字式の導出を受験生に積ませる。(2) III: 未習の骨格(ピリジン)を定義し、「ベンゼン環と同様に反応する」と約束して既習反応を転用させる。
- 解答形式は空欄補充と構造式が大半。論述・導出過程要求はない。

## 大問I(a)(理論/黒鉛とグラフェンの密度・比表面積)

- 流れ: 黒鉛の層状構造、グラフェン、活性炭の微細構造を紹介。図1に正六角形の面積(5.1×10^-16 cm^2)と層3枚にわたる距離(6.7×10^-8 cm)を示す。
  - 問1 ア: 層間に働く力(ファンデルワールス力)
  - 問2: 黒鉛の密度(約 2.3 g/cm^3)
  - 問3: グラフェン3層からなる薄片の単位質量あたりの表面積(約 8.5×10^6 cm^2/g)
- その場で与えられた知識: なし(L0)。グラフェン・比表面積は題材であり、解くのに使うのは原子の数え上げと単位計算だけ。
- 解法の核心・差がつく点: 正六角形1個に炭素原子は2個(各頂点を3つの六角形が共有)。図の 6.7×10^-8 cm は層間隔2つ分。問3は露出面が表裏の2面だけで、原子は3層分あることに注意。
- 作問メモ: 単位格子を明示せず、「繰り返しの最小単位を自分で切り出す」ことを求める結晶計算。先端材料(グラフェン、活性炭)を題材にしつつ、中身は数え上げに絞る型。

## 大問I(b)(理論・無機/溶鉱炉内の化学平衡)

- 流れ: 溶鉱炉でのコークスの役割と、Fe2O3 → Fe3O4 → FeO → Fe の逐次還元(反応(1)〜(3))、C + CO2 ⇄ 2CO(反応(4))を空欄付きで示す。後半は 939 K・全圧 100 kPa、気体が CO・CO2・N2 のみとして、反応(3)(Kp=1.0)と反応(4)(Kp=42 kPa)がともに右に進む条件を CO・N2 のモル分率 x, y の不等式で表す。
  - 問4: イ=CO、ウ=Fe3O4、エ=CO2 と係数 a〜j
  - 問5: オ・カ(y > 1-2x)、キ・ク(y < 1-x-(50/21)x^2)
  - 問6: ケ(0.16)。y がこれ以下だと両反応がともに右に進む組成が存在しない
- その場で与えられた知識:
  - L1 反応商と圧平衡定数の大小による反応方向の判定。問題文は説明せず、不等号を選ばせる空欄にしている。受験定番の知識として前提にされている。
- 解法の核心・差がつく点: CO2 のモル分率を 1-x-y と置くこと、固体は平衡定数の式に入らないこと。2つの不等式が両立するのは x < 0.42 のときで、そのとき y > 1-2x > 0.16。「N2 が少なすぎると成り立たない」という結論を式から読む最後の一歩で差がつく。
- 作問メモ: 教科書の工業的製法(無機)を入口に、同じ装置内の競合する2平衡を「運転条件の制約」として定量化する型。2変数の不等式領域の存在条件を問うのが新味。

## 大問II(理論/揮発性2成分混合溶液の気液平衡)

- 流れ: 蒸気圧降下とラウールの法則(名称なし)を文章で与え、揮発性の2成分 A, C の混合溶液に拡張。図1は全蒸気圧が x_C の一次関数であること、図2は隔壁で容積を変えられる容器を示す。状態 I〜III を順につくり、圧力や組成を文字式で表す。
  - 問1 ア: 蒸気圧降下
  - 問2 イ〜エ: P_A x_C、(1-x_C)、x_C
  - 問3(状態 I: 一部蒸発して平衡): オ=P_C、カ=P1-P_A
  - 問4(状態 II: すべて気体になった瞬間): キ=P_A P_C、ク=P_C-P_A
  - 問5(状態 III: 気液共存、n_L=n_G): ケ=y_C3-x_C0、コ=2x_C0-1
- その場で与えられた知識:
  - L1 ラウールの法則。「P_A と希薄溶液の蒸気圧の差は、P_A と B のモル分率の積に等しいという関係式が知られている」と文章で提示。
  - L1 2成分とも揮発性の混合溶液への拡張(理想溶液)。「組み合わせによっては x_C の大きさによらず上記の関係式が成立する」とし、図1から成分 C の蒸気圧も導かせる。
  - L1 気液の物質量比を組成から出す物質収支(てこの原理)。式(4)の形だけ与える。
  - L2 としなかった理由: 2成分系の気液平衡は大学の物理化学の内容だが、ラウールの法則は教科書発展・受験定番で、揮発性2成分への拡張も難関大向け問題集で定番。しかも問題文は新しい式を「教える」のではなく、既習の式から受験生に導かせている。
- 解法の核心・差がつく点: 液相の式 P = P_A(1-x) + P_C x と気相の式 yP = P_C x の2本ですべて解ける。状態 II は「気相組成=仕込み組成」と見抜けるか。状態 III は x + y = 2x_C0 から P3 の2次方程式を立て、与えられた解の形に合わせて整理する。計算量が多く、後半の完答は難しい。
- 作問メモ: 1文で与えた法則を、装置の操作(状態 I→II→III)に沿って適用範囲を広げていく型。答えの式の骨格(分母や根号の中身)を先に見せ、空欄だけ埋めさせることで、文字式の重い導出を採点可能にしている。

## 大問III(有機/ピリジン環をもつ化合物の構造決定)

- 流れ: ピリジンを「ベンゼンの C-H の1つが N に置き換わった化合物」と定義し、位置番号、構造式の等価性(図1)、同一化合物の描き方の例(図2)を示す。「炭化水素基は KMnO4 で酸化される」「置換基はベンゼン環上と同様に反応する」「環は反応で変化しない」と約束する。
  - 問1 ア: トルエンやスチレンの酸化生成物(安息香酸)
  - 問2: C7H9N でピリジン環をもつ構造異性体の数(9)
  - 問3: C7H7NO2 の異性体 A〜D と酸化生成物 E, F(オルト二置換ベンゼン、またはピリジンの3,5-二置換体)
  - 問4: C9H11NO2 の異性体 G〜I(一置換ベンゼン、またはピリジンの2-置換体)
- その場で与えられた知識:
  - L1 ピリジン環の定義・位置番号・等価性と、ベンゼン環と同様に扱う約束。問2〜問4で条件を読むのに必須。新しい反応や式は与えられておらず、使う化学は既習の芳香族の反応だけなので L2 とはしなかった(境界例)。
- 解法の核心・差がつく点: 分子式の差分からベンゼン系かピリジン系かを見分ける。F のエステルが C9H9NO4 → カルボキシ基2個 → ピリジン-3,5-ジカルボン酸、が突破口。D は 3-アセチル-5-ヒドロキシピリジン、I は乳酸とアニリンのアミド(不斉炭素1個)。ピリジン環はベンゼンより対称性が低いので、数え上げで重複・漏れが出やすい。
- 作問メモ: 未習の骨格を1つ定義し、「既習の環と同様に反応する」と約束して、既習の環の化合物と混在した異性体群を解かせる型。新しい反応を教えずに新規性を出せる。

## 大問IV(高分子(天然)/非天然アミノ酸を含むペプチドの構造決定)

- 流れ: アミノ酸の定義を確認し、α-アミノ酸(図1)とそれ以外のアミノ酸の例(図2: 3-アミノブタン酸)を示す。ジペプチド A(C7H12N2O5、不斉炭素1個)とトリペプチド B(分子量289)の加水分解、エステル化、電気泳動、窒素定量の情報を与える。
  - 問1: 図2の化合物の構造異性体となるアミノ酸の構造式すべて(4種)
  - 問2: X1(アミノマロン酸)、X2(2-アミノ酪酸)
  - 問3: ジペプチド A の構造
  - 問4 ア: Y2 の窒素の数(2)
  - 問5: Y1(β-アラニン)、Y2(2,4-ジアミノ酪酸)
- その場で与えられた知識: なし(L0)。α 以外のアミノ酸があり得ることの提示は定義の確認にとどまる。
- 解法の核心・差がつく点: 完全エステル化後の分子式からカルボキシ基の数を出す。A の不斉炭素が1個という条件から、アミノマロン酸は「アミノ基側」でペプチド結合していると決まる(カルボキシ基側で結合すると不斉炭素が2個になる)。Y2 は「COOH を H に換えると不斉が消える」から側鎖が -CH2CH2NH2 に絞られる。
- 作問メモ: 教科書の20種のアミノ酸の暗記を無効化し、分子式・官能基数・不斉炭素の有無という一般的な手がかりだけで未知のアミノ酸を組み立てさせる型。不斉炭素の数を「結合の向き」の決定に使うのが巧妙。
