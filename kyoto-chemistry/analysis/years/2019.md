# 京大化学 2019年度

## 全体

- 冊子 15〜32 ページ、大問4題・100点。全大問が (a)(b) の独立2部構成(計8パート)。
- 理論(I, II)は教科書〜準範囲内の題材を一工夫して出す形で、最大でも L1。
- 有機・高分子(III, IV)に L2 が集中: 「化学的に等価な炭素」「イミドの加水分解」「フィッシャー投影式+糖の酸化・減炭反応」。いずれも問題文が定義・図示し、それを道具にして構造を決めさせる。
- IV(b) は題材こそ新奇(バイオ由来高分子・糖脂質型界面活性剤)だが、既習知識だけで解ける。

## 大問I(a)(理論/モール法と溶解度積)

- 流れ: クロム酸カリウムを指示薬とする塩化物イオンの沈殿滴定を説明し、[Ag+] を横軸にした両対数グラフ(図1)で Cl- と CrO4 2- の濃度変化を示す。
  - 問1: 酸性で CrO4 2- が変化する反応式の生成物(Cr2O7 2- + H2O)
  - 問2: Ag2CrO4 が沈殿し始める [Ag+](6.0×10^-5)と、そのときの残存 [Cl-](3.0×10^-6)
  - 問3: 終点で [Ag+]=[Cl-] となるための滴定前の [CrO4 2-](2.0×10^-2 mol/L)
- その場で与えられた知識:
  - L1 モール法と終点の考え方(教科書本文〜発展)。終点で [Ag+]=[Cl-] なら正確、という条件は本文が与える。
- 解法の核心・差がつく点: Ksp の割り算だけ。問3の「指示薬濃度を変えると終点が動く」という趣旨を読み取れるか。
- 作問メモ: 定番の滴定を「ある量を横軸にとったグラフ」で再表現し、最後に「理想的な終点になる条件」を逆算させる型。

## 大問I(b)(理論/銀イオン濃淡電池)

- 流れ: AgCl 飽和+KCl の液 A と AgBr 飽和+KBr の液 B に銀電極を浸して塩橋でつなぐ。
  - 問4: 各液の [Ag+](1.8×10^-7、5.4×10^-10)、電流が止まったときの [Br-](6.0×10^-6)
  - 問5: A 側の反応の種類(還元)、電流の向き(A→B)、AgCl の量(減少)
- その場で与えられた知識:
  - L1 濃淡電池。「濃度差を小さくするように反応が進行」と原理を文章で与える。定量式(ネルンスト式)は出ない。受験定番のため L1 としたが、原理をその場で与えて使わせる構造ではある(L2 寄り)。
- 解法の核心・差がつく点: 電流が止まる=両液の [Ag+] が等しい、と読み替える。A 側では Ag+ が減る分 AgCl が溶けて [Cl-] が増える、という沈殿との連動。
- 作問メモ: 「難溶性塩の溶解平衡でイオン濃度を固定した溶液」×「濃淡電池」。平衡定数2つを電池の停止条件でつなぐ型。

## 大問II(a)(理論/電子対反発則と分子の形)

- 流れ: 電子式と、電子対の反発が最小になる配置という規則を述べ、表1(直線形・折れ線形・正四面体形・三角錐形)を完成させる。
  - 問1: 共有/非共有、CO2・H2O・NH3 と電子対の組数(空欄10個)
  - 問2: NO2+ の電子式と形(直線形)
- その場で与えられた知識:
  - L1 電子対反発則(現行教科書で発展・参考扱い)。規則は下線部①②として明文化される。
- 解法の核心・差がつく点: ほぼ知識で埋まる。NO2+ は CO2 と等電子。
- 作問メモ: 既知の分子で規則を確認 → 未知のイオンに適用、という2段構え。易しい導入パート。

## 大問II(b)(理論/Kc・Kp・Kx と容器連結)

- 流れ: A ⇄ 2B について3種の平衡定数の関係を導き、容器1(V1)で xA=xB となる条件、コックを開いて体積 3V1 にしたあとの A の物質量を求める。
  - 問3: Kc の式、Kp=KcRT、Kx=Kp/p
  - 問4: Kx=1/2、全圧は Kp の2倍
  - 問5: A の物質量は 0.75 倍(導出過程要求)
- その場で与えられた知識:
  - L1 モル分率平衡定数 Kx。式(5)で定義。教科書にない量だが Kp の単純な書き換えなので L1 に倒した(広めに取るなら L2)。
- 解法の核心・差がつく点: 問5 を物質量で立式(B 換算の保存+Kc)し二次方程式を解く。
- 作問メモ: 「定義式を1つ追加 → 条件が簡単になる特別な点(xA=xB)を設定 → 体積変化後の再平衡」という平衡計算の型。

## 大問III(a)(有機/C9H12 異性体と等価な炭素)

- 流れ: ベンゼンと o-キシレンを例に「化学的に等価/非等価な炭素原子」を説明し、C9H12 の芳香族化合物 A〜H を非等価炭素の種類数(3, 6, 6, 7, 7, 9, 9, 9)で分類する。
  - 問1: クメン法の副生成物(アセトン)、PET の相手モノマー(エチレングリコール)
  - 問2: A(1,3,5-トリメチルベンゼン)、B(1,2,3-トリメチルベンゼン)、D(プロピルベンゼン)
  - 問3: A のニトロ化物 J と還元生成物 K(どちらも非等価炭素3種類 → トリニトロ体、トリアミノ体)
  - 問4: E(p-エチルトルエン)→テレフタル酸の収率80%、CO2 88.0 g から E の質量(37.5 g)
- その場で与えられた知識:
  - **L2 化学的に等価/非等価な炭素原子**(概念定義)。「ベンゼンの6炭素は環境が同じ」「o-キシレンで同じ番号は等価」と例示で定義し、「種類数を考えることは構造決定に重要」と述べる。実質は 13C NMR のシグナル数だが NMR の語は出ない。問2・問3、および C, E の特定に必須。
- 解法の核心・差がつく点: 8異性体を漏れなく書き、対称性で数える。問3は「モノニトロ化だと種類が増える」ことに気づけるか。
- 作問メモ: 分光法の名前を出さずに「その分光法が与える情報(対称性による種類数)」だけを定義して構造決定に使わせる型。異性体が多い分子式と相性がよい。

## 大問III(b)(有機/イミドの加水分解)

- 流れ: イミド構造と、温和な加水分解で C-N 結合が1本だけ切れる2通りの反応(図2)を説明。イミド L(C20H15NO2)、P(C23H21NO2)の加水分解生成物から構造を決める。
  - 問5: M(安息香酸)、O(アニリン)
  - 問6: L(N,N-ジベンゾイルアニリン)
  - 問7: Q として考えられる構造すべて(m-/p-エチル安息香酸、3,4-/3,5-ジメチル安息香酸の4種)
- その場で与えられた知識:
  - **L2 イミド構造と段階的加水分解**(反応の提示)。「窒素が2つのカルボニル基に挟まれた構造をイミドと呼ぶ」「アミドより加水分解されやすく、温和な条件では反応(1)または(2)で一方だけ切断されアミドとカルボン酸が得られる」「両方起こると生成物が混在」。L の生成物が2種だけ(対称)、P は4種(非対称)という情報の解釈に必須。
- 解法の核心・差がつく点: 分子式の引き算。問7は「COOH の両オルト位が H」の条件での数え上げ。
- 作問メモ: 「未習の官能基+切断の仕方が2通りある反応」を与え、対称な基質(生成物2種)→非対称な基質(生成物4種)の順に解かせる型。最後を「すべて記せ」にして数え上げで締める。

## 大問IV(a)(高分子(天然)/アルドースの立体化学)

- 流れ: くさび形表記と十字形の投影式を対応させ、炭素数4のアルドースを例に反応1(硝酸酸化で両末端 COOH)と反応2(C1 が取れて炭素1個減)を図示。酒石酸でメソ体と対称面を説明。
  - 問1: テトロース4種に反応2を行ったときの生成物2種(グリセルアルデヒドの両鏡像体)
  - 問2: ペントース8種のうち反応1の生成物に鏡像異性体が存在しないもの(あ・え・か・き)
  - 問3: 条件を満たす H の構造(2種)と G(い・く)
- その場で与えられた知識:
  - **L2 フィッシャー投影式**(概念定義)。「左右方向の結合は紙面の表側、上下方向は裏側、アルデヒド基を一番上」と規約を説明(名称は出さない)。全問の読み書きに必須。
  - **L2 アルドースの硝酸酸化と減炭反応**(反応の提示)。図3で例示し「OH の立体配置は変化しない」と明記。全問で必須。
  - L1 メソ体(下線部②で対称面と関連づけて説明)。問2・問3で使用。
- 解法の核心・差がつく点: 「両端が同じ基になると上下対称性が生じうる」ことを投影式上で機械的に判定する。問3は反応2→反応1の2段階を逆にたどる。
- 作問メモ: 表記法1つ+立体保持の反応2つを与え、「どの立体異性体が条件を満たすか」を選ばせる純論理型(フィッシャーのグルコース構造決定の縮小版)。知識ゼロで解けるが読解量が多い。

## 大問IV(b)(高分子(合成)/バイオ由来高分子と界面活性剤)

- 流れ: (i) 植物由来モノマー I から作るナイロン(繰り返し C11H21NO)と、ナイロン6モノマーに類似の J(C6H10O2)から作る生分解性高分子。(ii) オレイン酸由来のヒドロキシ酸 K と、β-グルコース2分子が C1–C2 でつながった二糖 L が2箇所で縮合した M、その加水分解物 N。
  - 問4: I(11-アミノウンデカン酸)、J(ε-カプロラクトン)の構造式
  - 問5: L の構造と、K の OH/COOH と縮合している OH の指定
  - 問6: N の界面活性が pH に依存する理由(選択6箇所)
- その場で与えられた知識:
  - L1 環状エステルの開環重合(説明はなく、「重合に関与する官能基以外の構造が同じ」から類推)。
  - それ以外は既習事項(グリコシド結合と還元性、エステル、弱酸の電離、ミセル)。
- 解法の核心・差がつく点: 「M が還元性を示さない」→ K の OH は L の還元末端 C1 とグリコシド結合、という読み取り。文章条件を構造図へ正確に写す作業。
- 作問メモ: 実在の機能性物質を題材に、既習の結合(アミド・エステル・グリコシド)を組み合わせて構造を言葉で指定し描かせる型。最後に物性(pH 応答)を選択式で確認する。
