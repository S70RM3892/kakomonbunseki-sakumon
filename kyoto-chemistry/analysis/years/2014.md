## 大問I(無機・理論/硫化亜鉛)

### (a) ZnS の反応と分別沈殿

- 流れ: ZnS の焙焼と酸との反応 → Zn2+ と Cu2+ の混合溶液から硫化水素で分離 → 溶解度積による残存濃度。
  - 問1: 粉末と塊の反応速度・反応熱、CuS を先に沈殿させる液性(選択 3)
  - 問2: ZnS と酸素の反応式
  - 問3: H2S 水溶液に SO2 を吹き込む反応式
  - 問4: [S2−] = 1.0×10⁻²⁰ のときの [Cu2+]、[Zn2+]
- その場で与えられた知識: なし(L0)。
- 解法の核心・差がつく点: [Cu2+] = 9.0×10⁻¹⁶。ZnS はイオン積が溶解度積に届かず沈殿しないので [Zn2+] は初濃度のまま。機械的に割り算すると誤る。
- 作問メモ: 「2 つの空欄のうち片方は沈殿しない、という罠を入れた溶解度積の計算」。
- 読み取りの注意: CuS の溶解度積の指数を −36、ZnS を −21、金属イオンの濃度を 1.0×10⁻⁵ mol/L と読んだ。

### (b) 結晶構造と限界半径比

- 流れ: NaCl 型と ZnS 型の図 → 配位数 → 図3 でイオンの接し方を示し、限界半径比を定義。
  - 問5: NaCl、ZnS それぞれの最近接の異符号イオン数・同符号イオン数
  - 問6: NaCl 型の限界半径比
  - 問7: ZnS 型の限界半径比
- その場で与えられた知識: L1 限界半径比。図3 と本文で、陰イオン同士が接する限界として定義。
- 解法の核心・差がつく点: NaCl 型は √2 − 1 = 0.41。ZnS 型は体対角線の 1/4 が r⁺ + r⁻ で、√6/2 − 1 ≒ 0.22。
- 作問メモ: 「定番の構造で概念を定義し、同じ考えを別の構造に適用させる」。

## 大問II(理論/NO2 の平衡、NO 酸化の反応速度)

### (a) 可動壁つき容器の平衡

- 流れ: 壁で仕切った容器で 2NO2 ⇄ N2O4。実験1〜4 を順に行う。
  - 問1: 濃度平衡定数 K と圧平衡定数 Kp の式
  - 問2: 壁を自由にして容積比 5 : 2 になったとき、部屋 B に入れた量(部屋 A の何倍か)
  - 問3: 壁を右に動かしたときの平衡移動、体積一定でアルゴンを加えたときの N2O4 の分圧と物質量(選択 3)
- その場で与えられた知識: なし(L0)。圧平衡定数は本文で定義されるが教科書本文事項。
- 解法の核心・差がつく点: 部屋 A の体積は V/2 なので K = yV/(2x²)。同温・同圧・同じ元素組成なら平衡組成が同じになり、物質量は体積に比例する(0.40 倍)。
- 作問メモ: 「装置を工夫して、等圧・等積の両方の条件を 1 つの題材で順に問う」。

### (b) 負の温度依存性

- 流れ: 2NO + O2 → 2NO2 は昇温で遅くなる温度範囲がある → 実験で得られた速度式を示す → 2 段階の素反応機構と仮定を提示 → K と k を素反応の速度定数で表す → 温度依存性を対数グラフで検討。
  - 問4: K、k を k1, k2, k3 で表す
  - 問5: 式(4) の正反応は発熱か吸熱か
  - 問6: 4 組のグラフから、条件に合わないもの・合うものを選ぶ(答は 1 つとは限らない)
- その場で与えられた知識:
  - **L2 前駆平衡機構(モデルの提示)**: 全反応の速度式 v = k[NO]²[O2] を実験事実として与え、NO + NO ⇄ N2O2、N2O2 + O2 → 2NO2 の 2 段階で進む機構を示す。各素反応の速度式を与え、「v1 と v2 は v3 より充分大きい。すなわち N2O2 が消費されても式(4) の平衡が速やかに達成される」と仮定を明示。問4 で K = k1/k2、k = k1k3/k2 を導き、問5・問6 の議論はすべてこの k = K·k3 の上に立つ。
  - L1 log K、log k3 を 1/T に対してとったグラフ: 軸の説明のみ。直線になる理由や傾きの意味は説明しない。
- 解法の核心・差がつく点: 発熱なら昇温で K が小さくなり、その減り方が k3 の増え方を上回れば k は小さくなる。グラフでは「log K の傾きが正」かつ「2 本の傾きの和が正」と読み替える。コ = う・え、サ = あ。
- 作問メモ: 「教科書の常識に反する実験事実を示し、それを説明する機構と仮定を与え、式で確かめさせてから図の選択に落とす」。見かけの速度定数が平衡定数と素反応の速度定数の積になる、という構造は他の反応にも移せる。

## 大問III(有機/テレフタル酸誘導体、アセトアルデヒドの合成実験)

### (a) C32H39NO3 の構造決定

- 流れ: オゾンと酸化剤による二重結合の切断を例示 → A の加水分解で B、C、D が 1 : 1 : 1 → B はテレフタル酸、C・D は F(E の水素付加体)から導かれるアミンとフェノール。
  - 問1: B、C、F の構造式
  - 問2: 空欄(エチレングリコール、亜硝酸ナトリウム)
  - 問3: E の幾何異性体の数
- その場で与えられた知識: L1 オゾン分解。「低温でオゾンと反応させたのち酸化剤と反応させると酸化的に切断され、カルボン酸あるいはケトンが生成する」と述べ、例を 1 つ図示。
- 解法の核心・差がつく点: 分子式の収支から F = C12H18。E は環に直結した CH= を 2 つもつ p-二置換体。ニトロ化が単一生成物なので置換基は同じで、F は p-ジプロピルベンゼン。E の幾何異性体は 3 種。
- 作問メモ: 「未習の切断反応を例で与え、切断後の生成物から元の炭素骨格を復元させる。対称性の条件(生成物が単一)で候補を 1 つに絞る」。

### (b) 実験報告書

- 流れ: 題目・目的・方法・結果・考察・感想からなる報告書。装置図と試薬の表つき。
  - 問4: 色の変化に関する説明の正誤
  - 問5: イオン反応式の係数
  - 問6: 酸化されてアルデヒドを経てカルボン酸になるもの(選択)
  - 問7: 利用しているアセトアルデヒドの性質(選択)
  - 問8: 効率よく得る方法(30 字)
  - 問9: ガラス管の先を水中に入れたときに起こりうる現象(10 字)
  - 問10: その理由(40 字)
- その場で与えられた知識: なし(L0)。
- 解法の核心・差がつく点: 3C2H5OH + Cr2O7²⁻ + 8H⁺ → 3CH3CHO + 2Cr³⁺ + 7H2O。沸点の低さを利用して生成物をすぐ蒸発させること、加熱をやめると圧力が下がって逆流することを短く書く。
- 作問メモ: 「教科書の実験を生徒の報告書として書き、失敗談から操作の理由を問う」。知識は易しく、表現の正確さを見る型。

## 大問IV(高分子(天然)/抗酸化ペプチド、セレブロシド)

### (a) トリペプチドの構造決定

- 流れ: 抗酸化物質 A(C10H17N3O6S)と B(分子量 163)について条件(i)〜(vii)を列挙。
  - 問1: 硫黄の検出反応、キサントプロテイン反応を示すもの
  - 問2: A1、A2、A3、B の構造式
- その場で与えられた知識: なし(L0)。チオール基とジスルフィド結合は条件文に出るが教科書本文事項。
- 解法の核心・差がつく点: A1 = グルタミン酸(等電点 3.22)、A3 = グリシン、分子式の収支から A2 = システイン。B は N-アセチルシステイン(121 + 42 = 163)。アミノ酸の側鎖は与えられないので暗記が前提。
- 作問メモ: 「箇条書きの条件から分子式の差し引きで構成要素を決める」。実在の生体物質を名称を伏せて使う。

### (b) セレブロシド

- 流れ: スフィンゴシン(構造式を図示)、脂肪酸、β-ガラクトースからなる糖脂質 → 酵素反応 1(アミド結合の加水分解)、酵素反応 2(グリコシド結合の加水分解)。
  - 問3: T1 の構造式
  - 問4: 銀鏡反応を示すもの、塩酸と塩をつくるもの、不斉炭素をもつもの
- その場で与えられた知識:
  - L1 ガラクトースの構造: 「4 位のヒドロキシ基の方向がグルコースとは逆になった異性体」と文章で定義。
  - L1 糖とアルコールのグリコシド結合: 「第一級アルコールのヒドロキシ基と β-ガラクトースの 1 位のヒドロキシ基が脱水縮合したもの」と説明。
- 解法の核心・差がつく点: T1 はガラクトースとスフィンゴシンが β-グリコシド結合したもの。還元性を示すのは遊離の糖 T2 だけ。アミノ基をもつ T1 と N2 が塩酸と塩をつくる。不斉炭素は T1、T2、N2。
- 作問メモ: 「複合脂質の構成を文章と図で与え、結合を 1 つずつ切って生成物の性質を問う」。題材は目新しいが、問うのは既習の官能基の性質。
