## 大問I(理論/氷の結晶、イオン交換膜法と炭酸塩緩衝液)

### (a) 氷の結晶構造

- 流れ: 図1(六方晶の氷の結晶格子)と、面上・格子内の O, H の個数、格子定数(a=b=0.780 nm, c=0.740 nm, a軸とb軸のなす角120°)を与える空欄補充形式の文章。
  - 問1: ア・イ(格子内の O, H の数)、ウ(体積)、エ(密度)、オ(O原子核どうしの最近接距離)、カ(ダイヤモンド)
  - 問2: 水素結合の方向数(4)、結晶中の H–O–H 角(109.5°)
  - 問3: 昇華熱 2.83 kJ/g から水素結合1か所あたりのエネルギー(J)
- その場で与えられた知識:
  - [L1] 直方体でない格子(120°)の体積と数え上げ: 角度と個数を明示。体積に sin120° が必要。
  - [L1] ファンデルワールス半径: 用法から意味がわかる形で提示(「…であるので原子核同士は□ nmまでしか近づけない」)。オで使用。
- 解法の核心・差がつく点: 面上は 1/2 → O 12個・H 24個。V=0.450×(√3/2)≒0.39 nm^3、密度 0.92 g/cm^3。水素結合は1分子あたり2本 → 2.83×18÷2÷(6.0×10^23)≒4.2×10^-20 J。
- 作問メモ: 「複雑な結晶図は雰囲気づけにとどめ、数え上げ情報は文章で与える。底面が平行四辺形の格子で体積計算に一捻り」型。構造→密度→結合エネルギーとミクロとマクロを往復させる。

### (b) イオン交換膜法と緩衝液

- 流れ: 図2(陽イオン交換膜で仕切った電解槽)。後半は NaHCO3/Na2CO3 混合水溶液が緩衝液になる話。
  - 問4: (i) 両極の反応式 (ii) 膜を取り除いて電解を続けたとき新たに起こる反応(どちらの極か+イオン反応式)
  - 問5: Na2CO3 0.100 mol + NaHCO3 0.200 mol/1 L(pH10.0)に 1.00 mol/L HCl を加えて pH9.9 にする体積(計算過程)
- その場で与えられた知識: なし(L0)。
- 解法の核心・差がつく点: pH10.0 の条件から Ka2=5.0×10^-11 を逆算し、10^0.1=1.26 を使って (0.100-x)/(0.200+x) を解く(約15 mL)。
- 作問メモ: 「工業プロセスの装置から条件を1つ外したら何が起こるか」を問う思考型小問+「平衡定数を与えず初期 pH から逆算させる」緩衝液計算。

## 大問II(理論/凝固点降下と固液平衡、気体反応の平衡)

### (a) 氷と共存する溶液の冷却

- 流れ: 非電解質水溶液が氷と共存したまま T1 → T2 へ冷却(状態①→②)。図1に凝固点–質量モル濃度の直線。記号は M(氷の質量)、w(溶液の質量)、C(質量モル濃度)、Kf、Ms。
  - 問1: T1 と C1 の関係式
  - 問2: ア(状態②の溶質の質量)、イ(M2=M1+w1(1-□) の□)
  - 問3: さらに冷却して全体が固体になったものを一定速度で加熱したときの温度変化グラフ(4択)
- その場で与えられた知識:
  - **[L2] 共晶(概念定義)**: 問3の設問文で「溶液中の水と溶質が同時に凝固し、一定の融点を示す固体相を形成した」と1文で述べる(「共晶」の語は出ない)。問3で、昇温 → 一定温度(共晶の融解) → 緩やかな昇温(氷が融けながら図1の直線上を戻る) → 急な昇温(全部液体)という形(B)を選ぶのに必須。軽量な L2(L1 寄りと見る余地あり)。
- 解法の核心・差がつく点: 「氷と共存する限り溶液は常に図1の直線上」という理解。問2は溶質保存と全質量保存を文字式で処理。問3は冷却過程を逆再生し、図1と加熱曲線を対応づける。
- 作問メモ: 「教科書の冷却曲線の“その先”(共晶)を1文で与え、逆向き(加熱)の曲線を選ばせる」型。既習グラフを時間反転・延長させるだけで新規性が出る。

### (b) CO と O2 の平衡

- 流れ: 可動壁で仕切った CO と O2(長さ lCO, lO2)、壁を取り除いて 2CO+O2⇄2CO2 の平衡。
  - 問4: あ(nCO/nO2)、い(平衡時の全物質量)、う(圧力は減少/増加)、え(Kp を x で表す方程式)
- その場で与えられた知識: なし(L0)。
- 解法の核心・差がつく点: 圧力変化 xRT/V の x=a/2 と対応づけ、Kp=4x^2·V/{(nCO-2x)^2(nO2-x)RT}。
- 作問メモ: 文字式のみの平衡問題。「a を含まず x で表せ」という変数の付け替えで式整理力を見る。

## 大問III(有機/配向性と合成経路、アリザリンの合成)

### (a) m-ブロモトルエンの選択的合成

- 流れ: リード文で、置換基が反応性と配向性に与える電子的効果を、トルエンの臭素化(ベンゼンの1000倍以上速い、o 約60%・p 約35%・m 5%以下)とアセトフェノン(遅い、m 体が主)の具体例で説明。図1に A(トルエン)→ニトロ化→還元→D(p-トルイジン)→[反応1 アセチル化]→F→臭素化→G→加水分解→H→ジアゾ化→I→H3PO2→J の経路。
  - 問1: F と I の構造式
  - 問2: F の置換基が反応性に及ぼす (あ) 電子的効果 (い) 立体的効果 を各50字程度で説明
- その場で与えられた知識:
  - [L1] 置換基の電子的効果と反応性・配向性: データ付きで説明。問2あで、アセチル基が電子密度を下げるという記述をアミドに転用する。
  - [L1] アセチル化による反応性の調節(保護基的発想)と立体効果: 問2の設問文で戦略を説明し、中身を論述させる。**L2 境界事例**(反応自体は既習、配向性は発展定番のため L1)。
  - (参考)H3PO2 によるジアゾニウム基の H 置換は範囲外だが説明なし・知識不要(生成物 J が図示)。
- 解法の核心・差がつく点: 問1は既習反応の当てはめ。問2は「-NHCOCH3 は C=O が N の電子を引くので -NH2 より環を活性化しない → 多置換を防ぐ」「かさ高く、隣接位への接近を妨げる」を自分の言葉で書く。
- 作問メモ: 「リード文で原理(電子密度⇔反応性・位置)を教える → 多段階合成の各段階の“意図”を論述させる」型。構造式を答えさせるより、なぜその迂回をするのかを問う点が京大らしい。

### (b) アリザリンの合成

- 流れ: K(C14H10)→ K2Cr2O7 酸化 → L(C14H8O2)→ 濃硫酸 → M(C14H8O5S)→ KOH 融解 → N(2-ヒドロキシアントラキノン、構造図示)→ アリザリン(図2)。
  - 問3: K, L の構造式 / 問4: NaOH 水溶液とエーテルで分液したとき化合物 O はどちらの層か+O の構造式 / 問5: アリザリン 960 g の完全燃焼で出る CO2(kg)
- その場で与えられた知識: なし(L0)。アントラキノン類は novel_context。分子式と N の構造から逆算できる。
- 解法の核心・差がつく点: N の骨格から L=アントラキノン、K=アントラセンと逆算。M はスルホン酸 → Na 塩 O は水層。C14H8O4=240 → 56 mol CO2 ≒ 2.5 kg。
- 作問メモ: 「歴史的な染料合成を題材に、未習骨格でも分子式+終盤の構造図から逆算させる」型。知識は教科書のフェノール合成(スルホン化→アルカリ融解)の転用。

## 大問IV(有機・天然高分子/脂肪酸の構造決定、アミノ酸とペプチドの電荷)

### (a) 不飽和脂肪酸の構造決定

- 流れ: 硫酸酸性 KMnO4 による C=C 酸化開裂(図1)と、特定の C=C にのみ水を付加する酵素を紹介。
  - 問1: プロピオン酸1分子+マロン酸2分子を与える A の構造式
  - 問2: 酸化でマロン酸を含む混合物を与え、酵素的水付加 → ヒドロキシ酸 C → 環状エステル D(五員環ラクトン、図2)となる B と C の構造式
- その場で与えられた知識:
  - [L1] KMnO4 による酸化開裂: 一般式で提示。問1・問2で必須。
- 解法の核心・差がつく点: D から C=4-ヒドロキシ-6-オクテン酸。B の第2の二重結合は 3,4位(4,5位だと共役ジエンとなりマロン酸が出ない)。
- 作問メモ: 「切断反応の断片パズル+環化生成物からの逆算で二重結合位置を一意に決める」型。候補が2つ残るようにして、もう1つの情報で絞らせる。

### (b) アミノ酸の電気泳動

- 流れ: Ala, Ser, Lys, Asn, Glu(図3)と等電点5個(3.22, 5.41, 5.68, 6.00, 9.75)。実験1(pH7.0 で1種が陰極へ)、実験2(pH4.0 で4種が陰極へ、強酸処理後は3種のみ)。
  - 問3: 双性イオン / 問4: 実験1で陰極へ動くアミノ酸 / 問5: 強酸処理で生じたアミノ酸 E の強酸性での構造(イオン式)
- その場で与えられた知識: なし(L0)。
- 解法の核心・差がつく点: 強酸処理で Asn の側鎖アミドが加水分解されて Asp になり、等電点が4未満になると見抜く。
- 作問メモ: 「実験結果の“数の不一致”(4種→3種)から、処理で何が起きたかを推理させる」型。

### (c) ポリペプチドの電荷と滴定

- 流れ: 10残基ペプチド F(Ala-Ser-Lys-Ala-Lys-Glu-Ala-Ser-Ser-Ala)。全カルボキシ基を非解離にした後 NaOH で滴定(図4: pH – [NaOH]/[ポリペプチド])。
  - 問6: 側鎖のアミノ基・カルボキシ基の数、pH2.0 と pH12.0 での電荷
  - 問7: 滴定曲線から等電点に最も近い整数
- その場で与えられた知識:
  - [L1] 多価両性電解質の滴定曲線と正味電荷: 操作と図を与える。問7で必須。
- 解法の核心・差がつく点: 出発点 +3、OH- 1当量ごとに電荷 -1 → 横軸3.0 で電荷0、pH≒9。
- 作問メモ: 「アミノ酸1個の定番(電荷・滴定曲線)をペプチドに拡張し、グラフの横軸(当量)と電荷を対応づけさせる」型。
