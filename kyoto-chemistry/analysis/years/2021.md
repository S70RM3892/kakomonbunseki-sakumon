# 京大化学 2021年度

## 全体

- 冊子 15〜30 ページ(18 ページは白紙)。4題100点。I・II は単一テーマ、III・IV は (a)(b) の2パート構成。
- 題材は目新しいが、**高校範囲外の概念・式をその場で定義して使わせる L2 は 0 件**。新規性は「既習事項を見慣れない実験設定・文字式・多段階スキームで運用させる」ことと「断片データからの推論」で作られている。
- 準範囲外の反応(銅のヨウ素滴定、オゾン分解、ラクタム、リグニン熱分解のルール)は1文〜1図で与えられるが軽量で L1 どまり。
- 難所は II(Δn の符号と熱量の収支)と IV(b)(ホルモンペプチドの構造決定)。
- 最高レベル: I L1 / II L1 / III(a) L1 / III(b) L1 / IV(a) L1 / IV(b) L1

## 大問I(理論/硫酸銅(II)の電気分解とヨウ素滴定)

- 流れ: 1.000 mol/L CuSO4 水溶液 10.00 L を白金電極・193 A・1000 秒で電解。電解後の液 2.00 mL を取り、緩衝液と KI を加えて(CuI の白色微粉末が分散した褐色懸濁液)、0.1000 mol/L Na2S2O3 で滴定(18.20 mL)。『』内に反応の説明文(空欄ア〜カ)。
  - 問1: ア〜カを選択肢から選ぶ(Cu2+、還元、I-、酸化、I2、I3-)
  - 問2: 『』内をまとめた1つのイオン反応式(2Cu2+ + 5I- → 2CuI + I3-)
  - 問3: 褐色が薄くなる過程のイオン反応式(I3- + 2S2O3^2- → 3I- + S4O6^2-)
  - 問4: 電解後に溶けている Cu の物質量(9.10 mol)
  - 問5: 酢酸緩衝液で pH 変化が最も緩やかになる pH を Ka で表す(pH = -log Ka)
  - 問6: 陽極・陰極の反応式
  - 問7: 陰極の理論析出量(1.00 mol)
  - 問8: 電解効率(90%)
- その場で与えられた知識:
  - [L1] Cu2+ + I- → CuI + I3- による銅のヨウ素滴定: 操作と観察を述べ、空欄付きの説明文で反応を誘導。受験定番。
  - [L1] S2O3^2- → S4O6^2-: 生成物を明示。
  - [L1] 緩衝作用最大の条件: 説明なしで問う(定番知識)。
  - [L1] 電気分解の効率: 問8で定義。
- 解法の核心・差がつく点: Cu2+ : S2O3^2- = 1 : 1 の対応と、採取倍率(2.00 mL → 10.00 L で 5000 倍)。有効数字3桁の処理。全体に易しく、落とせない。
- 作問メモ: 「電気分解(理論量)+滴定(実測量)→効率」という2実験の突き合わせ型。準範囲外の滴定反応は、空欄と選択肢で反応の筋を受験生に組み立てさせる形で導入する。

## 大問II(理論/硫酸の第二電離と中和の熱量測定)

- 流れ: H2SO4 の一段階目は完全電離、二段階目 HSO4- ⇌ H+ + SO4^2- は平衡。0.080 mol/L 希硫酸 40 mL に同濃度の NaOH を滴下し、HSO4-/SO4^2- の存在比率(図1)と温度上昇を測る。式(4)(7)(8)(9)の係数を空欄にした誘導文。
  - 問1: ア([H+]≒0.089 mol/L)、イ(K≒0.011 mol/L)
  - 問2: ウ・エ(整数。ともに -1)、オ・カ(-Q1、-(Q1+Q2))
  - 問3: キ〜コ(1、0.29、2、0.89)、サ(Q2≒20 kJ)
  - 問4: シ(ルシャトリエ)、ス(小さくなる)、セ(大きくなる)
  - 問5: 逆に NaOH 30 mL へ硫酸を 10 mL、30 mL 加えたときの発熱量を q(40)、q(80) で表す(q(80)/4、3q(40)/4)
- その場で与えられた知識:
  - [L1] 硫酸第二電離の不完全性と存在比率–滴下量の図: 式と図で提示、主要点(0.89、0.60、0)は本文でも数値を示す。
  - [L1] Δn を使った収支式と発熱量の分解: 枠組みは本文が与え、係数を埋めさせる。知識は既習のみ。
- 解法の核心・差がつく点:
  - 加えた OH- の量 = 「減った H+」+「HSO4- の電離で補給された H+」。Δn の符号の約束に従って係数を -1 と置けるか。
  - 発熱量は液量が 80 mL、120 mL と異なる点に注意(4.2 J/(mL·℃))。q(80) - 2q(40) で Q1 を消去。
  - 問5は「同じ組成の状態に至るなら発熱量は経路によらない」という発想(ヘスの法則)で、連立方程式を解き直さずに比例で答える。
- 作問メモ: 「一見単純な中和熱測定に、隠れた平衡(第二電離)の熱が上乗せされる」型。測定可能な2点(当量点の半分と当量点)の差から隠れた反応熱を取り出す。最後に溶液の組合せを逆にして状態量の理解を問う。

## 大問III(有機/リグニンの熱分解生成物、バニリンの合成)

### (a) リグニン熱分解物の構造決定

- 流れ: リグニンの部分構造図(図1)と熱分解ルールを与え、フェノール・グアイアコール(図2)のほかに得られる A〜E の性質を列挙。
  - 問1: A〜E の構造式(A アニソール、B 1,2-ジメトキシベンゼン、C 1-エチル-3,4-ジメトキシベンゼン、D・E 4-メチル-2-メトキシフェノールと 5-メチル-2-メトキシフェノール)
  - 問2: F(3,4-ジメトキシ安息香酸)、G(3,4-ジメトキシトルエン)、H(3,4-ジメトキシベンズアルデヒド)
- その場で与えられた知識:
  - [L1] 熱分解ルール: 「C–O 結合またはベンゼン環以外の C–C 結合が切れ、切断部が H に置き換わる。環と置換基の位置は保持」。置換位置を図1から決めるのに必要。問題固有のルールで L2 に近いが、新概念の学習というより図の読取り条件なので L1 とした。
  - [L1] 芳香族カルボン酸の熱による脱炭酸: 結果として記述。
- 解法の核心・差がつく点: FeCl3 陰性=OH がすべてエーテル化、という判断と、「D・E をメチル化すると同じ G」から D・E が OH と OCH3 の入れ替わった位置異性体だと気づくこと。置換位置(3,4-二酸素置換)は図1のユニット構造から読む。
- 作問メモ: 「巨大な天然高分子の構造図+断片化ルール」を与え、断片の構造を性質情報と図の両方から決めさせる型。図は情報源であると同時に、置換位置を一意にする制約として働く。

- 流れ: 石油由来の経路(i)(ベンゼン+プロペン→I→フェノール→J→グアイアコール→K→バニリン)と、バイオマス由来の経路(ii)(L をオゾン分解)を反応スキームで示す。
  - 問3: I(クメン)、J(カテコール)、K(4-ヒドロキシ-3-メトキシベンジルアルコール)、L(トランス形のイソオイゲノール)の構造式。オゾン分解の一般式は図3で与える

## 大問IV(高分子(天然)/アスパルテームの合成、ホルモンペプチドの構造決定)

### (a) アスパルテームの合成

- 流れ: ペプチドの表記(N末端・C末端)とアミノ酸の表1(等電点・分子量つき6種)を示したうえで、アスパルテームの構造を文章で定義(下線部①)。N-ホルミルアスパラギン酸 → 分子内酸無水物 X → フェニルアラニンメチルエステルと反応して異性体 Y、Z → Y からギ酸を外してアスパルテーム(図2)。
  - 問1: X、Y、Z の構造式
  - 問2: アスパルテームの構造式
- その場で与えられた知識:
  - [L1] アミノ基をギ酸アミドにして保護し、分子内酸無水物経由で縮合、最後に脱保護する合成戦略: 工程を文章と図2で説明(「保護基」の語は使わない)。
- 解法の核心・差がつく点: 非対称な五員環無水物はどちらのカルボニルでも開環できる → α 側で開いた Y が目的物、側鎖側で開いた Z が副生成物。下線部①の「不斉炭素原子に結合したカルボキシ基」と照合する。
- 作問メモ: 「実在の工業合成法を言葉で説明し、位置選択性の問題(望まない異性体が出る)を構造式で答えさせる」型。使う反応は無水酢酸+アミンと同型で既習。

### (b) 視床下部ホルモン(化合物A)の構造決定

- 流れ: (ア)〜(ケ)の9個の実験情報。分子量 362・C16H22N6O4、加水分解で His と他2種(1:1:1)、ニンヒドリンですぐ呈色するのは2種、pH6.0 の電気泳動で陽極へ動くのは1種、五員環ラクタムを含む、A はアセチル化されないが NaOH で穏やかに処理すると分子量 380 になりアセチル化される、His のカルボキシ基側のペプチド結合を切ると2種の有機化合物、推定配列のトリペプチド C は分子量が一致しない、C を酸触媒メタノール → アンモニアで処理すると A。
  - 問3: His 以外の2種(グルタミン酸、プロリン)
  - 問4: 陽極側へ動くアミノ酸の説明文の空欄 a〜d(カルボキシ、酸性、4、負)とイオンの構造式 I・II
  - 問5: (i) 酸無水物 B の名称(無水酢酸) (ii) アセチル化が進んだ理由を「ラクタム」を含め40字以内
  - 問6: トリペプチド C の配列(グルタミン酸–ヒスチジン–プロリン)
  - 問7: A の構造式
- その場で与えられた知識:
  - [L1] ラクタム: (オ)で「分子内でアミド結合を形成した環状アミド」と定義。どの残基が環化するかは推論。
  - [L1] エステル+アンモニア → アミド: (ケ)で操作と結果のみ。分子式の N の数と分子量から C 末端 −CONH2 と推論する。説明はないが論理的に到達できる設計。
  - [L1] プロリンのニンヒドリン呈色が異なること: 結果のみ記述。必須ではない(裏づけ)。
- 解法の核心・差がつく点: 分子量収支(155+147+115-36=381、ラクタム化で -18、−COOH → −CONH2 で -1 → 362)。N が 6 個であることからアンモニア由来の N を1個見抜く。五員環ラクタムを作れるのは側鎖に −CH2CH2COOH をもつ N 末端のグルタミン酸。
- 作問メモ: 「実在の生理活性ペプチド(両末端が修飾されている)を、通常のトリペプチドでは説明できない矛盾(分子量不一致・アセチル化不可)から修飾を推理させる」型。その場で教える型ではなく、データ統合型の難問。
