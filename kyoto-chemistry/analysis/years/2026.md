# 京大化学 2026年度

## 全体

- 冊子 19〜34 ページ(22 ページは白紙)。4題100点。I・II・IV は単一構成(II は本文が (a)(b)(c) に分かれるが設問は通し)、III は (a)(b) の2パート(計5パート)。
- I は結晶格子・限界半径比・鉛蓄電池と電気分解の定番(L1)。
- **L2 は 4 パートに出現: II(吸着平衡の式 q = H[P] と化学平衡の同時平衡)、III(a)(アセタール交換・ヘミアセタール・環化優先の規則)、III(b)(鏡像異性体選択的触媒によるアセチル化)、IV(スフィンゴ糖脂質と血液型糖鎖の構造表記)。**
- L2 の与え方は「規則・式・表記法を図と数文で示し、適用は既習の平衡計算・構造推定・量的関係」。計算負荷は軽く、読解と規則の正確な適用が勝負。
- III(b) と II は L1 との境界(下記の注を参照)。
- 最高レベル: I L1 / II L2 / III(a) L2 / III(b) L2 / IV L2

## 大問I(理論・無機/硫化鉱物の結晶構造、鉛蓄電池と電気分解)

- 流れ: 硫化鉱物(PbS、FeS2、ZnS、HgS)と製錬。PbS は塩化ナトリウム型。閃亜鉛鉱型構造(図1)。12族元素、亜鉛めっき。限界イオン半径比の考え方(図2)。
  - 問1: い(6)、ろ(12)、は(酸化)
  - 問2: FeS2 の燃焼の反応式(4FeS2 + 11O2 → 2Fe2O3 + 8SO2)
  - 問3: 限界イオン半径比 (i) 配位数6(0.41)、(ii) 配位数8(0.73)
  - 問4: ZnS の (i) 密度(4.0 g/cm3)、(ii) Zn–S 中心間距離(0.234 nm)
  - 問5: 鉛蓄電池で CuSO4 水溶液と NaOH 水溶液を同時に電気分解(図3)。(i) 正極の反応式、(ii) 電解液が 3.20 g 減ったときの電気量(3.86×10^3 C)、(iii) 電極 C の反応式、(iv) B の気体が C の気体の1.5倍のとき A の質量増加(0.96 g)
- その場で与えられた知識:
  - [L1] 限界イオン半径比: 図2と本文で配位数6について定義。配位数8は自力で拡張。
  - [L1] 閃亜鉛鉱型構造: 図1と本文で説明。
- 解法の核心・差がつく点: 鉛蓄電池は電子 2 mol あたり電解液 160 g 減。図3は並列なので、2槽の電子の配分を気体の体積比(O2 と H2)から 3:1 と決める。
- 作問メモ: 鉱物 → 結晶構造 → 製錬 → 電池・電気分解と、無機の素材から理論の定番計算を引き出す型。回路を並列にして「電気量の配分」を未知数にするのが一工夫。図3は A・C が負極側、B・D が正極側と読み取った。

## 大問II(理論/吸着平衡と化学平衡の組み合わせ)

- 流れ: 吸着の説明(シリカゲル、活性炭)。(a) 吸着平衡の式 q = H[P] と実験1(P の溶液に吸着剤 S を加える)。(b) A ⇌ P + R の平衡と反応率の定義、実験2。(c) 実験2の平衡溶液に S を加え、P だけを吸着させて平衡を移動させる実験3。
  - 問1: ア(mH[P]1)
  - 問2: イ([A]0(1−α))、ウ([A]0α)、エ([A]0α^2/(1−α))
  - 問3: オ(V[A]0β/(V+mH))、カ(V/(V+mH))
  - 問4: H の値(1.5 L/g)
  - 問5: K の値(5.0×10^-4 mol/L)
  - 問6: (i) S を加えた後の A、P、R の濃度変化のグラフ選択(A ③、P ④、R ①)、(ii) [A]3 = 2.0×10^-4 mol/L となる m(0.36 g)、(iii) 生成した P のうち吸着している割合(0.84)
- その場で与えられた知識:
  - [L2] 吸着平衡の式: 「吸着剤 S 1 g あたりの P の吸着量 q [mol/g] と溶液中の P のモル濃度 [P] との関係は、吸着定数 H [L/g] を用いて次式で与えられるものとする: q = H[P]」。問1で吸着量 mH[P]1 を書かせ、問4で H を数値化、問3・問6で化学平衡と連立する。
  - [L2] 吸着と化学平衡の同時平衡: 「S は P のみを選択的に吸着し」「反応前の A の物質量は、平衡状態における溶液中の A、P の物質量、および S に吸着した P の物質量の和に等しい」と収支の立て方まで誘導。問3で式(8)(9)を導き、問6で数値に適用する。
  - [L1] 反応率: 式(4)で定義(解離度と同じ)。
- 解法の核心・差がつく点: P の収支 V[A]0β = (V+mH)[P]3。K の式は「吸着なしの式 × V/(V+mH)」になる。グラフは R と A が対称に動き、P は K = [P][R]/[A] から A よりさらに小さくなる(「反応速度は吸着速度より十分大きい」ので常に化学平衡が成立)。
- 作問メモ: 「教科書にない平衡(吸着)を一次式で与え、既習の化学平衡と物質収支で連立させ、最後に数値とグラフで確認する」型。分配平衡と同じ数学なので、L2 としては軽い(L1 と判定する余地あり)。文字式 → 数値 → グラフ選択 → 応用の階段が丁寧。図1の破線の意味は明記がなく、解答には不要と判断。

## 大問III(有機/アセタールの平衡、鏡像異性体選択的アセチル化)

### (a) アセタール交換と構造決定

- 流れ: アセタールの定義。図1(1) アセタールとアルコールの交換平衡、(2) アセタール ⇌ ヘミアセタール ⇌ アルデヒド、(3) 五員環・六員環の環状アセタールが優先。「酸の存在下で図1の反応のみが起こる」「平衡移動の原理に従う」。
  - 問1: アセタール A、B、C を少量の硫酸を含む大過剰のエタノール中で反応させた生成物 A'、B'、C'、C'' の構造式
  - 問2: C8H18O3 のアセタール D(OH をもち、ヨードホルム反応陽性)→ 大過剰メタノール中で五員環アセタール E(C6H12O2)→ 大過剰エタノール中で F(C7H14O2)。D、E の構造式
- その場で与えられた知識:
  - [L2] アセタール交換: 「アセタールは1つの炭素原子を挟んで2つのエーテル結合をもつ有機化合物の総称であり、酸の存在下で図1に示す平衡が成り立つ」。問1で、大過剰のエタノール中ではアルコキシ基がすべてエトキシ基に置き換わると判断するのに使う。
  - [L2] ヘミアセタール・アルデヒドとの平衡: 図1(2)。問1の C で、分子内のホルミル基がアルコールと反応してアセタールになる(逆向き)ことに使う。
  - [L2] 環化優先の規則: 「六員環、あるいは五員環の構造を形成しうる場合は平衡定数が大きく、R4–OH が多量にあったとしても…環状のものが主生成物となる」。B'(五員環)、C''(六員環)、E(五員環)の決定に使う。
- 解法の核心・差がつく点: A' は PhCH(OEt)2。B' は 2-エトキシテトラヒドロフラン。C はアセタール部分で2つに分かれ、CH3CH(OEt)2 と、5-ヒドロキシペンタナールが環化した 2-エトキシテトラヒドロピランになる。D は CH3CH(OH)– をもち、E が五員環になる位置に OH がある → CH3CH(OH)CH2CH2CH(OCH3)(OC2H5)、E は 2-メトキシ-5-メチルテトラヒドロフラン。
- 作問メモ: 「未習の官能基変換を3本の平衡図で与え、(i) 順方向の適用、(ii) 逆方向・分子内での適用、(iii) 逆算による構造決定」と段階を上げる型。糖のヘミアセタール構造(既習)と地続きの題材を選んでいる。全問が構造式で、規則なしでは1問も解けない純粋な L2。

### (b) 鏡像異性体選択的なアセチル化

- 流れ: アルコール G とそのアセチル化体 H の鏡像異性体を GR、GS、HR、HS と表記(図2、くさび形表記の凡例つき)。無水酢酸ではラセミ体からラセミ体。化合物 I と触媒 X または Y によるアセチル化(図3、分子量つき、アセトンが副生)と特徴1〜3。
  - 問3: 触媒 X、ラセミ体 G 8.00 g と I 2.00 g → 未反応 GR(4.00 g)、GS(1.28 g)
  - 問4: 触媒 Y、ラセミ体 G 1.36 g から H 0.712 g(HR:HS = 90:10)→ 未反応の GS は GR の何倍か(約3.3倍)
- その場で与えられた知識:
  - [L2] 鏡像異性体を区別する触媒: 「特徴1: 触媒 X は GS のみをアセチル化し、GR をまったくアセチル化しない」「特徴2: 触媒 Y は両方をアセチル化するが、それぞれの反応速度が異なる」「特徴3: GR からは HR が、GS からは HS が生じる」。問3・問4とも、鏡像異性体ごとに物質量を追うために必須。
  - [L1] エノールエステル I によるアセチル化: 図3の反応式と分子量。1:1 の量的関係に使う。
  - [L1] くさび形・破線の立体表記: 凡例で説明。設問では直接使わない。
- 解法の核心・差がつく点: ラセミ体を鏡像異性体ごとに半量ずつに分け、それぞれ独立に収支をとる。
- 作問メモ: 「先端的な反応(速度論的光学分割)を、特徴の箇条書き+分子量つきの反応式に落として量的関係だけを問う」型。化学的には軽いので、L2 と L1 の境界事例。形式(未習の規則を読んで適用)を重視して L2 とした。

## 大問IV(天然高分子/スフィンゴ糖脂質と ABO 式血液型物質)

- 流れ: スフィンゴ糖脂質・セラミド・スフィンゴシンの定義(図2)。ABO 式血液型物質の糖鎖(図3、結合位置の表記法つき)。単糖 I、II、III、I'、II' の定義と6種の単糖の構造(図4)。実験1: 酵素でセラミド X1 と糖鎖 X2 に分ける。実験2: X1 を加水分解して脂肪酸 Y 306 mg(C=C 3個、H2 3.00×10^-3 mol で飽和)。実験3: X2 をヨウ化メチルで完全メチル化。実験4: グリコシド結合だけ加水分解。
  - 問1: 単糖 I、II、III の名称(グルコース、ガラクトース、フコース)
  - 問2: 単糖 II' の環状構造式(ガラクトースの C2 が –NHCOCH3)
  - 問3: Y の分子式(C20H34O2)
  - 問4: 糖鎖 1 mol の全 OH のメチル化に必要なヨウ化メチル: ア(O 型 15)、イ(A 型 17)、ウ(B 型 18)
  - 問5: (i) ヨウ化メチル 2.556 g から血液型、(ii) 実験4で得られる単糖 II のメチル化物の種類数 → 組み合わせを選択(B 型・3 種)
- その場で与えられた知識:
  - [L2] スフィンゴ糖脂質とセラミド: 「セラミドは、スフィンゴシンのアミノ基と脂肪酸のカルボキシ基がアミド結合を介してつながった物質」「糖類は、セラミド中のスフィンゴシンとグリコシド結合を形成」。問3・問5(i)で「脂肪酸 Y の物質量 = 糖鎖 X2 の物質量」とし、問4でセラミドから外れた末端に OH が1個生じると判断するのに使う。
  - [L2] 血液型糖鎖の構造と結合表記: 図3の注「\"1-2\"は、左側の単糖の C1 炭素と右側の単糖の C2 炭素がグリコシド結合を形成していることを意味する」。問4で各糖鎖の遊離 OH を数え、問5(ii)で3か所の単糖 II の結合位置(C1 のみ/C1・C3/C1・C2・C3)を読み分ける。
  - [L1] 単糖の誘導体の定義: C4 の立体異性体、C6 のデオキシ体、C2 のアセトアミド体を言葉で定義し、図4から選ばせる。
  - [L1] メチル化分析: 「すべてのヒドロキシ基がメチル化され、メトキシ基となった」「グリコシド結合のみが完全に加水分解される」。難関大向け問題集で定番。
- 解法の核心・差がつく点: 単糖単体の OH の数(I・II は5、III・I'・II' は4)を正しく押さえ、グリコシド結合1本につき2個引く。AB 型なら平均 17.5 になる点も選択肢の判別に関わる。
- 作問メモ: 「生体分子の模式図と表記規則を与え、官能基の数え上げだけで同定(ここでは血液型判定)に持ち込む」型。定番のメチル化分析を、OH の総数(試薬の消費量)という別の観測量で使わせている。リード文と図が長く(図5点)、読解量そのものが難度になっている。
