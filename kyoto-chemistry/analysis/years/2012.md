## 大問I(理論+無機/ガリウムの結晶構造と性質) 最大レベル L1・標準

- 流れ: Ga は Al と同族でメンデレーエフがエカアルミニウムとして予言。Al と同様の反応性。固体が液体より低密度、融点が低く沸点が高い、という特徴を Cs(体心立方、充填率68%)、Al(面心立方、74%)と比較。Ga の固体は原子2個が強く結合した対をつくり、対の中心が直方体単位格子の頂点と面心にある(図3)。融点・沸点のデータ(Cs 28 ℃/670 ℃、Al 660 ℃/約2500 ℃、Ga 30 ℃/約2400 ℃)。
  - 問1: ア 13、イ メンデレーエフ、ウ 体心立方格子、エ 2、オ 8
  - 問2: 4Ga + 3O2 → 2Ga2O3
  - 問3: 希硫酸との反応、NaOH 水溶液との反応(Al の類推)
  - 問4: Ga の充填率(対内の原子間距離 0.250 nm、単位格子体積 0.157 nm3 → 約 42%)
  - 問5: 融点が最も低い金属(水銀)
  - 問6: Ga の融点が極めて低い理由を、融解時の原子間の結合状態の変化に着目して50字で
- その場で与えられた知識:
  - L1 ガリウムの結晶構造モデル(モデルの提示): 「原子2個ずつが比較的強く結合して原子対を形成」「対どうしは比較的弱い結合」「対の中心が頂点と面心」。オ、問4、問6 で必須。
  - L1 同族元素(Al)からの類推による反応。問2、問3。
- 解法の核心・差がつく点: 対を1粒子とみて面心配置で4対=8原子。問6 は「融解では対間の弱い結合だけ切れ、対内の強い結合は残る(沸騰にはそれも切る必要がある)」と本文のモデルから組み立てる。
- 判定メモ: 範囲外の構造モデルを与えて論述に使わせる点は L2 的。ただしコードブックの「見慣れない結晶構造は novel_context」に合わせ、迷って低い方に倒した。
- 作問メモ: 「未知元素 X を既知の同族元素・類似物性の元素と3者比較」し、(1) 類推で反応式 (2) 与えた構造で充填率 (3) 構造から物性(融点・密度)の理由を論述、と進める型。

## 大問II(理論/石けん水と大気中 CO2 の多重平衡) 最大レベル L1・やや難

- 流れ: ラウリン酸ナトリウム(分子量222)の構造、加水分解平衡(1)、ラウリン酸の析出平衡(2)(Ksp=2.0×10^-10)、ミセル。次に大気と接した水: CO2 の水和(3)(4)、炭酸の2段階電離(5)(6)。大気と平衡の水は pH 5.5。ラウリン酸ナトリウム 4.66 g/L の水溶液を大気に触れさせると pH 8.0、式(2)の溶解平衡が成立しミセルは生じていない。電荷均衡の式(7)。
  - 問1: ア 疎水(親油)性、イ 親水性、ウ ミセル
  - 問2: a [CO2]=2.2×10^-5 mol/L、b [RCOO-]=2.0×10^-2 mol/L
  - 問3: A = [RCOO-] + [OH-] + [HCO3-] + 2[CO3 2-]
  - 問4: c 2.2×10^-5、d 1.0×10^-3、e 4.7×10^-6 mol/L
- その場で与えられた知識:
  - L1 弱酸の析出への溶解度積の適用(式と値を提示)。b で必須。
  - L1 CO2 の水和平衡定数を電離と分けて扱う(式(4)を提示)。a, c で必須。
  - L1 電荷均衡の式(左辺のみ与え右辺を書かせる)。問3。
- 解法の核心: 大気と平衡なら [CO2] は pH によらず同じ値、という一点。あとは与えられた平衡式を上流から順に代入。近似基準(y/x ≦ 0.01)に従い [OH-] や 2[CO3 2-] を落とす。
- 作問メモ: 「身近な系(石けん水+空気)」に、既習の平衡(加水分解・溶解度積・多段電離)を式ごと全部並べ、純水の場合 → 溶質ありの場合、と同じ道具を2回使わせる型。近似の許容基準を冒頭で数値指定するのも京大的。

## 大問III(有機/C6H10 異性体の構造決定、4エステル化合物の構造決定)

### (a) 最大レベル L1・やや難

- 流れ: 冒頭で C=C の酸化的切断を例示(同じアルケンに KMnO4/H2SO4 ではカルボン酸+ケトン、オゾン分解ではアルデヒド+ケトン)。A は燃焼に O2 8.50 mol、C 87.8%、H 12.2%。A を KMnO4 で酸化した生成物とヘキサメチレンジアミンから 6,6-ナイロン。B は不斉炭素1個、Hg(II) 触媒で水付加するとカルボニル化合物に変化しヨードホルム反応陽性。C はメチル基2個、H2 2分子付加でメチル基4個のアルカン、付加重合で主鎖に二重結合をもつ高分子 E。D のオゾン分解生成物 F は銀鏡反応陽性、還元で二価アルコール G、G の分子内脱水生成物は「α-グルコースのすべての OH を H に置き換えた化合物」と同一。
  - 問1: A の分子式の導出(C6H10)
  - 問2: A シクロヘキセン、B 3-メチル-1-ペンチン、D 1-メチルシクロペンテン、E ポリ(2,3-ジメチル-1,3-ブタジエン)(1,4付加)、G 1,5-ヘキサンジオール
- その場で与えられた知識:
  - L1 C=C の酸化的切断(KMnO4 とオゾン分解の違い)。図の例で提示。A, D で必須。
  - L1 アルキンへの水付加とケト-エノール異性化。文章で記述。B で必須。
- 差がつく点: G → 環状エーテル(2-メチルテトラヒドロピラン)の逆算。グルコースの環構造を「OH をすべて H に」と読み替える翻訳。
- 作問メモ: 同一分子式の異性体4つに、それぞれ異なる反応(酸化開裂・水付加・重合・オゾン分解)を1つずつ割り当て、最後の1つは既習の有名構造(グルコースの環)を経由した間接ヒントにする型。

### (b) L0・やや難

- 流れ: 不斉炭素1個の H(分子量480)に H2 付加で不斉炭素のない I(C27H30O8)。H のエステル結合4個を加水分解すると J(トルエンの酸化で得られる一価カルボン酸)、K(C3H8O、酸化で N、N は中性でフェーリング陰性)、L(粘性の高いアルコール、高級脂肪酸とのエステルが油脂)、M(C7H8O4、同一炭素に COOH 2個、COOH を H に置き換えるとシクロペンテン)。
  - 問3: J 安息香酸、L グリセリン
  - 問4: K(2-プロパノール)と N(アセトン)に関する正誤(正しいのは ウ, オ)
  - 問5: H 48.0 g から J は 24 g(安息香酸は2分子)
  - 問6: H の構造(グリセリンの1,3位が安息香酸エステル、2位が M、M の他方がイソプロピルエステル、M は 2-シクロペンテン-1,1-ジカルボン酸)
- その場で与えられた知識: なし。
- 解法の核心: 分子式の収支で安息香酸が2分子と決め、「H で不斉1個、I で0個」を満たす配置を探す(グリセリン中央が不斉にならない対称配置、かつ環の二重結合の位置で C1 が不斉になる)。
- 読み取りメモ: H の分子式は拡大して C27H28O8 と確認。
- 作問メモ: 「不斉炭素の数が反応前後で変わる」条件を、構成部品の結合位置と二重結合位置の両方を絞る鍵にする型。

## 大問IV(天然高分子/アミノ酸・ペプチド)

### (a) 最大レベル L1・標準

- 流れ: 8種のアミノ酸の構造(図1)。アミノ酸の電離状態(図2)。ペプチドの呼称(表1)、N末端・C末端(図3)。
  - 問1: 酸性・塩基性で多い構造 A, B
  - 問2: Ala と Asn からなるペプチドの完全加水分解で水 18.9 g 消費、Ala 26.7 g、Asp 53.2 g → Ala 6個、Asn 8個
- その場で与えられた知識: L1 N末端・C末端などの用語定義。
- 差がつく点: 生成物がアスパラギン「酸」であることから、側鎖アミドの加水分解でも水を消費すると気づく。比 3:4 だけで止めず、水の量から実数を決める。
- 作問メモ: 「主鎖以外にも同じ官能基(アミド)がある」ことを生成物名だけでほのめかし、水の収支で整数解を1つに絞らせる型。

### (b) 最大レベル L1・標準

- 流れ: ペンタペプチド P(a-b-c-d-e)。実験1: 温和な加水分解で1か所切断の断片 X1, X2, Y1, Y2, Z1, Z2, A1, A2(図4)。実験2: 構成アミノ酸は A1〜A4 の4種。実験3: N末端を切り出す酵素で P, X1, Y1, Y2 から A1。実験4: X2 から A3(等電点9.7)。実験5: FeCl3 で X1, X2, Y1, Z1, A4 が紫。実験6: NaOH 加熱後に酢酸鉛で X2, Y1, Z1, A2 が黒色沈殿。実験7: キサントプロテイン反応が P, X1, X2, Y1, Y2, Z1, Z2, A1, A4 で陽性。
  - 問3: A1 フェニルアラニン、A2 メチオニン、A3 リシン、A4 チロシン
  - 問4: ビウレット反応陽性(X1, X2, Y1, Y2)
  - 問5: a〜e = A1, A3, A1, A4, A2
- その場で与えられた知識:
  - L1 N末端切断酵素による末端決定(実験3で操作を記述)。
  - L1 部分加水分解による断片化(図4)。
- 解法の核心: 実験3・4 で断片の向き(X1 = a〜d、X2 = b〜e、Y1 = c〜e、Y2 = a〜c)を確定し、呈色反応の陽性・陰性の集合から各位置を埋める。
- 作問メモ: 断片に「どちら側か未定の名前」を付け、検出反応の陽性集合の包含関係で向きと位置を同時に決めさせる論理パズル型。知識は定番の検出反応だけで足りる。
