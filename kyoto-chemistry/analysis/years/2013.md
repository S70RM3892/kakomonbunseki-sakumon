## 大問I(理論・無機/電気陰性度と結合、錯体)

### (a) 電気陰性度・極性・CO2 結晶

- 流れ: ポーリングの定義式と結合エネルギー表 → イオン化エネルギー・電子親和力との関係 → 分子の極性 → CO2 分子結晶(面心立方)。
  - 問1: 表の元素で電気陰性度最大のもの(ア)
  - 問2: イオン化エネルギー・電子親和力の定義と電気陰性度との大小関係(選択 6 か所)
  - 問3: H–F の ΔE、CO2 結晶の最近接 C–C 距離、密度
  - 問4: H2O は極性分子、CO2 は無極性分子である理由(論述)
- その場で与えられた知識:
  - **L2 ポーリングの電気陰性度の定義(式の提示)**: 「ポーリングによれば」として ΔE = E(A–B) − ½{E(A–A)+E(B–B)} を与え、電気陰性度の差の絶対値が √ΔE に比例すると述べる。表中で最小は H と明示。問1 は H–X の ΔE が最大になる X を選ぶ形、問3 の I はその ΔE の値。アは既習知識でも答えられるが、I は式なしには出せない。
  - L1 電気陰性度とイオン化エネルギー・電子親和力の関係: 「関係している」と述べるだけで、大小は選択肢で判断させる。
- 解法の核心・差がつく点: H–F は 570 − (430+150)/2 = 280 kJ/mol。CO2 は C が面心立方配置なので最近接 a/√2 = 0.40 nm、密度は 4 分子で約 1.7 g/cm³。難所はない。
- 作問メモ: 「教科書で値だけ習う量(電気陰性度)の定義式を与え、表のデータに代入させる」。導入として軽い L2 を置き、後半は定番計算に流す構成。

### (b) 錯体

- 流れ: 配位結合と錯イオンの説明 → 多座配位子とキレートの定義。
  - 問5: 空欄(非共有電子対)
  - 問6: Ag2O がアンモニア水に溶ける反応式
  - 問7: 八面体型 [MA3B3] の幾何異性体をすべて図示(記入例つき)
  - 問8: エチレンジアミンは Co3+ と安定なキレート錯体をつくるが、ヘキサメチレンジアミンはつくらない理由(論述)
- その場で与えられた知識:
  - L1 八面体型錯体の幾何異性体: 存在することだけ述べ、[MA5B] の記入例を示す。
  - L1 キレート: 「金属イオンと結合する部位を複数もち、挟み込むように結合する様式」と定義。安定な理由は説明されない。
- 解法の核心・差がつく点: [MA3B3] は 2 種(同種 3 つが 1 つの面を占める型と、子午線上に並ぶ型)。問8 は 2 つの N の間隔が隣り合う配位座にちょうど届き、ひずみの少ない五員環になることを書く。
- 作問メモ: 「定義だけ与え、理由は分子の形から考えさせる論述」。鎖長の違う 2 物質を対比させて答えの方向を示す型。キレートは準範囲内と見て L1 としたが、問8 の考察は L2 寄り。

## 大問II(理論/シュウ酸の存在比、グリシンのミクロ電離定数)

### (a) シュウ酸

- 流れ: 2 段階電離と滴定曲線 → 物質収支式から各化学種の存在比を誘導。
  - 問1: [HA−]、[A2−]、[H2A]/c の式(空欄 3)
  - 問2: pH 4 での [H2A] : [HA−] : [A2−]
  - 問3: 滴下量 12 mL 付近で緩衝作用を示す理由(論述)
- その場で与えられた知識: L1 多価酸の存在比の式(誘導つきで導出)。
- 解法の核心・差がつく点: 1 : K1/[H+] : K1K2/[H+]² = 1 : 5.4×10² : 2.9×10²。HA− と A2− が同程度共存することを比から読み取り、問3 の説明につなぐ。
- 作問メモ: 「(b) の準備運動として、同じ道具(物質収支と定数の組合せ)を既習の題材で使わせる」。

### (b) グリシン

- 流れ: +1 価のグリシンを 2 価の酸とみなす → 電荷 0 の形には分子型 G⁰ と双性イオン型 G± があり、4 つの電離定数で記述される → 滴定で得られる K1, K2 との関係 → メチルエステルの定数を使って 4 つを決定。
  - 問4: K1、K2 を Ka〜Kd で表す
  - 問5: メチルエステルの電離定数と等しいとみなす定数を選ぶ
  - 問6: pH 7 での [G±]/[G⁰]
  - 問7: Kd の値
- その場で与えられた知識:
  - **L2 ミクロ電離定数(モデルの提示)**: 「正味の電荷をもたないグリシンには分子型と双性イオン型の 2 種類が存在するため、電離平衡は 4 つの電離定数で記述される」とし、図3 で四角形の平衡図と Ka〜Kd の定義式を与える。問4 で K1 = Ka + Kb、K2 = KcKd/(Kc+Kd) を自分で導き、問6・問7 の計算の土台にする。
  - **L2 モデル化合物による近似(モデルの提示)**: 「2 つの式から 4 つの定数は決められない」と述べ、解離基を 1 つしかもたないメチルエステルの電離定数がどれかと等しいと仮定する。どの過程に対応するか(–COOH が電離しない G⁺→G⁰、すなわち Kb)は受験生が判断する。
- 解法の核心・差がつく点: 滴定では G± と G⁰ を区別できない、という一点から K1, K2 の式を立てる。Ka ≫ Kb なので指定の近似で Ka ≒ K1。[G±]/[G⁰] = Ka/Kb ≒ 2.3×10⁵。四角形を一周する関係 KaKc = KbKd と K2 ≒ Kc から Kd ≒ 3.8×10⁻⁵。
- 作問メモ: 「教科書では 1 つの形として扱うもの(双性イオン)を 2 つの形に分解し、測定できる量と測定できない量の関係を立てさせる。式が足りない分を、構造の似たモデル化合物の値で補う」。冒頭で近似の基準(|y/x| < 0.01)を明示しておく点も再利用できる。

## 大問III(有機/フタル酸ジエステル、C9H10O の環状化合物)

### (a) C16H18O4 の構造決定

- 流れ: 水素付加の量 → 加水分解生成物 C(1-ブタノール)、D(フタル酸)の同定 → A を直接加水分解すると D、E(アルデヒド)、F(E の構造異性体)。
  - 問1: A 1 mol に付加する H2 の物質量
  - 問2: 酸化して D になる芳香族化合物の名称
  - 問3: A、C、E、F の構造式
  - 問4: E と F の沸点が異なる理由(論述)
- その場で与えられた知識: L1 エノール型エステルの加水分解でアルデヒドが生じること。説明はなく、事実から受験生が推論する。
- 解法の核心・差がつく点: 2 つの C4H7 基はどちらも水素付加後に 1-ブチル基になる。一方は –O–CH=CH–CH2CH3(加水分解でブタナール)、他方は幾何異性体のない –O–CH2CH2CH=CH2(3-ブテン-1-オール)。F はアルコールなので水素結合で沸点が高い。
- 作問メモ: 「水素付加してからの加水分解と、そのままの加水分解を並べ、差から二重結合の位置を決めさせる」。

### (b) C9H10O

- 流れ: ベンゼン環に縮合した五員環をもつ C9H10O のうち、不斉炭素をもつ G〜J。不斉炭素の H を OH に替えた K〜M のうち L、M はヘミケタール。L と平衡にあるケトン N はアルコール性 OH をもつ。
  - 問5: G、H、L、N の構造式
- その場で与えられた知識: L1 ヘミケタール。図1 で一般構造 R–C(R')(OH)–OR'' と名称を示す。ケトンとの平衡は「平衡状態にあるケトン型の化合物」と書くだけ。
- 解法の核心・差がつく点: 環に O を含む骨格(ジヒドロベンゾフラン型、ジヒドロイソベンゾフラン型)を漏れなく挙げる。G は 1-インダノール。OH 置換後にヘミケタールにならない K の元が H(3-メチル体)。開環してアルコール性 OH を与えるのはイソベンゾフラン型で、N は 2-(ヒドロキシメチル)アセトフェノン。
- 作問メモ: 「骨格の条件だけ与えて異性体を列挙させ、仮想的な置換で生じる官能基の性質で絞る」。グルコースの環状構造と鎖状構造の平衡を一般の分子に移した型。構造を図で定義して使わせる点は L2 寄りだが、教科書知識の類推で解けるので L1 とした。

## 大問IV(高分子(天然)/ペプチドグリカン)

### (a) 糖鎖部分

- 流れ: 細菌のペプチドグリカンの模式図。N-アセチルグルコサミンと N-アセチルムラミン酸の構造を文章で定義。
  - 問1: 二糖繰り返し単位の構造式を 4 つから選ぶ
- その場で与えられた知識: L1 2 つの糖誘導体の構造。「グルコースの 2 位のヒドロキシ基がアミノ基に置換され、アセチル化されたもの」「その 3 位のヒドロキシ基に乳酸がエーテル結合したもの」と文章で定義。
- 解法の核心・差がつく点: 乳酸は –OH 側でエーテル結合するので –O–CH(CH3)–COOH。β-1,4 結合はセルロースと同じく隣の環が反転した表記。正答は(エ)と推定(細部は未確認)。
- 作問メモ: 「未知の物質を、既知の物質からの置換として文章で定義し、構造式に翻訳させる」。誤答選択肢は α/β の取り違えと、エーテル/エステルの取り違えで作る。

### (b) ペプチド部分

- 流れ: テトラペプチド A1–A4 とペンタペプチド(A5×5)。A2–A3 間と A3–A5 間は側鎖の官能基が関与するアミド結合。候補アミノ酸 4 種の構造と各アミノ酸の等電点を与える。
  - 問2: A1〜A5 の名称
  - 問3: A2 と A3 からできるジペプチドの種類数
  - 問4: ペプチドグリカン中と同じ結合様式のジペプチドの構造式と、A1・A5 との結合に使う官能基の指定
- その場で与えられた知識: なし(L0)。側鎖を介したアミド結合は説明されるが、化学的には既習のアミド結合。
- 解法の核心・差がつく点: A1・A4 = アラニン、A2 = グルタミン酸、A3 = リシン、A5 = グリシン。問3 は 2×2+1 = 5 種。問4 は、A3 の ε-アミノ基が A5 との結合に使われることから、A2–A3 はリシンの α-アミノ基とグルタミン酸の側鎖カルボキシ基の結合と決まる。
- 作問メモ: 「模式図の結合関係と『通常のペプチド結合ではない』という条件から、どの官能基が使われるかを消去法で決めさせる」。
