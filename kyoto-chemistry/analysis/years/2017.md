## 大問I(無機・理論/硫化鉱物の結晶と銅の製錬、金属水酸化物の沈殿平衡)

### (a) 黄銅鉱・黄鉄鉱と銅

- 流れ: 図1で CuFeS2 と FeS2 の単位格子と体積 v を与え、リード文で「半格子2段重ね、金属は面心+頂点」「FeS2 は Fe2+ と S2^2- の NaCl 型」と説明。
  - 問1: 密度比 d1/d2(導出過程あり)
  - 問2: FeS2 と希硫酸で H2S が出る反応式
  - 問3: Cu2S → Cu の2段階反応(①Cu2S の一部が Cu2O に、②Cu2S と Cu2O から Cu)の反応式
  - 問4: FeCl3 水溶液による銅のエッチングをイオン反応式と文章で説明
- その場で与えられた知識:
  - [L1] 二硫化物イオン S2^2-: 「鉄(II)イオンと二硫化物イオンから構成」と一言。問2で S が -1 価 → H2S と S に分かれると見抜くのに必須。
  - [L1] 立方体でない単位格子の数え上げ: 文章で配置を説明。問1で両者とも4式単位と数える。
- 解法の核心・差がつく点: 密度比は式量/体積の比だけ(≒0.82)。未習反応を「酸化数の指定」から自力で組む問2・問3②で差。
- 作問メモ: 「未習の鉱物・製錬反応を、酸化数や生成物のヒントだけ与えて反応式を組ませる」型。結晶は図が複雑でも、数え上げ情報を本文に書いて計算自体は軽くする。

### (b) 廃水中の金属イオンの沈殿

- 流れ: 4種の金属イオン各 1.0×10^-2 mol/L、pH1.0 の廃水に NaOH を加える。表1に Ksp、図2に溶解度(対数)–pH の4直線。
  - 問5: 直線ア〜エがどのイオンか
  - 問6: (i) pH5.0 で沈殿しているもの (ii) Zn(OH)2 が沈殿し始める [H+]
  - 問7: (i) [Zn(OH)4]2- の溶解度の対数 y を pH=x と K で表す(導出) (ii) 錯イオン濃度が Zn2+ の10倍になる pH(導出)
- その場で与えられた知識:
  - [L1] 溶解度の対数–pH 図と、両性水酸化物の再溶解の平衡定数 K: 問7で反応と K を設定させる。受験定番の発展。
- 解法の核心・差がつく点: 傾き=価数で Fe3+/Al3+ と Cu2+/Zn2+ を分け、Ksp の大小で位置を決める。問7(ii) は [OH-]^4=10Ksp/K を与えられた log 値で処理(pH≒11)。
- 作問メモ: 「Ksp の表 → 片対数グラフの同定 → 錯イオン平衡を自分で式にして接続」の3段構成。log の値を冒頭で与え、対数処理を必須にする。

## 大問II(理論/光異性化の速度・平衡と浸透圧、2成分系の気液平衡)

### (a) 光で構造が変わるタンパク質

- 流れ: X→Y は光で進み(v=kP[X])、Y→X は常に進む(v=kR[Y])。式(1)の差分近似で kR を決める方法を説明。
  - 問1: 光照射下の平衡 [X]:[Y]=1:4 から kP:kR
  - 問2: 消灯5.0 s 後の [Y] から kR(単位つき、導出)
  - 問3: X+Z ⇄ Y+Z ⇄ YZ の平衡時の [X], [Z] を初濃度と [Y], [YZ] で表す
  - 問4: 半透膜の反対側(グルコース水溶液)にかけた追加圧力 2.00×10^2 Pa から [YZ](導出)
- その場で与えられた知識: なし(L0)。速度式・近似式は与えられるが内容は教科書の平均反応速度。光定常状態・追加圧力で水面を揃える実験は novel_context。
- 解法の核心・差がつく点: 会合で溶質粒子数が [YZ] だけ減る → 浸透圧差 Δπ=[YZ]RT。問3の物質収支がそのまま問4の布石。
- 作問メモ: 「見慣れない生体系の設定 × 既習の速度・平衡・束一的性質」を1本のストーリーでつなぐ型。範囲外知識なしでも設定読解で難度を出せる例。

### (b) 揮発性2成分の気液平衡

- 流れ: ラウールの法則(pA=xAπA, pB=xBπB)を冒頭で定義。ピストン容器で操作(1)〜(5)(定圧加熱→全気化→膨張してB注入→圧縮して気液共存→さらに圧縮)。図2に5状態。
  - 問5: ア(加えた熱量/mol)、イ(混合気体中の A のモル分率)、ウ(xA の式)、エ(その値)
  - 問6: 気相の A のモル分率 yA を xA, πA, πB で表す(導出)+ yA の増減の選択
- その場で与えられた知識:
  - [L1] ラウールの法則(2成分とも揮発性): 式で定義(法則名なし)。問5ウ・エ、問6で必須。教科書発展+受験定番として L1(気相組成まで扱う点は L2 寄り)。
- 解法の核心・差がつく点: 「370 K での純 A の蒸気圧 = 1.60×10^5 Pa」を操作(1)の沸騰条件から読み取ること。P=xAπA+(1-xA)πB、yA=pA/P。
- 作問メモ: 「未習の式を1つ与え、長い操作列の中で既習(状態方程式・熱量)と交互に使わせる」型。必要な定数を前の操作の記述に埋め込んでおくのが京大らしい仕掛け。

## 大問III(有機・合成高分子/エステルの構造決定、ポリ乳酸)

### (a) C16H18O6 の構造決定

- 流れ: オゾン分解の反応例を図示。A(カルボニル3個、不斉炭素なし)の水素付加量、加水分解生成物 C(1)・D(2)・E(1) の情報。
  - 問1: B の分子式 / 問2: C の名称 / 問3: D, F の構造式 / 問4: E の2構造 / 問5: B の構造式
- その場で与えられた知識:
  - [L1] オゾン分解: 反応例を構造式で提示。E → ベンズアルデヒド + F から E の骨格を決めるのに必須。
- 解法の核心・差がつく点: H2 消費量 = A の物質量 → C=C 1個。グリセリン + 酢酸×2 + ケイ皮酸。不斉炭素なし → ケイ皮酸は2位。E はシス・トランス。
- 作問メモ: 定番の「与えた切断反応+量的情報+対称性(不斉炭素の有無)で位置決定」型。

### (b) ポリ乳酸

- 流れ: L-乳酸 → L-ラクチド → 開環重合でポリ-L-乳酸(図1、くさび表記)。
  - 問6: D-乳酸の立体構造の空欄 / 問7: 残り2種のラクチド立体異性体 / 問8: ポリ-L-乳酸がポリ-DL-乳酸よりかたい理由(30字、指定語句) / 問9: ポリ-D-乳酸の密度・加水分解・酵素分解の異同(選択)

  - [L1] 不斉炭素2個の環状化合物の立体異性体(メソ体含め3種): 数だけ与える。問7で必須。
- 解法の核心・差がつく点: 鏡像体は「キラルな相手(酵素)に対してのみ性質が異なる」。規則的な鎖 → 結晶部分が増える。
- 作問メモ: 「身近な高分子材料 × 立体化学」。立体規則性→物性→生分解性と、知識より原理理解を選択・短い論述で問う。

## 大問IV(天然高分子・有機/核酸塩基の化学修飾、いす形配座と糖)

### (a) 突然変異誘発

- 流れ: 塩基対の水素結合を位置番号で問う。亜硝酸ナトリウムによる脱アミノ化を 2-アミノピリジンのモデル反応(式(1))で示し、シトシン・5-メチルシトシンに話をつなぐ。後半はベンゾ[a]ピレンによるグアニン修飾。
  - 問1: 水素結合に関わる位置番号(ア〜エ) / 問2: X(ジアゾニウム基) / 問3: 化合物 C(アミド形)の構造式 / 問4: 5-メチルシトシンの脱アミノ化生成物の名称 / 問5: (i) ヌクレオチド単位の平均式量 (ii) タバコ1本で修飾できる細胞数(導出)
- その場で与えられた知識:
  - [L1] 複素環アミンの脱アミノ化とヒドロキシ形⇄アミド形の互変異性: 式(1)と「最終的にアミド結合を有する化合物 C となる」で提示。問3・問4で必須。**L2 境界事例**(ジアゾ化・加水分解・エノール→ケトはいずれも既習の延長と見て L1)。
  - [L1] プリン・ピリミジン環の位置番号: 図1で付番。問1で使用。
- 解法の核心・差がつく点: モデル反応を 5-メチルシトシンの 4位 NH2 に写像 → チミン。問5は A=T=10%、G=C=40% → 309、4.5×10^-10 mol ÷ 4.40×10^-15 mol ≒ 1.02×10^5 個。
- 作問メモ: 「小さなモデル化合物で反応を図示 → 生体分子に同じ変換を適用させ、生物学的意味(修復されない変異)に結びつける」型。計算小問を添えて配点を分散。

### (b) いす形配座と糖(本年度の L2)

- 流れ: メタンの正四面体から始め、シクロヘキサンが横から見るといす形であること、各炭素に「環平面に垂直」と「ほぼ平行」の水素が1つずつあること、C1 を押し下げ C4 を持ち上げると ⓅからⓆへ変換され水素の配置が変わること(平衡)を説明。図2に全水素ラベル付きの2配座。
  - 問6: H2a, H4b, H6a をメチル基にしたとき立体反発が小さい配座はⓅⓆどちらか
  - 問7: α-ガラクトース(図3 ハース投影式)の安定ないす形で、C1-OH・C2-OH・C5-CH2OH が垂直かほぼ平行か(8択)
  - 問8: (i) α-グルコース、β-グルコースの垂直/平行置換基数(空欄4) (ii) 4種の糖のうち最も立体反発が小さいもの
- その場で与えられた知識:
  - **[L2] いす形配座・環反転・垂直(アキシアル)/平行(エクアトリアル)と立体反発(モデルの提示)**: 用語は避けつつ文章と模型図で導入。「垂直な置換基どうしは混み合う」という規則は明示せず図から読み取らせる。問6〜8すべてで必須(これなしでは1問も解けない)。
  - [L1] ハース投影式: 「置換基を上下に記して位置関係を表す表記」と説明。問7・8で、上下配置をいす形の垂直/平行へ翻訳するのに使う。
- 解法の核心・差がつく点: 図2から「垂直位は隣の炭素ごとに上下交互」「環反転で垂直⇄平行が総入れ替え」を抽出する。最大置換基 CH2OH を平行に置く配座で他の OH の向きを順に決める。β-グルコースは全置換基が平行(垂直0・平行5)で最安定、という結論に至る。
- 作問メモ: 「範囲外の立体モデルを図とやさしい言葉(専門用語なし)で導入 → 単純な系(メチルシクロヘキサン)で練習 → 既習の生体分子(糖)に適用 → 『なぜβ-グルコースが安定か』という意味のある結論で締める」型。L2 問題の模範的な段階設計。
