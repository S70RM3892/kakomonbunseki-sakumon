# 京大化学 過去問分析コードブック

各年度の問題を同じ物差しで記録するための基準。年度別ファイル(`years/YYYY.md`, `data/YYYY.json`)はすべてこの基準で書く。

## 分析単位

大問(I〜IV)。大問が (a)(b) など独立した前後半に分かれる場合は、その各パートを 1 単位(part)とする。

## 「高校範囲」の基準

**現行課程(2022年度入学生〜の学習指導要領「化学基礎」「化学」)の検定教科書本文**を基準にする。
出題当時の課程ではなく、いま受験する人の目線で判定する。

- 本文に載っている事項 → 範囲内
- 教科書の「発展」「参考」コラムや、標準的な受験参考書(重要問題集・新演習レベル)で定番化している事項 → L1
- それらにも通常載らない事項(大学初年級以降の概念・式・反応・実験手法) → L2 / L3

## 範囲外度レベル(その場学習の判定)

| レベル | 定義 | 例 |
|---|---|---|
| L0 | 教科書本文の知識だけで閉じている | 鉛蓄電池の反応式、凝固点降下の計算 |
| L1 | 教科書の発展・受験定番の準範囲外事項。問題文で説明される場合も、されない場合も含む | 限界半径比、マルコフニコフ則、ザイツェフ則、アレニウスの式、緩衝液の近似 |
| L2 | 高校範囲外の概念・式・反応・装置を、**問題文がその場で定義・説明し、それを使って解かせる** | 「〜という。この反応は次式で表される」と未習の反応機構を与える/未習の式を与えて計算させる |
| L3 | 高校範囲外の知識を**説明なしに前提**とする(知らないと解けない) | まれ |

判定で迷ったら低い方に倒し、`note` に迷った理由を書く。
L2 の本質は「読解して新しいルールを把握 → 既習事項と組み合わせて適用」という作業が要求されること。
単に見慣れない物質名が出るだけで、解くのに既習知識しか使わないものは L0/L1 とする(物質名は `novel_context` に記録)。

## その場で与えられる知識(beyond_items)の型

`kind` に次のいずれかを付ける。

- `概念定義` : 新しい用語・量を定義する(例: 分配係数、活量、結合次数)
- `式の提示` : 未習の関係式を与える(例: ネルンスト式、ラングミュア吸着式、反応速度の積分形)
- `反応の提示` : 未習の有機・無機反応や反応機構を与える(例: オゾン分解、ディールス・アルダー、アルドール縮合)
- `モデルの提示` : 現象を説明する仮定・モデルを与える(例: 定常状態近似、格子モデル)
- `実験手法の提示` : 未習の分析・測定法を与える(例: NMR、質量分析、クロマトグラフィー、滴定の変法)
- `データ読解` : 未習の量を含む図表を与え読み取らせる

## 難易度

京大受験生(合格ライン付近)目線の 4 段階: `易` / `標準` / `やや難` / `難`。理由を一言添える。

## Markdown(`years/YYYY.md`)

人間が読む用。構成は以下。

```
# 京大化学 YYYY年度
## 全体
## 大問I(分野/テーマ)
- 流れ: リード文で何を述べ、各問で何を問うか(問ごとに1行)
- その場で与えられた知識: レベル付きで列挙。L2 以上は問題文の言い回しの要旨と、それをどの問でどう使うかを具体的に
- 解法の核心・差がつく点
- 作問メモ: この問題の「型」(作問時に再利用できる構造)を1〜3行
## 大問II …
```

問題文の逐語的な長い転記はしない(要旨と構造を書く)。
