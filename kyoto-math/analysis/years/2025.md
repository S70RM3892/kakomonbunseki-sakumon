## 大問1 問1(複素数平面/易/35点)

- 分野: 複素数平面
- 形式: 求値、小問数 0、誘導 G0
- 要旨: |z|=2 のとき |z-i/z| の最大・最小。
- 解法の核心: |z²-i|/|z|。z² は半径4の円周を動く。
- 型: 絶対値の性質/円周上の点と定点の距離
- 答: 最大 5/2、最小 3/2(確認: 手計算)
- 作問メモ: 小問集合の一行問題。

## 大問1 問2(積分/標準/配点は同じ大問の問1に合算)

- 分野: 積分
- 形式: 求値、小問数 2、誘導 G1
- 要旨: 定積分2題(分数式+無理式、√((1-cos x)/(1+cos x)))。
- 解法の核心: (1) は x/√(x²+1) と (2x³+1)/(x²+1) に分ける。(2) は tan(x/2)。
- 型: 分数式を割って分ける/半角で根号を外す
- 答: (1) 4-2log 2+π/3 (2) log 2(確認: 計算機)
- 作問メモ: 計算力確認。arctan 型を含む。

## 大問2(整数/やや難/35点)

- 分野: 整数(+平方数)
- 形式: 求値、小問数 0、誘導 G0
- 要旨: N=9z²=x⁶+y⁴ と表される正整数 N の最小。
- 解法の核心: 平方数の和が 3 の倍数なら両方 3 の倍数。x=3a, y=3b で w²=(3a³)²+(b²)²。a=1 で (w-b²)(w+b²)=9。
- 型: mod 3 で平方和/ピタゴラス数/最小性の論証
- 答: 2025(x=3, y=6, z=15)(確認: 手計算)
- 作問メモ: 答が西暦。最小であることの論証(a≧2 では大きすぎる)まで書く。

## 大問3(微分/標準/30点)

- 分野: 微分(+対数)
- 形式: 求値、小問数 0、誘導 G0
- 要旨: f(x)=x²log x の接線に垂直で (t,g(t)) を通る直線の x 切片 p(t) の値域。
- 解法の核心: p=t+g·f'。g の分母 1+2log t が f' の因数と消えて p=t³log t(1+2log t)。
- 型: 式の整理で約分が起きる/log x を変数に
- 答: -1/(9√e)≦p≦3e³(確認: 手計算)
- 作問メモ: きれいに約分されるよう g を作ってある。見た目に怯まず計算する。

## 大問4(空間図形/標準/35点)

- 分野: 空間図形(+ベクトル)
- 形式: 証明+求値、小問数 2、誘導 G2
- 要旨: OL=sOA 等で 1/s+2/t+3/u=4。(1) 平面 LMN が定点 P を通り、P は唯一。(2) 四面体 PABC の体積。
- 解法の核心: 点 xOA+yOB+zOC が平面 LMN 上 ⇔ x/s+y/t+z/u=1。条件式と比べて P=(1/4,1/2,3/4)。唯一性は s,t,u を具体的に3組とって示す。
- 型: 平面の方程式(斜交座標)/恒等式として見る/体積比=係数
- 答: (2) V/2(確認: 手計算)
- 作問メモ: 「定点を通る」の存在と一意性を分けて書かせる。一意性の論証が抜けやすい。

## 大問5(軌跡・領域/やや難/30点)

- 分野: 軌跡・領域(+空間座標、2次曲線)
- 形式: 求値+図示、小問数 0、誘導 G0
- 要旨: A(0,0,√2/4) と P(cosθ,sinθ,(1/2)cosθ) を通る直線と xy 平面の交点 Q の軌跡(-π/4<θ<π/4)。
- 解法の核心: Q=(cosθ,sinθ)/(1-√2cosθ)。X²+Y²=(1+√2X)² に整理すると双曲線。θ の範囲から片方の枝全体。
- 型: 直線と平面の交点/媒介変数の消去/変域
- 答: (x+√2)²-y²=1 の x≦-√2-1 の枝(確認: 手計算)
- 作問メモ: 円錐曲線を「円の射影」として出す。数学C の2次曲線が単独の大問になった。

## 大問6(確率・場合の数/やや難/35点)

- 分野: 確率・場合の数(+数列)
- 形式: 求値、小問数 0、誘導 G0
- 要旨: 硬貨を n 回投げ X_k∈{0,1}。Y_n=ΣX_{k-1}X_k が奇数である確率。
- 解法の核心: (Y の偶奇, 最後の X) の4状態。偶−奇の差で見ると2ステップごとに 1/2 倍。
- 型: 直前の出目を状態に含める/偶奇の差に注目/2項ずつの漸化式
- 答: n 偶数: (1-2^{-n/2})/2、n 奇数: (1-2^{-(n-1)/2})/2(確認: 計算機)
- 作問メモ: 状態に「直前の結果」を入れる必要がある漸化式。偶奇で答の形が変わる。
