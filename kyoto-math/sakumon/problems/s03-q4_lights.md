# 3 個の電球(状態を決める → 偶奇に気づく → 2回分の漸化式 / 想定 25 分 / 標準)

狙い: 2014[2]・2017[6] と同じく状態の少ない確率漸化式だが、設定を見慣れないものにした。状態は「ついている電球の個数」。個数の偶奇が1回ごとに入れ替わるので、$n$ が偶数なら確率は 0 で、奇数のときは2回分をまとめた漸化式を立てる(2025[6] と同じく、答が $n$ の偶奇で分かれる)。

## 問題

3個の電球があり、最初はすべて消えている。「3個の電球から1個を無作為に選び、その電球がついていれば消し、消えていればつける」という操作を繰り返す。

$n$ を自然数とする。この操作を $n$ 回行ったあとで、3個の電球がすべてついている確率を求めよ。

## 解答

### 答

$n$ が偶数のとき $0$、$n$ が奇数のとき $\dfrac14\left\{1-\left(\dfrac13\right)^{n-1}\right\}$

### 解答

ついている電球の個数を $k$ とする。1回の操作で $k$ は 1 だけ増えるか 1 だけ減るので、$k$ の偶奇は操作のたびに入れ替わる。最初 $k=0$ だから、$n$ 回後の $k$ の偶奇は $n$ の偶奇と一致する。

**$n$ が偶数のとき。** $k$ は偶数で、$k=3$ にはならない。確率は 0。

**$n$ が奇数のとき。** $k$ は 1 または 3 である。$k=3$ である確率を $p_n$ とすると、$k=1$ である確率は $1-p_n$。

1回の操作での変化は、ついている電球を選ぶ確率が $\dfrac k3$、消えている電球を選ぶ確率が $\dfrac{3-k}{3}$ であることから

- $k=3$ → 必ず $k=2$
- $k=2$ → 確率 $\dfrac13$ で $k=3$、確率 $\dfrac23$ で $k=1$
- $k=1$ → 確率 $\dfrac23$ で $k=2$、確率 $\dfrac13$ で $k=0$
- $k=0$ → 必ず $k=1$

2回の操作をまとめると

- $k=3$ から2回後に $k=3$: $1\cdot\dfrac13=\dfrac13$
- $k=1$ から2回後に $k=3$: $\dfrac23\cdot\dfrac13=\dfrac29$

よって、奇数 $n$ に対して

$$p_{n+2}=\frac13p_n+\frac29(1-p_n)=\frac19p_n+\frac29 .$$

$p_{n+2}-\dfrac14=\dfrac19\left(p_n-\dfrac14\right)$ と変形でき、$p_1=0$ である。$n=2m-1$ とおくと

$$p_{2m-1}-\frac14=\left(\frac19\right)^{m-1}\left(0-\frac14\right)=-\frac14\left(\frac13\right)^{2m-2} ,$$

$2m-2=n-1$ より

$$p_n=\frac14\left\{1-\left(\frac13\right)^{n-1}\right\} .$$

### 検算

$n=1$: 0。$n=3$: $\dfrac14\cdot\dfrac89=\dfrac29$。3回で全部つくには毎回消えている電球を選ぶしかなく、$1\cdot\dfrac23\cdot\dfrac13=\dfrac29$ で合う。

### 採点で見るところ

- 偶奇の議論。$n$ が偶数のとき 0 であることを落とした答案は、答の半分が欠けている。
- 状態を「どの電球がついているか」(8通り)ではなく「個数」(4通り)にまとめてよい理由。遷移確率が個数だけで決まることを述べる。
- 指数の処理。$\left(\dfrac19\right)^{\frac{n-1}{2}}=\left(\dfrac13\right)^{n-1}$。
