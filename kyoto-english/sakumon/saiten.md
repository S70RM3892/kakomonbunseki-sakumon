# 京大英語 採点基準(自己採点・添削用、厳格版)

根拠は `analysis/scoring-research.md`(採点方法の調査)と `analysis/official-intent.md`(京大公式の出題意図)。
過去問でも `sakumon/problems/` の自作問題でも、答案はこの基準で採点する。

## この基準の立場

京大は採点基準を公表していない。成績開示で分かるのも教科別の得点までで、大問別の得点や減点の内訳は分からない。したがって **「本番と同じ点が出る基準」は誰にも作れない**。公式に確かなのは採点の「観点」だけである。

そこでこの基準は、本番の点を当てることではなく、**本番の点を上げること**を目的に設計する。

1. **観点は公式に合わせる。** 何を見るかは、京大が出題意図で明言した観点だけを使う。
2. **減点幅は厳しい側に固定する。** 幅には裏付けがないので、「1 か所ずつ引く減点法」と「全体の出来で決める相対評価」のどちらが本番でも失点になるものを、すべて引く。
3. **疑わしきは減点。** 採点者が迷いうる答案は、迷われない答案に直すまで満点にしない。
4. **点より失点の内訳を残す。** 伸びるのは点数を見たときではなく、同じ種類の失点を次回消したときである。

この基準で出る点は、本番より低く出るように作ってある。どれだけ低いかは検証できない(本番の内訳が開示されないため)。

## 配点

| 大問 | 配点 | 根拠 |
|---|---|---|
| I 読解 | 50 | 冊子に記載 |
| II 読解 | 50(英作文を含む年は 75) | 冊子に記載 |
| III 和文英訳 | 25 | 冊子に記載 |
| IV 英作文 | 25 | 冊子に記載 |

I・II の設問別配点は非公開。この基準では、下線部和訳は語数に比例して配り、内容説明は 1 問 10〜15 点を先に取る(自作の目安)。例: 和訳 2+内容説明 1 の大問なら、内容説明 12、残り 38 を和訳 2 問の語数比で分ける。

工学部は英語 150 点を 200 点に換算する。**素点 1 点は総点で約 1.33 点**。和訳の訳語 1 つ、冠詞 1 つの失点がそのまま総点に効く。

## 下線部和訳

### 手順

1. **採点前に着眼点を書き出す。** 公式の出題意図と同じ粒度で、設問ごとに「構文」「語句」「指示語・文脈」の着眼点を列挙する。50 語の下線部なら 5〜7 個が目安。過去問は `analysis/years/YYYY.md` の「難所」を使う。
2. 配点を着眼点に割り振る。構文に 6 割、語句・指示語に 4 割。
3. 答案を着眼点ごとに判定し、そのあと下の減点を適用する。

### 着眼点の判定

| 判定 | 得点 | 基準 |
|---|---|---|
| ○ | 満点 | 構造・意味とも正しく、日本語として読める |
| △ | 半分 | 構造は合っているが訳語がずれている/意味は合っているが構造を崩してごまかしている |
| × | 0 | 構造の取り違え、意味の取り違え、その部分の訳し漏れ |

- **構文の取り違えは、その着眼点だけでなく、それに依存する部分も ×。** 関係詞の先行詞を誤れば、節全体が ×。
- **設問が「〜の内容がわかるように」「〜を補足しつつ」と条件を付けているのに、指示語のまま訳したら、その着眼点は ×。**(公式が指示対象の把握を明言している。確からしさ: 高)
- **条件のない設問でも、this / it / such が下線部の外を指していて、訳文だけ読んで意味が通らない場合は △。** 本番での扱いは確認できていないが、公式は「全体の流れを踏まえた自然な日本語訳」を求めている。厳しい側に倒す。

### 全体への減点(着眼点の合計から引く)

| 失点の種類 | 減点 | 根拠の強さ |
|---|---|---|
| 訳し漏れ(語・句が訳文にない) | 1 か所 −2。節ごと抜けたら着眼点を × | 高(公式「取りこぼしなく訳出」) |
| 日本語として意味が通らない直訳 | 1 文 −2 | 高(公式「自然な日本語訳」)。幅は自作 |
| 原文にない内容の付け足し、意訳で原文の構造が確認できない | 1 か所 −2 | 低(扱いは確認できず)。厳しい側に倒す |
| 訳語の選択が文脈に合わない(多義語の第 1 語義をそのまま当てた) | 1 語 −1 | 中 |
| 誤字・脱字、漢字の誤り | 1 か所 −1(上限 −2) | 低(確認できず)。厳しい側に倒す |
| 文が完結していない(時間切れ) | 書けた着眼点だけ採点し、さらに −2 | 低(確認できず) |

下限は 0 点。

### 満点にしてはいけない答案

- 単語を順に置き換えただけで、主語と述語の対応が読み取れない訳。
- 構造が取れなかった箇所を、ぼかした日本語で通過している訳。該当の着眼点は △ ではなく ×。
- 「それ」「これ」「そのような」が 3 つ以上残り、何を指すか訳文から分からない訳。

## 内容説明・指示内容

1. **採点前に解答要素を書き出す。** 本文のどこに根拠があるかを行で特定し、要素を 2〜4 個に分ける。配点を要素に均等に割る。
2. 要素ごとに ○(満点)/△(半分)/×(0)。

| 失点の種類 | 扱い |
|---|---|
| 要素が欠けている | その要素 0 |
| 本文の該当箇所をそのまま訳して並べただけで、問いに答える形に整理されていない | 全体の上限を 7 割にする |
| 比喩・抽象表現を、具体的な内容に置き換えずそのまま書いた | その要素 × |
| 本文にない推測を書いた | 1 か所 −2 |
| 文末が問いに対応していない(「どういう意味か」に「〜から。」で終える等) | −1 |
| 字数制限の超過・大幅な不足 | 超過は −3、8 割未満は要素不足として処理 |
| 余計な内容で解答欄を埋めた | 加点しない。誤りがあれば減点 |

- 公式は「限られた字数内で要点を整理する力」「具体的な情報を踏まえつつ要約」と明言している(確からしさ: 高)。解答欄を埋める必要はない(河合塾・Z会が一致)。
- 字数超過の本番での扱いは確認できていない。0 点にする根拠はないので、重い減点にとどめる。

## 和文英訳(25 点)

### 手順

1. 和文を文ごとに区切り、25 点を文の長さに応じて配る(4 文なら 6〜7 点ずつ)。
2. 文ごとに、まず **文意が伝わるか** を判定して上限を決める。

| 判定 | その文の上限 |
|---|---|
| 日本語の内容が過不足なく伝わる | 満点 |
| 一部の内容が欠けている・ずれている | 6 割 |
| 文の主旨が変わっている、英語として意味が取れない | 2 割 |
| 白紙・途中で終わっている | 書けた部分を上の基準で判定し、さらに −2 |

3. 上限から、下の誤りを 1 か所ずつ引く。その文の下限は 0。

| 誤りの種類 | 減点 |
|---|---|
| 文構造の誤り(動詞がない、接続詞なしで文をつなぐ、関係詞の誤用、主語と動詞の不一致で意味が変わる) | −3 |
| 動詞の語法(自動詞・他動詞、取る文型、前置詞の誤り)、時制の誤り | −2 |
| 語彙の選択が不適切で意味がずれる、コロケーションが不自然 | −2 |
| 冠詞、単数・複数、三単現、スペル | 各 −1(同じ語の同じ誤りは 1 回だけ数える) |
| 日本語の語句の訳し落とし | −2(文意に関わる語なら上限を 6 割に下げる) |
| ことわざ・慣用句を逐語訳して意味が通らない | 上限を 6 割に下げる |
| 文と文の論理関係(逆接・理由)を落とした | −2 |

### 減点しないもの

- **意味を保った平易な言い換え。** 難しい語を避けて中学レベルの語で言い直しても、内容が伝わっていれば満点。公式の観点は「文意を正しく伝えながら、英語として自然な表現や適切な語彙」であり、Z会・河合塾の講評も一致している(確からしさ: 中〜高)。
- 文を 2 つに切る、主語を補う、語順を入れ替える、といった構成の変更。

### 減点するもの(言い換えと取り違えやすい)

- 訳しにくい箇所を **飛ばした** 言い換え。内容が減っていれば訳し落とし。
- 自信のない難語・凝った構文を使って誤った場合。**挑戦は加点しない。誤りだけを数える。**

減点幅は裏付けのある数字ではない。個人サイト 1 件の推定(小さなミス −1、重大な文法ミス −2〜3、意味の取り違え −3〜5、訳漏れ −2〜4)と、Z会の採点例(大きな文法ミスのない答案が、訳し落としと文意のずれで 11/25 点)を踏まえ、厳しい側に置いた。

## 自由英作文(25 点)

公式の 5 観点(条件遵守・構成・論理・語句・文法)で採る。独創性は公式の観点にないので採点しない。

| 観点 | 配点 | 基準 |
|---|---|---|
| 条件遵守 | 3 | 語数が範囲内、指定された要素(主張文・論証・総括文など)がすべてある。1 つ欠けるごとに −1.5 |
| 構成 | 5 | 導入(主張)→ 展開(根拠・例)→ 結論 が段落内で見て取れる。結論が主張の単なる繰り返しでも可。どれか欠ければ 2 以下 |
| 論理 | 7 | 根拠が主張を実際に支えている。飛躍・同語反復・主張とずれた例は各 −2。根拠が 1 つしか機能していなければ 4 以下 |
| 語句・文法 | 10 | 10 点から、和文英訳と同じ減点表で引く(下限 0) |

追加の扱い:

- **語数違反は条件遵守 0 に加え、全体から −3。** 本番での扱いは確認できていないが、解答用紙は 1 行 4 語のマス目で 20 語ごとに印があり、採点者には一目で分かる(河合塾)。失格とする根拠はないので重い減点にとどめる。
- 問いに答えていない(論題のすり替え)は、論理 0・構成の上限 2。
- 暗記した汎用の文章で、論題に固有の内容がない場合は論理の上限 3。
- 語数稼ぎの重複は加点しない。

### 会話文の空所補充(条件英作文)の場合

空所ごとに配点を等分し、(a) 前後の発言とつながるか(つながらなければ 0)、(b) 語数・使用語句の条件(違反は半分)、(c) 文法・語法(和文英訳の減点表)で採る。

## 記録の付け方

採点のたびに、点数と一緒に失点を次の分類で数える。次に解く前に、前回の上位 3 分類を読み直す。

| 記号 | 分類 |
|---|---|
| S | 構文の取り違え(関係詞・並列・修飾の範囲・省略) |
| R | 指示語・文脈(指示内容を取らなかった、文脈に合わない訳語) |
| V | 語彙(知らなかった、多義語の語義を外した、推測しなかった) |
| O | 訳し漏れ・訳し落とし |
| J | 日本語の不自然さ、誤字 |
| G | 英語の文法・語法(冠詞・単複・時制・動詞の型) |
| W | 英語の語彙選択・コロケーション |
| P | 和文の読み替え不足(逐語訳、主語の補い忘れ、論理関係の欠落) |
| L | 英作文の論理・構成・条件 |
| T | 時間切れ |

## 目標点

情報学科の英語の合格者平均は公表されていない。手がかりは次のとおり。

- 情報学科の合格者総点(京大公式): 最低点は得点率 62〜70%、平均点は 68〜74%(2023〜2026)。
- Z会の再現答案分析: 2022 年度の合格者平均 99.6/150、不合格者 90.4/150(全学部混合)。2016 年度の工学部合格者 11 人は 76〜110 点、平均 90.7 点。

これらから、本番の目安は **100 点で合格ライン相当、110 点で安全圏**(総点の得点率を英語に当てはめた試算で、裏付けのある数字ではない)。

この基準は本番より低く出るように作ってあるので、**この基準で 100 点を安定して超えること**を目標にする。この基準で 85〜90 点なら本番で合格ライン付近に届く可能性はあるが、どれだけ上振れするかは検証できないので当てにしない。

## この基準の限界

- 減点幅はすべて自作。本番の幅を裏付ける一次情報は存在しない。
- 本番が減点法か、全体の出来による評価かも分かっていない。個人の証言は 2 件で互いに食い違う。
- 東進「京大本番レベル模試」の採点基準(模試の減点幅を具体的に書いた公開資料)は取得できず、読めていない。読めたら和訳の減点幅を見直す。
- 駿台・河合塾の京大模試の採点基準、青本・赤本の記述は Web では確認できない。模試を受けたら、返却された採点基準とこの基準を突き合わせて直す。
- 意訳しすぎ、誤字、未完成答案、字数・語数違反の本番での扱いは確認できず、すべて厳しい側に倒してある。
