# 京大英語 過去問分析コードブック

各年度の問題を同じ物差しで記録するための基準。年度別ファイル(`years/YYYY.md`, `data/YYYY.json`)はすべてこの基準で書く。

## 分析単位

大問(I〜IV)。大問が独立した複数の課題に分かれる場合(和文英訳の (1)(2)、(A)(B) など)は、その各パートを 1 単位(part)とする。
読解問題は 1 つの英文につき 1 単位とし、設問は `questions` に列挙する。

## 大問の型(`format`)

- `英文読解` : 英文を読ませ、下線部和訳・内容説明などを課す
- `和文英訳` : 日本語の文章(または下線部)を英訳させる
- `自由英作文` : 語数や条件を指定して自分の考え・説明を英語で書かせる
- `条件英作文` : 会話文や文章の空所を、文脈に合う英語で埋めさせる(京大 2016 年度以降の会話文型など)
- `その他` : 上記に当てはまらないもの(note に説明)

## 設問の型(`questions[].type`)

- `下線部和訳` : 下線部を日本語に訳す
- `全文和訳` : 下線なしで段落・全文を訳す
- `内容説明` : 下線部や本文の内容を日本語で説明する(字数・行数制限があれば `limit` に書く)
- `理由説明` : 「なぜか」を日本語で説明する
- `指示内容` : 指示語・代名詞・語句が指す内容を答える
- `空所補充(選択)` : 選択肢から語句を選ぶ
- `空所補充(記述)` : 語句を自分で書く
- `語句整序`
- `内容一致(選択)`
- `要約`
- `英語での説明` : 本文内容について英語で答える
- `和文英訳`
- `自由英作文`
- `条件英作文`

## 英文(passage)の記録

- `words` : 語数の概算(行数×1行の平均語数で見積もる。±10% の精度でよい)
- `genre` : `評論・論説` / `科学解説` / `エッセイ・随筆` / `小説・物語` / `伝記・回想` / `その他`
- `field` : 主題分野を一語で(哲学、言語、心理、科学論、生物、歴史、教育、芸術、技術・AI、社会、経済、環境、文学 など)
- `abstractness` : 抽象度
  - `A1` 具体的な出来事・事例・実験の記述が中心
  - `A2` 具体例と抽象的主張が交互に出る(標準的な評論)
  - `A3` 抽象概念の議論が中心で、具体例が乏しい/比喩的(哲学・思想系)
- `source` : 冊子に出典の記載があれば著者・書名。なければ空文字(推測で書かない)
- `glossary` : 注(語注)が付いている語の数
- `omitted` : 著作権の都合で英文が PDF から省略されている場合 true(その場合は設問から分かる範囲だけ記録)

## 語彙レベル(その場で推測させる語の判定)

化学分析の「範囲外度」に相当する物差し。**下線部・設問の解答に関わる語句**について判定する。

| レベル | 定義 | 例 |
|---|---|---|
| V0 | 共通テストレベルの基本語 | important, environment |
| V1 | 標準的な受験単語帳(システム英単語・鉄壁・ターゲット1900 レベル)に載る語 | inevitable, comprise, subtle |
| V2 | 単語帳には通常載らないが、**文脈・語源・接辞・言い換えから意味を推測できる**ように書かれている語 | 文中で直後に言い換えがある専門語、de-/-ify などで分解できる語 |
| V3 | 単語帳に載らず、文脈からの推測も難しく、注もない語(知らないと訳せない) | まれ |

- 基本語の**意外な語義・多義**(例: `address` 対処する、`become` 似合う、`for all` にもかかわらず)は別枠 `多義・熟語` として記録する。
- 迷ったら低い方に倒す。
- V2 の本質は「知らない語を、文脈から意味を決めて訳語に落とす」作業が要求されること。

## 構文上の難所(`syntax_features`)

下線部・和訳対象に現れるものを、次の語彙から選んで列挙する(該当なしは空)。

`倒置` / `省略` / `挿入` / `同格` / `強調構文` / `比較(no more than 等の慣用含む)` / `否定(部分否定・二重否定・準否定)` / `仮定法` / `関係詞(連鎖・二重限定・前置詞+関係詞・what節)` / `分詞構文` / `無生物主語` / `名詞構文` / `共通関係(A and B の並列把握)` / `長い主語・修飾の入れ子` / `it の形式主語・目的語` / `as/that/of の用法識別` / `代名詞・指示語の特定` / `比喩表現の訳出`

## 和文英訳の記録

- `ja_chars` : 英訳対象の日本語の文字数(概算)
- `ja_style` : `随筆調` / `論説調` / `口語・会話` / `説明文`
- `paraphrase_level` : 和文和訳(日本語の読み替え)の必要度
  - `J0` ほぼ直訳で書ける
  - `J1` 一部の語句をやさしい日本語に言い換える必要がある(慣用句・擬態語・和語的表現が 1〜2 か所)
  - `J2` 主語の補い・文の切り直し・比喩や含意の解釈など、文全体の再構成が必要
- `key_expressions` : 差がつく日本語表現とその処理方針(例: 「〜にこしたことはない」→ nothing is better than / it is best to)。3〜6 個

## 自由英作文・条件英作文の記録

- `word_limit` : 語数指定(なければ解答欄の行数など)
- `task` : `意見論述` / `理由説明` / `状況説明` / `会話の空所補充` / `文章の続き` / `手紙・メール` / `図表の説明` / `その他`
- `prompt_summary` : 何を書かせるかの要旨(1〜2 文)

## 難易度

京大受験生(合格ライン付近)目線の 4 段階: `易` / `標準` / `やや難` / `難`。理由を一言添える。

- `points` は冊子に配点の記載があるときだけ数値を入れる。なければ `null`(推測しない)。
- `target_words` は下線部(和訳・説明対象)の語数の概算。対象が本文全体の内容なら `null`。
- `context_dependent` は、下線部だけでは訳語・指示内容が決まらず、下線部外の文脈を読む必要がある場合 true。
- `vocab_items` は V2 以上のみ列挙。なければ空配列。`max_vocab_level` はそのパートで解答に関わる語の最高レベル(V2 以上がなければ `V1`)。
- 英文読解以外のパートでは `passage` を省略し、`ja_translation` または `composition` を書く。条件英作文で会話文・文章が付く場合は `passage` も書く。

## Markdown(`years/YYYY.md`)

人間が読む用。構成は以下。

```
# 京大英語 YYYY年度
## 全体
- 冊子ページ数、大問数、配点、形式の前年からの変化
## 大問I(型/主題)
- 英文: 語数、ジャンル、分野、抽象度、論旨の流れ(段落ごとに1行)
- 設問: 設問ごとに1行(型、対象の語数、何が問われているか)
- 難所: 構文・語彙(V2 以上と多義語)・文脈依存の箇所を具体的に。語句の引用は数語まで
- 得点の核心・差がつく点
- 作問メモ: この問題の「型」(作問時に再利用できる構造)を1〜3行
## 大問II …
## 大問III(和文英訳/主題)
- 和文: 文字数、文体、内容の要旨
- 難所: 和文和訳が必要な表現と処理方針
- 得点の核心・差がつく点
- 作問メモ
```

## 著作権上の決まり

- 問題文(英文・和文)の逐語的な転記はしない。要旨と構造を書く。
- 難所の指摘に必要な語句の引用は、1 か所につき数語〜1 文未満にとどめる。
- 模範解答(全訳・英訳例)は年度別ファイルには書かない。処理方針だけ書く。
