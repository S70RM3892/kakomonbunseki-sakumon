# 京大物理 作問設計図

`analysis/trend.md` の結果を、作問に使える形に落としたもの。作った問題は `sakumon/problems/` に 1 題 1 ファイルで置く。

## 京大物理の大問の骨格

過去 17 年の大問はほぼ次の 5 段で組まれている(L2 の有無によらない)。

1. **基本設定の確認**: つりあい、保存則、基本公式で埋まる空欄を 3〜5 個(易)。文字の定義をここで覚えさせる。
2. **設定の変更(1 回目)**: 固定していたものを動かす、スイッチを切り替える、物体を 1 つ足す。同じ法則を立て直す(標準)。
3. **近似・モデル化**: 微小量の近似式を与えて線形化する、または現象を粗いモデルに置き換える(標準〜やや難)。
4. **前半の結果の転用**: (1)(2) で得た式を別の状況に当てはめる。選択式の空欄 { } で増減・向き・大小を判断させる(やや難)。
5. **問(記述・描図)**: 理由の説明、導出過程、グラフ・軌道の作図、数値見積もり。1 大問に 1〜3 問(差がつく)。

守るべき制約:

- 文字式の空欄が 7 割。空欄は「直前までに定義された文字だけ」で書けること。使用文字を明示する。
- 本文は 55〜75 行、空欄+問で 15〜18 個、図 3〜5 枚。**答え 1 個あたりの本文は I で 3 行、II・III で 4〜4.5 行**(2021〜2026 の実測)。途中結果や方針は空欄にせず本文で与え、答えを詰め込みすぎない。想定時間 30 分(理科 2 科目 180 分、物理 3 題)。
- 飛び抜けた難問は作らない(17 年で「難」はゼロ)。標準 2 : やや難 1 の配分で、後半に向けて段階的に上げる。
- 近似を使うなら、近似式は問題文で与える((1+x)^a ≒ 1+ax、sinθ ≒ θ、cosθ ≒ 1 など)。
- 選択式の空欄を 2〜4 個入れる(近年の傾向)。
- 答は一意に決まること。前の空欄を間違えても後ろが全滅しないよう、途中で文字を置き直す。

## 型A: 力学(大問 I)— 2 体系と拘束の切り替え

先例: 2010 I、2014 I、2016 I、2020 I、2024 I、2025 I、2026 I

構造: 2 物体を何か(ばね、糸、棒、斜面台)でつなぐ → 片方を固定した場合 → 自由にした場合(運動量保存、重心運動+相対運動)→ 拘束が切れる・たるむ・離れる条件 → その後の運動のグラフ。

未出題で作りやすい題材:

| 題材 | 切り替える拘束 | 最後に問うもの |
|---|---|---|
| 動く台上の単振り子(台に摩擦のある区間) | 台の固定/自由/摩擦 | 周期の比、重心の軌跡 |
| ばねでつないだ 2 物体を壁に押しつけて放す | 壁から離れる瞬間 | 離れた後の重心速度と相対振動の振幅 |
| 滑車を介した 3 物体(アトウッドの器械の変形) | 糸の張り/たるみ | たるむ条件、再び張るときの速度 |
| 回転する棒上のビーズとばね | 回転数 | つりあいの安定性、微小振動の周期 |
| 楕円軌道上での分離・合体 | 分離の向き | 分離後の軌道の周期比 |

## 型B: 電磁気(大問 II)— 力学への読み替えと過渡現象

先例: 2013 II、2016 II、2020 II、2021 II、2024 II、2026 II

構造: 回路または電磁場中の物体 → 運動方程式/回路の式を差分形(Δv/Δt, ΔQ/Δt)で書かせる → 単振動や終端速度との対応を指摘させる → エネルギー収支を確認 → 時間変化のグラフ。

未出題で作りやすい題材:

| 題材 | 対応させる力学 | 最後に問うもの |
|---|---|---|
| 導体棒+コンデンサー(レール上) | 質量が増えた物体の等加速度運動 | 見かけの質量 m + CB²ℓ² |
| 導体棒 2 本の相互作用 | 非弾性的な速度の緩和 | 終状態の速度と失われるエネルギー |
| LC 回路+スイッチ切り替え(整流・倍電圧) | 単振動の半周期 | n 回後の電圧 |
| 磁場中を落下する輪(非一様磁場) | 速度に比例する抵抗 | 終端速度、ジュール熱 |
| 直交電磁場中のサイクロイド運動 | 等速直線+等速円運動の合成 | 到達高さ、ドリフト速度 |

## 型C: 熱(大問 III)— 理想気体の手順を別の系でやり直す(L2 型)

先例: 2022 III(ゴムひも)、2025 III(2)(光子気体)、2020 III(二原子分子)、2018 III(重力場中の気体)

構造: 前半で理想気体の手順(第一法則、定積・定圧・断熱、ポアソンの式の導出、サイクル)を空欄で復習 → 後半で「状態方程式」と「内部エネルギー」を別の式で与える → 同じ手順で断熱の式・熱容量・熱効率を導く → 理想気体との違いを 1 問で説明させる。

**新しく与えるモデルは 1 つ、式は 2 本まで**(状態方程式と内部エネルギー)。名称は伏せる(「光子気体」「エントロピー」とは書かない)。

未出題で作りやすい題材:

| 題材 | 与えるもの | やり直させる手順 |
|---|---|---|
| ファンデルワールス気体 | (P + a/V²)(V − b) = RT、U = C_V T − a/V | 自由膨張での温度変化、断熱の式 |
| 表面張力のある液膜 | 力 F = 2σℓ、内部エネルギー | 膜を広げる仕事と吸熱 |
| 常磁性体(磁化と磁場) | M = CB/T、仕事 −MΔB | 断熱消磁による冷却 |
| 1 次元気体・2 次元気体 | 自由度に応じた U | ポアソンの式の指数 |
| 重力場中の気体柱+ピストン | 密度分布(指数関数解を与える) | 重心の高さ、比熱 |
| 弾性棒・ばねの熱力学 | 張力が温度に依存 | ゴムひも(2022)との対比 |

## 型D: 波動・原子(大問 III)— 既習の干渉条件を新しい装置に当てる

先例: 2015 III(スペクトル線の幅)、2019 III(多重反射)、2021 III(中性子干渉計)、2023 III(偏光・波長板)、2024 III(光ファイバー)

構造: 教科書どおりの干渉・屈折を確認 → 装置を 1 段複雑にする(経路を 1 本足す、媒質を足す、動かす)→ 位相差を文字式で → 近似して測定量と結びつける → 実験データ(図)から数値を出す。

未出題で作りやすい題材:

| 題材 | 与えるもの | 最後に問うもの |
|---|---|---|
| マイケルソン干渉計+動く鏡 | 光のドップラー(式なし) | うなりの振動数と干渉縞の移動の一致 |
| サニャック干渉計(回転する光路) | 2 経路の時間差 | 回転角速度の測定 |
| 回折格子の分解能 | N 本のスリットの重ね合わせ | 2 本の線を分けられる条件 |
| 電子線の結晶回折と内部ポテンシャル | 屈折率に相当する量(2021 III の電子版) | ブラッグ角のずれ |
| コンプトン散乱+動く電子 | なし(保存則のみ) | 逆コンプトンでの波長変化 |
| 光てこ・レーザー冷却 | 光子の運動量 | 1 回の吸収・放出での速度変化と停止までの回数 |

## 優先順位

1. まず「繰り返し出る型」(`analysis/trend.md` の表)を型A・型B で作る。再出題の実績が最も多く、得点への寄与が最大。
2. 次に型C を未出題題材で作り、**未知の状態方程式を 5 分で読んで理想気体の手順を当てはめる**訓練にする。直近 6 年の L2 はここに集中している。
3. 型D は干渉と光のドップラーを軸に、頻度に応じて少なめに。

## 1 題のファイル形式

ファイル名は `problems/sNN-qK_分野_題材.md`(NN = セット番号、K = 大問番号 1〜3)。1 セット = 大問 3 題(I 力学、II 電磁気、III 熱・波動・原子)。
`node build-pdf.mjs` で `pdf/NNセット/問題/` と `pdf/NNセット/回答/` に、大問ごとの PDF(問題と解答・解説)を出力する。図は `problems/figures/` に SVG で置く。
問題 PDF は京大の問題冊子の体裁(表題「物理」、見出し「物理問題 Ⅰ」、枠つき空欄、{サ:①…} 形式の選択肢、問 1、図番号、ページ番号)に寄せて組む。md 側の書き方は `build-pdf.mjs` の冒頭を参照。問題文は本番と同じく読点に全角コンマ(,)を使う。

```
---
set: 1
daimon: 1
field: 力学
title: 題材名
---
# タイトル(型 / 題材 / 想定時間 / 難易度)
## 問題
## 解答
## 解説(どこで設定が切り替わり、何を転用するか)
## 出典・検証(与えた事実の典拠URL、極限・次元・数値の検算)
```

問題文中で与える範囲外の事実(式、定数、モデル)は、必ず信頼できる典拠で確認してから使う。
答はすべて、次元と極限(質量比 → 0、∞ など)で検算する。
