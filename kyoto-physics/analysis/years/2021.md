## 大問I(力学/斜方投射と一次元弾性衝突の繰り返し)

- 流れ: 質量 m の小球を初速 V、角度 θ で投げ上げ、最高点(高さ h0)を過ぎて高さ h の点で、質量 M のボールを小球と同じ速さ V0 で正面から一次元的に弾性衝突させる。衝突軸はボールの進行方向が正。
  - ア: V0 =(√(V² − 2gh))
  - イ: sinθ1 =(√(V² sin²θ − 2gh)/√(V² − 2gh))
  - ウ: mv1 + Mw1 =((M − m)V0)
  - エ: 1 = −(v1 − w1)/エ(−2V0)
  - オ: v1 =((3M − m)V0/(M + m))
  - カ: w1 =((M − 3m)V0/(M + m))
  - キ: w1 = 0 となる M/m(3)
  - ク: そのときの v1/V0(2)
  - ケ: h1 =(2V² sin²θ/g − 3h)
  - (2) 落下してくる小球に高さ h で毎回ボール(速さ V0、衝突後静止する質量 Mn)を当てる。vn = an V0。
  - コ: an =(a(n−1) + 1)
  - サ: an =(n + 1)
  - シ: hn =((n + 1)² V² sin²θ/(2g) − n(n + 2)h)
  - 問1(i): 運動量保存 Mn V0 − m a(n−1) V0 = m an V0 より Mn = (2n + 1)m((2n + 1) 倍)
  - 問1(ii): 2n + 1 ≦ 10 より n = 4 まで。h = 0 では h4 = 25 h0(25 倍)
- その場で与えられた知識: なし(「一次元的に衝突」「衝突軸」「速度成分」は用語の取り決めで、既習の1次元衝突そのもの)。
- 解法の核心・差がつく点: 放物運動の対称性から、小球は毎回同じ高さ h に同じ速さ・同じ角度 θ1 で戻る。衝突は軸上の1次元問題で、反発係数の式から an = a(n−1) + 1 が直ちに出る。hn は鉛直成分 (n+1)V0 sinθ1 から。
- 作問メモ: 「定番の2体衝突を、条件(衝突後ボール静止)付きで n 回繰り返して漸化式にする」型。斜方投射と組み合わせ、衝突を軸方向の1次元に落とす取り決めで計算を軽くしている。最後に質量の上限という現実的制約から回数を決めさせて数値で締める。未習事項ゼロで、京大としては易しめ。

## 大問II(電磁気/往復回転する導体棒の誘導起電力と RC 回路の過渡現象)

- 流れ: 半径 L の円弧導線 XY、中心 O を支点に回転する導体棒 OP、OY 間に抵抗 R とコンデンサー C。半円領域に磁束密度 B(裏から表)。棒は角速度 π/T で X → Y(0〜T)、Y → X(T〜2T)と瞬間的に折り返して往復する。
  - イ: 起電力(πBL²/(2T))
  - ロ: t = 0 の電流(πBL²/(2RT))
  - ハ: 抵抗のジュール熱 = ハ × Δt(RI²)
  - ニ: 静電エネルギーの増加 = ニ × Δt(QI/C)
  - ホ: 両者の和 = ホ × Δt(πBL²I/(2T))
  - ヘ: 電流が 0 とみなせるときの Qc(πBL²C/(2T))
  - ト: t = 0 の接線が Q = Qc と交わる時刻 tc(RC)
  - 問1: T ≦ t ≦ 2T の Q のグラフ。Q = Qc から −Qc へ向かって指数関数的に減少。t = T の接線は傾き −2Qc/tc で、t = T + tc で Q = −Qc の線と交わる(起電力が反転し、抵抗にかかる電圧が 2 倍になるため)。
  - (3) x = e^{−aT}(a = 1/tc)として
  - チ: Q(T) =(1 − x)× Qc
  - リ: Q(2T) =(−(1 − x)²)× Qc
  - ヌ: Q(3T) =((1 − x)(1 − x + x²) = 1 − 2x + 2x² − x³)× Qc
  - 問2: 定常では −Qm = −Qc + (Qm + Qc)x より Qm/Qc = (1 − x)/(1 + x) = 4/9、x = 5/13 ≒ 0.385。1/e ≒ 1/2.72 ≒ 0.368 より x > 1/e、すなわち T/tc < 1 で、T は tc より(わずかに)小さい。
- その場で与えられた知識:
  - [L2] RC 回路の式の解(指数関数): 「キルヒホッフの第2法則は V(t) = R ΔQ(t)/Δt + Q(t)/C と書くことができ、Q(t) についての解が求められることが知られている」「V(t) が一定であるとすると…解は Q(t) = Q∞ + (Q0 − Q∞)e^{−a(t−t0)} と表すことができる」。Q0 は区間の初めの電気量、Q∞ は十分時間がたって電流が 0 とみなせるときの電気量、e ≒ 2.72 は自然対数の底、a = 1/tc。チ・リ・ヌで区間ごとに Q0 と Q∞(= ±Qc)を入れ替えて適用し、問2で周期定常の条件と x と 1/e の比較に使う。
  - [L1] 時定数 tc = RC を初期接線から求める: 「時刻 t = 0 における接線の傾きが、出発した直後の微小時間における電気量の変化を表すことに注意すると」と誘導(「時定数」の語は出ない)。ト、問1で使用。
- 解法の核心・差がつく点: 棒が折り返すと起電力の符号が反転し、Q∞ が +Qc ↔ −Qc と切り替わる。式(iii)に「どの値を Q0、Q∞ に入れるか」を区間ごとに判断するだけだが、符号の扱いで差がつく。問2は「最大値と最小値が一定」= 1 往復で元に戻る条件を自分で立て、e ≒ 2.72 を使って大小を判定する。
- 作問メモ: 「教科書では定性的にしか扱わない過渡現象について、指数関数の解を一般形(初期値・終端値・時定数)で与え、駆動の向きを周期的に反転させて区間ごとに使わせる」型。前段で (a) 終端値 Qc、(b) 初期接線から tc = RC を既習の範囲で求めさせ、与えた式の各パラメータの意味を先に体験させているのが丁寧。最後は等比的な収束先(周期定常)を問う。

## 大問III(原子・波動/ブラッグ反射の屈折率補正と中性子干渉計による重力の観測)

- 流れ: (1) 面間隔 d の結晶による X 線の反射。(2) 結晶中の屈折率 n(1 よりわずかに小さい)を考慮した条件。(3) 中性子のド・ブロイ波を結晶で2経路に分け、平行四辺形 ABCD(辺 AB は水平面上、AB と DC の間隔 s)を回って再び重ねる。平面 Σ を水平から角度 α だけ傾ける。
  - あ: 経路差(2d sinθ)
  - い: 強め合いの条件(2d sinθ = kλ)
  - う: cosθ と cosθ' の関係(cosθ = n cosθ')
  - え: λ' =(λ/n)
  - お: 位相の差(4πd√(n² − cos²θ)/λ)
  - か: 強め合いの条件(2d√(n² − cos²θ) = kλ)
  - き: α = π/2 のとき辺 DC での波長(λ0 v0/√(v0² − 2gs))
  - 問1: 位相差は辺 AB(波長 λ0)と辺 DC(波長 き)の長さ ℓ の部分だけで生じ(AD と BC は同等)、2πℓ(1/λ0 − 1/λ) ≒ 2πgsℓ/(λ0 v0²) = 2πm²gsℓλ0/h²。
  - 問2: 傾き α では高低差が s sinα になるので位相差 = 2π(m²g/h²)λ0(ℓs)sinα = 2π × 8.75 sinα。
    - (i) 8.75 sinα が整数になる回数。α > 0 では 1〜8 の 8 回。出発点 α = 0(位相差 0)を数えれば 9 回(要検証: α = 0 を含めるかどうかで答が変わる)
    - (ii) 8.75 sinα = 0.5 より sinα ≒ 0.057
- その場で与えられた知識:
  - [L1] X 線に対する結晶の屈折率: 「原子と X 線の間にはたらく力により…屈折率の形で表すと、結晶中の屈折率 n は 1 よりごくわずかに小さい値を持つ」。う〜か で屈折の法則と光路長に使う(法則自体は既習)。
  - [L1] 位相差の定義と強め合い条件: 「(位相の差)が 2π の整数倍の場合には X 線が強め合う」。お・か、問1・問2で使用。
  - [L0 相当・記録のみ] ド・ブロイ波 λ = h/(mv): 式を与えているが教科書本文の内容。
  - [L1] 中性子干渉計の扱い: 「ド・ブロイ波の周期 T は2つの経路で変化せず、位相の差は波長の違いのみで決まる」「結晶中の屈折率は近似的に n = 1」「軌道は重力によって影響を受けない」と仮定を列挙。問1で使用。
  - [L1] 近似式 √(1 − x) ≒ 1 − x/2: 問1で使用。
- 解法の核心・差がつく点: お は「結晶内の経路 2d/sinθ' を波長 λ/n で数え、外側の経路差 2d cosθ cosθ'/sinθ' を引く」と 2nd sinθ' にまとまる。(3) は力学的エネルギー保存で速さ → 波長を出し、位相差が平行四辺形の面積 ℓs に比例することに気づけば問2は数値代入だけ。
- 作問メモ: 「定番の干渉条件(ブラッグ)を (a) 媒質の屈折率で補正し、(b) 波を物質波に替えて力学(重力による減速)と接続する」二段発展型。実在の有名実験(中性子干渉計による重力効果の検証)を、ド・ブロイ波長とエネルギー保存だけで追える形に落としている。与えた定数を m²g/h² のかたまりにして数値計算を1回の掛け算にしているのも参考になる。

### 判定の注

- II の L2: RC 回路の指数関数解は現行教科書の本文では扱わず(充電・放電のグラフを定性的に示す程度)、自然対数の底 e を含む解の式を与えて使わせるので L2(数学手法の提示)とした。適用は代入だけで軽いが、式なしでは (3) と問2は解けない。時定数 RC を初期接線から求める部分は受験定番で L1。
- III は L1 にとどめた。X 線の屈折率が 1 より小さいこと、中性子干渉計は題材として範囲外だが、解くのに使う法則はすべて既習で、新しい量や式は与えられていない(novel_context に記録)。
- III 問2(i) は α = 0 での強め合いを回数に含めるかで 8 回/9 回に分かれる。
