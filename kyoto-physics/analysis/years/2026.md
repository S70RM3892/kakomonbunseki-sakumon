## 大問I(力学+電磁気/動く斜面台と、磁場中で円運動する荷電物体との衝突)

- 流れ: 水平な床の上の斜面台(質量 M、傾角 θ)と小物体 A(質量 m、高さ h から静かに置く)。(1) 斜面台の固定・摩擦の有無を変えた3条件。(2) 鉛直上向きの一様磁場中で、床の上を円運動する荷電物体 C(質量 m、電荷 Q)。(3) 斜面台から出た A が、円運動中の C と点 P で正面衝突する(真上から見た図)。速度は右向きを正。
  - (1)(a) 斜面台固定・摩擦なし
    - ア: A にはたらく合力の鉛直成分(上向き正)= −mg sin²θ
    - イ: 床に達するまでの時間 = (1/sin θ)√(2h/g)
    - ウ: 水平運動に移ったあとの速さ = √(2gh)
  - (1)(b) 斜面台は自由、A と斜面の間に動摩擦力あり
    - エ: u1 = (−m/M) × v1(水平方向の運動量保存。摩擦は内力)
  - (1)(c) 斜面台は自由、摩擦なし
    - オ: A の速度 = √(2Mgh/(M+m))
    - カ: 斜面台の速度 = −(m/M)√(2Mgh/(M+m)) = −m√(2gh/(M(M+m)))
  - 問1(導出): 逆向きの同じ斜面台(質量 M、自由)をもう1つ置き、A が右の斜面台を登る最高点の高さ h' = M²h/(M+m)²。A と右の台が同じ速度 mv/(M+m) になるときが最高点で、mgh' = (1/2)mv²·M/(M+m)、v² = 2Mgh/(M+m)。
  - (2)
    - キ: 上から見て時計回り、磁場は鉛直上向き → Q は ①正
    - ク: 磁場から受ける力の大きさ = QVB
    - ケ: 向心力の大きさ = mV²/R
    - コ: V = QBR/m
  - (3)(a) A(速さ v、右向き)と C(速さ V、点 P では左向き)が弾性衝突し、ともに逆向きにはね返る
    - サ: 衝突後の C の円運動の半径 = R·V1/V
    - 問2(導出): 等質量の弾性衝突なので速度交換。w = V、V1 = v
    - 問3(導出): A が速さ w で左へ進み、速さ u で左へ進む斜面台に追いついて登る。同じ速度 (mw+Mu)/(m+M) になったときが最高点で、H = M(w−u)²/(2g(M+m))
  - (3)(b) A と C が合体して F になる
    - シ: F の速度(右向き正)= (v−V)/2
    - ス: 運動エネルギーの比 = (v−V)²/(2(v²+V²))
    - セ: (v−V)² < v²+V² なので常に 1/2 未満 → ④半分より減少
  - 問4(図示): v = (3/2)V のとき F の速度は右向きに V/4、質量 2m、電荷 Q(A は電荷 0)。半径は 2m·(V/4)/(QB) = R/2。P で右向きに動く正電荷は磁場から −y 向きの力を受けるので、軌道は P で x 軸に下から接する半径 R/2 の円(中心 (0, −R/2)、最下点 (0, −R))、向きは時計回り。
- その場で与えられた知識: なし(L0)。
- 解法の核心・差がつく点: 全体として運動量保存と力学的エネルギー保存の繰り返し。(1)(b) は摩擦があっても水平方向の運動量は保存する点、問3 は「動いている台に追いついて登る」ので相対速度 w−u と換算質量で整理できる点、問4 は合体後も電荷は Q のままで質量だけ 2 倍になる点と、C の衝突前の速度が P では左向きである点(時計回りの円の最下点)で差がつく。セ は v、V がともに正であることから比が必ず 1/2 未満になることを見抜く。
- 作問メモ: 「別々の定番設定(動く斜面台/ローレンツ力による円運動)を小問 (1)(2) で個別に確認し、(3) で1つの図に重ねて衝突させる」型。衝突を弾性・完全非弾性の2通りにし、衝突後の軌道(半径と向き)を図示させて締める。新しい知識は使わず、組み合わせだけで見慣れない設定を作っている。

## 大問II(電磁気/ターンテーブル上の導体にはたらく力、微小振動、電磁誘導)

- 流れ: 質量の無視できる絶縁体のターンテーブル(鉛直軸まわりに摩擦なく回る)の上に導体を立てる。(1) 一様磁場中の2本の棒状導体のつり合い。(2) 長い直線電流がつくる磁場中で、正方形の導体枠が等速円運動する条件。(3) 一様磁場中の正方形枠の微小振動。(4) 電源を外した枠を一定の角速度で回したときの誘導起電力とジュール熱。冒頭で「微小な角度 α に対して sin α ≒ α」を与える。
  - (1) x 軸正の向きに一様磁場 B。点 D(O から d)と点 L(O から ℓ、反対側)に長さ h の導体
    - イ: D の導体(鉛直上向きに I_D)が受ける力の大きさ = I_D B h(y 軸正の向き)
    - ロ: 回転しないためには L の導体にも鉛直上向きの電流が必要 → ①(図1(c)で、導体上端から導線へ出ていく向き)
    - ハ: I_L = I_D d/ℓ(O まわりの力のモーメントのつり合い)
  - (2) 磁場を除き、D の導体を十分長い直線導体にする。L の導体の代わりに一辺 ℓ の正方形枠を線分 OL 上に鉛直に立てる(L 上の辺だけ質量 M)
    - ニ: 点 O での磁束密度 = μI_D/(2πd)
    - ホ: 点 L での磁束密度 = μI_D/(2π(d+ℓ))
    - ヘ: 角速度 ω で回しながら枠の固定をはずしても動かない → 枠全体が受ける力の合力が O 向きの向心力になる。磁場は O 上の辺のほうが強く、合力の向きは O 上の辺が受ける力で決まるので、O 上の辺が D 向き(L から見て内向き)の力を受ければよい。O 上で上向き、上側の辺で O→L、L 上で下向きに流れる → ①(上側・下側の辺が受ける力は鉛直方向で打ち消し合う)
    - ト: I_L ℓ (μI_D/2π)(1/d − 1/(d+ℓ)) = Mℓω² より I_L = 2πMω²d(d+ℓ)/(μ I_D ℓ)
  - (3) D の導体を除き、y 軸正の向きに一様磁場 B。線分 OL を x 軸から微小角 θ だけ反時計回りに回して静止させ、枠に I_L を流す
    - チ: 時計回りに動き始める → L 上の辺が x 軸正の向きの力を受ける → L 上で下向き(上側の辺で O→L)→ ①
    - リ: L 上の辺が受ける力の大きさ = I_L B ℓ
    - ヌ: 力の OL に垂直な成分 = (−I_L B) × Y(Y ≒ ℓ × 角度)
    - ル: OL が x 軸と平行になるまでにこの力がする仕事 = (I_L B ℓ²/2) × θ²
    - ヲ: 質量 M の単振動(角振動数 √(I_L B/M))の半周期。T = π√(M/(I_L B))
  - 問1(図示): Y = ℓθ cos(πt/T)。t = 0 と 2T で最大値 ℓθ、t = T で最小値 −ℓθ、t = T/2 と 3T/2 で Y = 0。
  - (4) 電源を外し、一定の角速度 ω で反時計回りに回す(t = 0 で OL は x 軸に平行)
    - ワ: L 上の辺の速度の x 成分の大きさ = ℓω × |sin ωt|
    - カ: V0 = −Bωℓ²(大きさは Bωℓ²。0 < ωt < π では L 上の辺に下向きの起電力が生じ、上側の辺では O→L 向き。図5(b)の破線の矢印は上側の辺で L→O 向きなので負。符号は要検証)
    - ヨ: 電力 = (V0²/R) × sin²ωt
    - タ: 一周(時間 2π/ω)のジュール熱 = πV0²/(Rω)
    - レ: 外力を除くと、誘導電流が受ける力が回転を妨げる → ③減少した
- その場で与えられた知識:
  - [L1] 微小角の近似: 冒頭で「微小な角度 α [rad] に対して sin α ≒ α となることを必要に応じて利用せよ」。ヌ(Y ≒ ℓ×角度)、ル(1−cos θ ≒ θ²/2 相当)、ヲ(単振動への帰着)で使う。
  - [L1] 半角公式: (4) で「sin²ωt = (1 − cos 2ωt)/2 なので」と書き、電力の一周平均が 0.5 倍になることを導かせる。数学IIの公式であり、交流の実効値の説明と同じ内容。
- 解法の核心・差がつく点: 電流の向きを選ぶ空欄が3つあり(ロ、ヘ、チ)、図の①②の矢印が「どの導線・どの辺での向き」かを読み取って力の向きから逆算する。ト は L 上の辺だけでなく O 上の辺が受ける力(こちらのほうが大きい)も含めた合力を向心力とする点が最大の分かれ目。(3) は力が x 方向で一定なのに、回転に効く成分だけを取り出すと復元力 −I_L B Y になり、磁場中の電流ループが単振動することに気づけるか。カ の符号は図5(b)の矢印の向きとの照合が必要。
- 作問メモ: 「1つの装置(ターンテーブル+導体)を使い回し、磁場の源と導体の形を1段ずつ差し替えて、力のモーメントのつり合い → 円運動 → 単振動 → 電磁誘導・エネルギーと、電磁気と力学の主要テーマを順に通過させる」型。各段は既習法則1つで解け、新しい知識は与えない。図に①②の矢印を描いて向きを選ばせる形式と、グラフ描図(振幅・時刻の記入つき)で締める形式は再利用しやすい。

## 大問III(熱/可動壁つき容器を液体中に固定した熱サイクル)

- 流れ: 上が閉じた固定容器(断面積 S)に n モルの単原子分子理想気体。下側を質量 m・厚さ L の水平な可動壁でふさぎ、壁は上下のストッパーの間を滑らかに動く。上部ストッパーから壁上面までの距離が x(0 ≦ x ≦ L)、気体の体積は S(2L+x)。壁はすべて断熱材で、容器内に温度調節器がある。(1) 大気中。(2) 密度 ρ の液体中に固定し、液面の位置 z(上部ストッパーから液面までの距離、0 ≦ z ≦ L)を変えられる。(3) 液面と温度を操作する4過程のサイクル。
  - (1) 大気圧 P0 の大気中
    - あ: 気体の圧力 = nRT/(S(2L+x))
    - い: x = nRT/(P0S − mg) − 2L(つり合い PS + mg = P0S)
    - う: x = L に達する温度 T_A まで定圧で加熱したときの吸熱量 = (5/2)nR(T_A − T)
    - え: 気体が外部にする仕事 = 3L(P0S − mg) − nRT
  - 問1(導出): T_A で温度調節器を切り、壁を x = 0 までゆっくり押し上げる(断熱圧縮、体積 3LS → 2LS)。気体がされる仕事 = 内部エネルギーの増加 = (3/2)nR T_A{(3/2)^(γ−1) − 1} = (9/2)L(P0S − mg){(3/2)^(γ−1) − 1}。(定積モル比熱を R/(γ−1) と書けば 3L(P0S − mg){(3/2)^(γ−1) − 1}/(γ−1)。γ = 5/3 では同じ値。)
  - (2) 液体中
    - お: 液体が可動壁(下面)におよぼす圧力 = P0 + ρg(z + x + L)
    - か: z = 0、x = 0 で気体の圧力が正になる条件。m < (P0 + ρgL)S/g
    - き: z = L、x = 0 でつり合う温度 T1 = 2L(P0S − mg + 2ρgLS)/(nR)
    - く: z = L、x = L でつり合う温度 T2 = 3L(P0S − mg + 3ρgLS)/(nR)
    - け: z = 0、x = 0 でつり合う温度 = 2L(P0S − mg + ρgLS)/(nR)
  - (3) P0S − mg = 2ρgLS のとき(T1 = 8ρgL²S/(nR)、T2 = 15ρgL²S/(nR)、T3 = 12ρgL²S/(nR)、T4 = 6ρgL²S/(nR))
    - 問2(図示): P–x 図で平行四辺形。過程 I は (0, 4ρgL) → (L, 5ρgL) の右上がりの直線、過程 II は x = L で 5ρgL → 4ρgL の下向きの線分(液面を下げる間は状態は動かず、その後の冷却で圧力が下がる)、過程 III は (L, 4ρgL) → (0, 3ρgL) の直線、過程 IV は x = 0 で 3ρgL → 4ρgL の上向きの線分。P1 = 4ρgL、P2 = 5ρgL、P3 = 4ρgL、P4 = 3ρgL。
    - こ: W1 = (9/2)ρgSL²
    - さ: W2 = 0
    - し: W3 = −(7/2)ρgSL²
    - す: W4 = 0
    - せ: 吸熱は過程 I(+15ρgSL²)と過程 IV(+3ρgSL²)→ ⑦。(過程 II は −(9/2)ρgSL²、過程 III は −(25/2)ρgSL²)
  - 問3: 全吸熱量 18ρgSL²、正味の仕事 ρgSL²、熱効率 1/18。
- その場で与えられた知識:
  - [L1] ポアソンの式: 問1で「この過程では、[温度]×[体積]^(γ−1)(γ は 1 より大きい定数)が一定になることが知られている」と与える。断熱圧縮後の温度を求めるのに使う。教科書の発展・受験定番。
- 解法の核心・差がつく点: 壁のつり合い PS + mg = {P0 + ρg(z+x+L)}S から、気体の圧力が x の一次関数(傾き ρg)になることを押さえれば、P–x 図は直線になり仕事は台形の面積で出る。過程 II・IV の前半(温度一定で液面だけ動かす)は、壁がストッパーに押しつけられたままで気体の状態が変わらないことを読み取る必要がある。(2) の か は「気体の圧力が正」という条件の立て方に気づけるかどうか。つり合いが安定であること(x が増すと必要な圧力は上がり、気体の圧力は下がる)は暗黙の前提。
- 作問メモ: 「ピストンの外圧を、液面の高さという第2の操作変数で変えられるようにし、(温度、液面)の2つのつまみでサイクルを組ませる」型。圧力が体積の一次関数になるので P–V 図は平行四辺形、計算は台形の面積と (3/2)Δ(PV) だけで済み、数値係数がきれいに出るように P0S − mg = 2ρgLS と条件を置いている。ストッパーで「状態が動かない区間」を作り、読解で差をつける。
