## 大問I(力学/フロントガラス上のワイパー:摩擦と仕事、質量が増える物体の運動量)

- 流れ: 水平面と角 β をなす平らなフロントガラス面上を、質量 M のワイパーが回転せず水平方向に動く。重力に加え面に垂直な力 F_p で押しつけられる(垂直抗力 N = F_p + Mg cosβ)。静止摩擦係数 μ、動摩擦係数 μ'。0〜t1 で加速して v1、t1〜t2 は等速、t2 以降減速して停止。
  - ア(加速度): v1/t1
  - イ(加えた力): Mv1/t1 + μ'(F_p + Mg cosβ)
  - ウ(0〜t1 の仕事): {Mv1/t1 + μ'(F_p + Mg cosβ)}v1t1/2 = Mv1²/2 + μ'(F_p + Mg cosβ)v1t1/2
  - エ(力を 0 にしてからの距離): Mv1²/(2μ'(F_p + Mg cosβ))
  - オ(停止時刻): t2 + Mv1/(μ'(F_p + Mg cosβ))
  - 問1(折線 d の最初の傾き v1'/t1' の条件): 動き出すには水平力が最大摩擦力 μN を超える必要があり、動いた後は動摩擦 μ'N になるので、加速度は (μ − μ')N/M より大きくなる。v1'/t1' > (μ − μ')(F_p + Mg cosβ)/M(d が実現の限界なので等号を含めるかは要検証)。
  - 問2(仕事が最小の運動): d。仕事 = 運動エネルギーの増加 Mv1²/2(共通)+ 摩擦に抗する仕事 μ'N×移動距離。移動距離は v–t グラフの面積で、d が最小。
  - カ(水膜あり、直線 c に従う加速中の力): 加速度 v1/t1、s = v1t²/(2t1)。運動量 (M+ns)v の時間変化から (M + 3ns)v1/t1 + μ'{F_p + (M + ns)g cosβ}。t で書けば Mv1/t1 + 3nv1²t²/(2t1²) + μ'{F_p + (M + nv1t²/(2t1))g cosβ}。(要検証: 付着水の重さを垂直抗力に含めた)
  - キ(等速中の運動量増加 ÷ Δt): nv1²
  - ク(等速中に加える力): nv1² + μ'{F_p + (M + m1 + nv1(t − t1))g cosβ}
- その場で与えられた知識:
  - [L1] 質量が増加する物体の運動(運動量の変化 = 力積で扱う): 「集められた雨水はワイパーと一体となって動き、付着した雨水の質量だけワイパーの質量が増加した状態と同じとみなされる」「単位長さ進むと質量 n の雨水が付着する」とモデル化し、等速区間では質量 [M + m1 + nv1(t−t1)]、速度 v1 を示して「Δt 後の運動量の増加は キ × Δt」「合力は キ」と誘導。カは同じ考えを加速中に自力で適用。法則は既習(運動量と力積)だが、質量変化系への適用は受験定番の準範囲外。
- 解法の核心・差がつく点: 重力の面に垂直な成分が垂直抗力に加わること。問1は「静止摩擦で動き出しの力の下限が決まり、動いた瞬間に動摩擦に切り替わるので加速度に下限が生じる」ことに気づくか。カは ma = F としてはならず、d(mv)/dt = (M+ns)a + nv² と付着分の運動量を加える。
- 作問メモ: 身近な機械(ワイパー)を「押しつけ力つきの摩擦面上の物体」に抽象化し、(i) 定番の運動・仕事、(ii) v–t グラフの折線の比較で静止摩擦と仕事を考察、(iii) 質量付着による運動量変化、と3段に上げる型。等速なのに力が要る(nv1²)という結果を誘導で出させ、加速中は誘導なしで問う「誘導の順序を逆にした配置」が特徴。面に沿って下向きの重力成分 Mg sinβ をどう支えるかは問題文に記述がなく、水平方向の運動には関係しないとして扱った。

## 大問II(電磁気/離れた2コイルの相互インダクタンスと運動するコイルの電磁誘導)

- 流れ: xy 平面内に、中心 (L, 0)・幅 2a で y 方向に十分長い長方形コイル1(AB は x = L−a、CD は x = L+a)と、原点中心・一辺 2b・抵抗 R の正方形コイル2。x 軸近くでは AB、CD を無限に長い直線電流とみなす。真空の透磁率 μ0。コイル1に ADCB の向き(AB では +y 向き)に I1。紙面の裏から表を正。
  - イ(AB がつくる磁界): I1/(2π(L − a − x))
  - ロ(AB と CD の合計): (I1/2π){1/(L − a − x) − 1/(L + a − x)}
  - ハ(原点付近の近似、AB 分): (I1/(2π(L − a))){1 + x/(L − a)}
  - ニ(コイル1全体、x の1次式): (I1a/(π(L² − a²))){1 + 2Lx/(L² − a²)}
  - ホ(コイル2を貫く磁束): 4μ0I1ab²/(π(L² − a²))
  - ヘ(相互インダクタンス): 4μ0ab²/(π(L² − a²))
  - ト(中心が x = vt のときの磁束): (4μ0I1ab²/(π(L² − a²))){1 + 2Lvt/(L² − a²)}
  - チ(コイル2の電流、EFGH の向きを正): −8μ0I1ab²Lv/(πR(L² − a²)²)
  - リ(単位時間のジュール熱): 64μ0²I1²a²b⁴L²v²/(π²R(L² − a²)⁴)
  - 問1(コイル2全体が受ける力): 辺 EF と GH に流れる電流(大きさ |チ|、互いに逆向き)が受ける力の差。磁束密度の差は μ0×(ニの傾き)×2b なので、大きさ 64μ0²I1²a²b⁴L²v/(π²R(L² − a²)⁴)、向きは x 軸の負の向き(運動を妨げる向き)。FG、EH が受ける力は打ち消し合う。力×v = リ で検算できる。
- その場で与えられた知識:
  - [L1] 近似式 1/(1−ε) ≒ 1+ε(|ε| ≪ 1): (2) の本文で明示。ハ、ニで磁界を x の1次式にするのに使う。
  - [L0 相当、記録のみ] 十分長い導線を無限に長い直線電流とみなす、AD・BC の寄与を無視する: 設定上の近似の宣言。
- 解法の核心・差がつく点: イ・ロは「磁界」なので μ0 を含まない H で答える(磁束で初めて μ0 を掛ける)と読んだ。磁界が x の1次式なので、正方形を貫く磁束は中心の値 × 面積で厳密に求まる。チの符号: 表向きの磁束が増える → 時計回りの誘導電流 → EFGH(反時計回り)と逆で負。問1は磁界の一様部分が打ち消し、勾配だけが力を生む。
- 作問メモ: 「直線電流の磁界(既習)→ 近似式で1次式化 → 磁束 → 相互インダクタンス → コイルを動かして誘導起電力・ジュール熱 → 力」という一本道。近似で場を「一様 + 一定勾配」にしておくと、磁束は中心値で、力は勾配で決まり、仕事率 = ジュール熱の検算も成り立つ。遠方のコイル間の相互インダクタンスを高校の道具だけで計算させる設計。
  - 注: コイル2の頂点配置は図1から E 左上、F 左下、G 右下、H 右上と読み取った(EFGH は反時計回り)。

## 大問III(熱+力学/単原子理想気体の状態変化と熱機関、断熱変化によるピストンの単振動)

- 流れ: 断面積 S の両端開口シリンダーを、質量 m のピストン(摩擦なし)と栓(最大摩擦力 F)でふさぎ、単原子分子理想気体 1 mol を封入。すべて断熱材、内部に温度制御装置。外気圧 p0、気体定数 R。状態 A は T0、p0。
  - あ(栓が動き出す直前 B の温度): T0(1 + F/(p0S))
  - い(A → B の熱量): 3RT0F/(2p0S)
  - う(定圧で体積 8 倍 C までの内部エネルギー変化): 21RT0/2
  - え(与えた熱量): 35RT0/2
  - お(断熱で体積 8 倍 D の温度): T0/4
  - か(A → D で気体が外にした仕事): 9RT0/8
  - き(F の下限): 31p0S/32
  - 問1(サイクル A→C→D→A): p–V 図は A(V0, p0) → C(8V0, p0) の水平線、C → D(8V0, p0/32) の垂直線、D → A の断熱曲線(下に凸)。吸熱は A→C の 35RT0/2、放熱は C→D の (3/2)R(8T0 − T0/4) = 93RT0/8。熱効率 = 1 − 93/140 = 47/140 ≒ 0.34。
  - く(ピストンの運動方程式、膨張の向きが正): ma = (p − p0)S
  - 問2(微小振動の周期): pV^(5/3) = 一定、V0 = RT0/p0、変位 x で V = V0 + Sx より p ≒ p0(1 − 5Sx/(3V0))。ma = −(5p0²S²/(3RT0))x。周期 2π√(3mRT0/(5p0²S²)) = (2π/(p0S))√(3mRT0/5)。
- その場で与えられた知識:
  - [L1] ポアソンの式: 「単原子分子からなる理想気体の断熱変化では、(圧力)×(体積)^(5/3) は一定である」と明示。お、か、き、問1、問2で使う。
  - [L1] 近似式 (1+ε)^α ≒ 1+αε(|ε| ≪ 1、α は任意の実数): 問2で「必要ならば用いてよい」と明示。断熱変化の圧力を変位の1次式にするのに使う。
- 解法の核心・差がつく点: 栓のつり合いは内外の圧力差×S と最大摩擦力の比較(加熱時は内 > 外、断熱膨張時は外 > 内で向きが逆)。8 = 2³ なので 8^(2/3) = 4、8^(5/3) = 32 ときれいに出る。熱効率は放熱が定積 C→D のみであることを押さえる。問2は気体の物質量 1 mol から V0 = RT0/p0 を自分で入れる。
- 作問メモ: 「同じ始状態 A から、定積・定圧・断熱の3通りの操作を独立に行い(毎回『再び状態 A に戻し』)、最後にそれらをつないだ熱機関と、断熱ばねとしての単振動を論述で問う」型。栓の最大摩擦力という仕掛けで、各過程の圧力を不等式・しきい値の形でも問える。数値(体積 8 倍、γ = 5/3)を累乗が整数になるよう選んでいる。
