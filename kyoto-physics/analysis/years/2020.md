## 大問I(力学/ばねと糸でつるした2球の振動と糸のたるみ)

- 流れ: ばね定数 k・自然長 ℓ のばねと長さ L の糸、質量 m の小球2個。鉛直下向きが正。
  - (1) 天井―糸―小球1―ばね―小球2(図1)。原点は糸が張っているときの小球1の位置。小球2をつり合い位置から d 引き下げて放す。
    - ア: 小球2の振動中心(ℓ + mg/k)
    - イ: 振幅(d)
    - ウ: 糸がたるみ始める瞬間の小球2の位置(ℓ − mg/k)
    - エ: たるむ条件 d >(2mg/k)
    - オ: たるみ始めた瞬間の重心の速さ((1/2)√(kd²/m − 4mg²/k))
    - カ: 相対位置 x の単振動の周期(2π√(m/(2k)))
    - キ: 小球1の速度が最小になる瞬間の相対速度 = キ × オ(2)
  - (2) 天井―ばね―小球1―糸―小球2(図2)。原点はばねが自然長のときの小球1の位置。小球2を支えて糸の張力 0 の状態(図3)から、小球2を速さ v で打ち上げる。
    - ク: 小球1の位置(mg/k)
    - ケ: 落下して戻り糸が張った直後の小球2の速度(0。等質量でエネルギー保存 → 速度交換)
    - コ: その後の小球1の振幅(v√(m/k))
    - サ: 弾性衝突直後の小球1の速さ v'(√(v² − 2gL))
    - シ: 時刻 T の直前の小球1からみた小球2の速度(0)
    - ス: 時刻 T の小球1の位置(0。ばねが自然長)
    - セ: v² =(4gL − mg²/k)
    - 問1: 時刻 0〜T の速度グラフ。小球2は −v から傾き g の直線で T' に −v' → 0 に跳び、再び傾き g の直線。小球1は T' まで 0、T' で −v' に跳び、接線の傾き 0 から始まる正弦曲線で増加し、T で小球2の直線に傾き g で接して一致する(T では両者とも正の同じ速度)。
- その場で与えられた知識:
  - [L1] 重心運動と相対運動の分離: 本文で「ばねの力は互いに逆向きで大きさが等しいので、重心は鉛直投げ上げ運動」「相対位置 x は重力の影響を受けずばねの力で単振動」と誘導。オ・カ・キで使う(換算質量 m/2 は自分で出す)。
  - [L1] 糸が張る瞬間の扱い: 「たるみがなくなる前後で力学的エネルギーの和は保存されるものとする」と仮定を明示。ケ・シで等質量の弾性衝突と同じ速度交換として使う。
- 解法の核心・差がつく点: キは「小球1の加速度が 0 に戻る瞬間 = 相対位置がたるみ始めと同じ値に戻る瞬間」で、相対速度は符号だけ反転(たるみ始めの相対速度は −2×オ)。(2) 後半は、糸が張った瞬間に速度交換が起きるので、たるまないためには相対速度 0、さらに直後に小球1が小球2に近づかないためにばねの力 0、という2段の条件を読み解く。セは小球1(単振動のエネルギー保存)と小球2(自由落下)の速度を等置。
- 作問メモ: 「ばね+糸」で拘束が切れる/戻る瞬間を問う型。同じ部品の並べ替え(糸が上/ばねが上)で2つの小問を作り、前半は重心・相対運動、後半は「糸が張る=弾性衝突」と読み替えさせる。条件文(F ≧ 0、F > 0 ならたるむ)を本文で誘導し、空欄は結論だけにするのが京大らしい。最後に速度グラフで全体像を確認させる。

## 大問II(電磁気/電気振動とダイオード・スイッチによる昇圧回路)

- 流れ: (1) LC 回路の電気振動を差分の式で書く。(2) 電源 E・コイル L・抵抗 r とスイッチ・ダイオード・コンデンサー C の回路(図2)でスイッチを開く。(3) 抵抗 r を除き負荷抵抗 R を付け(図4)、スイッチを周期 T = Δt1 + Δt2 で開閉する定常状態(昇圧回路)。
  - イ: L ΔI/Δt =(−V)
  - ロ: C ΔV/Δt =(I)
  - ハ: V の I に対する位相の遅れ(π/2)
  - ニ: I の最大値(Q0/√(LC))
  - ホ: スイッチを十分長く閉じたときのコイルの電流(E/r)
  - ヘ: L ΔI/Δt =(−V')(V' = V − E)
  - ト: C ΔV'/Δt =(I)
  - チ: 振動が止まる時刻 T1(π√(LC)/2)
  - 問1: エネルギー収支 (1/2)L I0² + E·C(V − E) = (1/2)CV² − (1/2)CE² から V(T1) = E + I0√(L/C) = E{1 + (1/r)√(L/C)}。グラフは V = E から正弦曲線の 1/4 周期ぶん上昇し、T1 で最大となり以後一定。
  - リ: L ΔI1/Δt1 =(E)
  - ヌ: C ΔV1/Δt1 =(−V/R)
  - ル: L ΔI2/Δt2 =(E − V)
  - ヲ: C ΔV2/Δt2 =(I − V/R)
  - 問2: V0 = (1 + α)E、I0 = (1 + α)²E/R。α = 1 のグラフは V = 2E から直線的に下がり t = T/2 で 2E − ET/(RC)、そこから直線的に上がって t = T で 2E に戻る。
  - 問3: 図4の抵抗の消費電力は図5の (1 + α)² 倍。
- その場で与えられた知識:
  - [L1] 電気振動の差分方程式: 式(i)(ii) の形(L ΔI/Δt、C ΔV/Δt)を本文で立てさせ、(2) で「式(iii)は式(i)(ii)と同じ形をしているため…電気振動が始まる」と読み替えを明示。チ・問1で使う。
  - [L1] 理想ダイオード: 「順方向の抵抗は 0、逆方向の抵抗は無限大」と定義。チ(I が 0 になった時点で停止)、(3) の場合分けに使う。
  - [L1] 周期的定常状態の条件: 問2で「1周期では ΔI1 + ΔI2 = 0、ΔV1 + ΔV2 = 0」と与える。V0、I0 の決定に使う。
- 解法の核心・差がつく点: 変数を V' = V − E にずらすと LC 振動と同型になる点。問1は電源の仕事 E·ΔQ を忘れない(結果は V' について (1/2)L I0² = (1/2)C V'² と簡単になる)。(3) はスイッチの開閉それぞれでキルヒホッフを書くだけで、定常条件から昇圧比 1 + α が出る。
- 作問メモ: 「実用回路(昇圧チョッパ)を、微小時間の差分式 2 本 × 2 状態に分解して、周期条件で平均値を求める」型。前段で LC 振動の式を同じ書式で書かせておき、後段の読み替えの足場にしている。未習の知識は不要で、設定が新しいだけ(L1 どまり)。最後に「電源より高い電圧・(1+α)² 倍の電力」という意外な結論で締める。

## 大問III(熱/膨張する立方体中の分子運動から断熱変化の式、二原子分子の γ)

- 流れ: 各辺が L + wt で膨張する立方体(w は粒子の速さより十分小さい)。x 方向に往復する1粒子を追い、壁A(x = 0、固定)が受ける圧力の変化と体積の変化を w/v の1次まで求めて、ΔP/P + γΔV/V = 0 を導く。後半は二原子分子モデル。
  - あ: L1 =(Lv/(v + w))
  - い: L2 =(Lv/(v − w))
  - う: T12 =(2Lv/(v² − w²))
  - え: T12 ≒(2L/v)
  - お: P =(mv²/L³)
  - か: v' = v − aw の a(2)
  - き: L3 =(Lv(v' + w)/{v'(v − w)})
  - く: ΔP/P = く × w/v(−(2a + 6))
  - け: ΔV/V = け × w/v(6)
  - こ: γ =((a + 3)/3)
  - さ: ΔT/T + さ × ΔV/V = 0(γ − 1)
  - し: a = 2 のときの γ(5/3)
  - 問1: エネルギー保存 (5/6)mv² + (1/2)Mw² = (5/6)mv'² + (1/2)Mw'²、運動量保存 mv + Mw = −mv' + Mw'。v' = {(5 − 3m/M)v − 6w}/(5 + 3m/M)。
  - 問2: m/M → 0 で v' = v − (6/5)w、a = 6/5、γ = 7/5。
- その場で与えられた知識:
  - [L2] 二原子分子の回転エネルギーのモデル: 「二原子分子を2つの質点が長さ一定で質量を無視できる棒でつながったものと見なすと、重心の並進運動の他に、重心のまわりの Y 軸と Z 軸を回転軸とする2つの回転運動がある」「各回転運動のエネルギーの値がどれも (1/3)Kx に等しく、E = (1 + 2/3)Kx の関係が常に成り立っていると仮定する」「二原子分子は上記のエネルギー E を持った質量 m の粒子と考えればよい」。問1で衝突のエネルギー保存の式に (5/3)×(1/2)mv² を入れ、問2で a = 6/5、γ = 7/5 を出すのに使う。
  - [L1] 動く壁との衝突による気体分子運動論的な断熱変化の導出(ポアソンの法則): 本文全体が誘導。「式(iv)は理想気体の断熱変化におけるポアソンの法則として知られたもの」と名称も与える。
  - [L1] 近似式 1/(1 + x) ≒ 1 − x: え で使用。
  - [L1] 近似式 (1 + a1x)^b1 (1 + a2x)^b2 {1 + a3x/(1 + cx)}^b3 ≒ 1 + (a1b1 + a2b2 + a3b3)x: く・け で使用。
  - [L1] 微小変化の関係 ΔT/T = ΔP/P + ΔV/V(状態方程式の対数微分に相当): さ で自力で導く(式は与えられない)。
- 解法の核心・差がつく点: L3/L = {1/(1 − w/v)}{1 + (w/v)/(1 − a w/v)} ≒ 1 + 2w/v と P'/P = (v'/v)²(L/L3)³ を与えられた近似式の形に合わせて一気に処理する。a を文字のまま残す指示(後半で a を差し替えるための伏線)に従うこと。問1は「速度交換の式」を覚えていても使えず、エネルギーの係数 5/3 を入れて連立を解き直す必要がある。
- 作問メモ: 「定番の導出(分子運動論による断熱変化)を、パラメータ a を残した一般形で書かせ、モデルを差し替えて(単原子 a = 2 → 二原子 a = 6/5)別の結果を出させる」型。新しいモデルは「エネルギーが (1 + 2/3) 倍」という1行の仮定に圧縮されていて、適用は既習の保存則だけ。汎用の近似式を1本与えて計算量を抑えている点も再利用できる。

### 判定の注

- III の L2 は境界事例。二原子分子の定積モル比熱 (5/2)R や γ = 7/5 は教科書の発展・参考に載ることがあるが、「回転の自由度にエネルギーが等分配される」ことを衝突のエネルギー保存に組み込んで γ を導くのは範囲外で、問題文の仮定を読んで適用しないと問1・問2は解けない。形式(未習のモデルを読んで既習の保存則と組み合わせる)を重視して L2 とした。適用の負荷は軽い(係数が 1 → 5/3 に変わるだけ)ので、L1 と判定する立場もありうる。
- II の昇圧回路は題材として新しいが、使うのはキルヒホッフの法則とコイル・コンデンサーの基本式だけなので L1(novel_context に記録)。
