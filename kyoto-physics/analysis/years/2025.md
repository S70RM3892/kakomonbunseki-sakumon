## 大問I(力学/円運動と、拘束が外れた後の重心運動+回転)

- 流れ: (1) ばね(自然長 L、ばね定数 k)につないだ小球の水平面上の等速円運動。(2) ひも a で O につないだ小球1(M)と、さらにひも b でつないだ小球2(m)が一直線で回転中、ひも a が切れる。(3) 鉄棒に付けた物体 A(軽い棒 2a の先に小球1(2m)、さらに棒 a の先に小球2(m))を鉛直面内で回し、真下に来た瞬間に小球1から上の棒が外れる。
  - ア: k(R − L)
  - イ: MRω^2
  - ウ: R = kL/(k − Mω^2)
  - 問1(導出): R が正の有限値になる条件 k − Mω^2 > 0 より 0 < ω < √(k/M)
  - エ: a + mb/(M+m)、オ: 0
  - カ: mbω/(M+m)
  - キ: ④(y 軸負の方向)
  - ク: 張力 Mmbω^2/(M+m)
  - ケ: ω
  - コ: 0
  - サ: ②(直線運動)
  - シ: 運動エネルギー (17/18) m V0^2(小球1の速さは 2V0/3)
  - ス: 位置エネルギー 7 m g a sinθ
  - セ: ②(反時計回り。運動エネルギー 8.5mga が最高点の位置エネルギー 7mga を上回り、そのまま回りきる)
  - ソ: √(31g/(17a))
  - タ: 鉄棒の高さ 3a + 34π^2 a/31
- その場で与えられた知識:
  - [L1] 重心運動と重心まわりの回転への分解: 重心の位置・相対速度・角速度を順に求めさせ、「重心の運動は2つの小球の質量が重心に集中したものとして考えることができる」と明記。(3)のタでそのまま使う。
- 解法の核心・差がつく点: 外れた直後の2球は、重心まわりに外れる前と同じ角速度で回り続ける。(3)は重心が水平投射の放物運動、鉛直方向は自由落下なので、1回転の時間 2π/Ω に落ちる距離 (1/2)g(2π/Ω)^2 を出し、小球2の最初の高さ(鉄棒の下 3a)に足す。
- 作問メモ: 「固定点まわりの回転 → 拘束を切る → 重心の運動+重心まわりの回転」という型を、水平面(外力なし)で練習させてから鉛直面(重力あり)に持ち込む2段構え。慣性モーメントや角運動量を持ち出さず、2質点の速さの比だけで剛体的な回転を扱わせている。最後は「1回転して着地」という条件から装置の寸法を逆算させる。

## 大問II(電磁気/伸縮自在のソレノイドにはたらく電流の圧力)

- 流れ: (1) 長さ d、半径 r、N 回巻きのソレノイドの磁場・自己インダクタンス・エネルギー。(2) 風船状の膜に巻いた伸縮自在のコイル。長さを固定し、電流 I 一定のまま半径を速さ v で広げる。(3) 半径を固定し、長さを速さ v で伸ばす。
  - イ: μNI/d
  - ロ: μπr^2 N^2/d
  - ハ: μπr^2 N^2/d
  - ニ: μπr^2 N^2 I/d
  - ホ: μπr^2 N^2 I^2/(2d)
  - ヘ: 2πμNIrv/d
  - ト: 2πμN^2 I r v/d
  - チ: 2πμN^2 I^2 r v/d
  - リ: πμN^2 I^2 r v/d
  - ヌ: 2πrdv
  - ル: −2πrdv δp
  - ヲ: δp = B^2/(2μ)
  - ワ: ①(コイルを膨らませる方向)
  - カ: −μπr^2 N^2 I^2 v/d^2
  - 問1: δp = −B^2/(2μ)(エネルギー変化 −μπr^2N^2I^2v/(2d^2)·Δt = 電源の仕事 + 圧力差の仕事 −δp·πr^2 vΔt)
  - 問2: ②(軸方向に縮もうとする)
  - 問3(論述): 隣り合う巻き線には同じ向きの電流が流れ、平行電流どうしは引き合うので、コイルは軸方向に縮もうとする
- その場で与えられた知識:
  - [L1] 近似式(i): (x+Δx)^2 − x^2 ≒ 2xΔx。
  - [L1] 近似式(ii): 1/(x+Δx) − 1/x ≒ −Δx/x^2。
  - [L1] エネルギー収支の立て方: 「このエネルギーの変化は、外部電源が行った仕事と、膜内外の気体の圧力差が膜に対して行った仕事の和に等しい」。δp の符号の定義、膜・導線の伸縮に要する仕事は無視という仮定も与える。
- 解法の核心・差がつく点: 電流一定なら電源の仕事はエネルギー増加のちょうど2倍(半径を広げる場合)。差が圧力差の仕事になる。長さを伸ばす場合はインダクタンスが減り、電源の仕事もエネルギー変化も負で、δp の符号が逆になる。起電力の符号の約束(上流側が高電位で正)を崩さないこと。
- 作問メモ: 「形状パラメータを1つだけ微小変化させ、エネルギー収支から力(圧力)を出す」型(コンデンサーの極板間引力のコイル版)。半径方向は誘導つき、軸方向は誘導なしで再現させ、符号が逆になる結果を平行電流の引力で説明させて締める。範囲外の結果(磁気圧)に名前も式も与えず到達させるので L2 ではない点が、III(2) との対比になる。

## 大問III(熱/断熱変化の導出と、理想気体でない気体のサイクル)

### (1) おもりを1個ずつ取り除く断熱膨張とポアソンの式

- 流れ: 1 モルの単原子分子理想気体を、蓋つきの円筒容器(透熱・断熱を切り替え可)に入れる。質量 M のおもり O(N 個の小さなおもり c)を載せた状態 X から、c を1個ずつ取り除く操作 α を繰り返す。
  - あ: P_X = P_ex + Mg/S
  - い: P_k = P_ex + (N−k)Mg/(NS)
  - う: 内部エネルギー変化 (3/2)(P_{k+1}V_{k+1} − P_kV_k)
  - え: (3P_k + 2P_{k+1})/(5P_{k+1})
  - お: 5/3
  - か: ①(V_Y < V_Z)
  - 問1(論述): 断熱膨張では気体が外へする仕事の分だけ内部エネルギーが減って温度が下がる。等温膨張では温度が保たれる。最終圧力は同じ P_ex なので、温度の低い断熱の方が体積が小さい
- その場で与えられた知識:
  - [L1] ポアソンの式 PV^(5/3)=一定: 冒頭で与え、差分からの導出の到達点として示す。
  - [L1] 微小膨張の仕事の近似と差分式: 「気体がする仕事は P_{k+1}(V_{k+1}−V_k) と近似できる」。ΔP_k/P_{k+1} + [お]ΔV_k/V_k = 0 の形を与える。
- 解法の核心・差がつく点: 第一法則 (3/2)(P_{k+1}V_{k+1} − P_kV_k) = −P_{k+1}(V_{k+1} − V_k) を V_{k+1} について解くだけ。添字の取り違えに注意。
- 作問メモ: 「準静的過程を有限回の小さな不可逆操作の極限として組み立て、既知の公式を導く」型。(2) で未知の気体に同じ手順を使わせるための予行演習になっている。

### (2) U=3PV に従う気体 F のサイクル

- 流れ: 気体 F は U=3PV に従う。微小な断熱膨張から PV^γ=一定を導く。エネルギー密度 u=U/V=3P が温度だけで決まり u=aT^x と書けるとして、断熱(A→B)・等温 T_B(B→C)・断熱(C→D)・等温 T_A(D→A)のサイクル(図2、等温変化は圧力一定)から x を決める。
  - き: PΔV
  - く: 4/3
  - け: (P_A/P_B)^(3/4)
  - こ: Q_BC = 4P_B(V_C − V_B)
  - さ: Q_DA = 4P_A(V_A − V_D)
  - し: 4P_A/T_A − 4P_A^(3/4) P_B^(1/4)/T_B
  - す: 4P_B/T_B − 4P_A^(1/4) P_B^(3/4)/T_A(し・すは共通の定数倍の任意性あり)
  - せ: x = 4
  - 問2(論述): 気体 F の圧力は温度だけで決まるので、圧力を一定に保つと温度も変わらない。熱を加えても温度が上がらず、「圧力一定で温度を1 K 上げるのに必要な熱量」が定まらない
- その場で与えられた知識:
  - [L2] 気体 F のモデル: 「単原子分子理想気体とは異なる状態方程式や内部エネルギーの式に従う気体 F」「熱力学第一法則に従い…気体がする仕事は理想気体と同様に表される」「U=3PV であることがわかっている」。き・くで断熱の式を導き、こ・さで等温変化の熱量を出すのに使う(理想気体と違い、等温でも内部エネルギーが変わる)。
  - [L2] エネルギー密度とその温度依存性: 「単位体積あたりの内部エネルギーはエネルギー密度と呼ばれる」「u=U/V=3P」「絶対温度 T のみに依存し u=aT^x と表されることがわかっている」。等温変化=定圧変化と読み替える根拠で、せの x を決める対象。問2の論述の根拠でもある。
  - [L2] クラウジウスの関係: 「ゆっくりと進む等温変化と断熱変化からなるサイクルにおいて、一般に次の事実が知られている。…Q_H/T_H + Q_L/T_L = 0 の関係が成り立つ」。こ・さの結果を代入し、V_A と V_C の係数がそれぞれ0になる条件から P^(1/4)/T = 一定を得る。
  - [L1] 微小量の扱い: 「ΔPΔV などの微小量どうしの積は無視してよい」。
- 解法の核心・差がつく点: ΔU = 3(PΔV + VΔP) = −PΔV。等温変化の熱量は ΔU + W = 3PΔV + PΔV = 4PΔV(ΔU を0としない)。V_B、V_D を断熱の式で V_A、V_C に直し、「任意の V_A、V_C で成立」から係数ごとに0とおく。
- 作問メモ: 「理想気体でない物質の性質を1〜2本の式で与え、(i) 第一法則で断熱の式を導く、(ii) サイクルに普遍的関係を適用して未知の温度依存性を決める」型。実体は光子気体とシュテファン・ボルツマンの法則だが、名称を伏せて「気体 F」とし、熱力学だけで T^4 則に到達させる。最後の論述は「理想気体の常識(定圧比熱)が成り立たない理由」を問い、モデルの理解を確かめている。この年度で唯一の明確な L2。
