## 大問I(力学/衝突後の重ねた2円盤の摩擦運動)

- 流れ: 水平な床の上に円盤1(質量 m1、半径 l1)、その上に円盤2(m2、l2)が載って静止。円盤3(m3)が速度 v0 で円盤1に衝突(はね返り係数 e)。床と1の間の動摩擦係数 μ1、1と2の間 μ2。衝突直後の2の速度は 0。時刻 T_A で1と2の相対速度が 0 になり、以後一体で T_B に静止。
  - ア: 衝突直後の1の速度 v = (1+e)m3 v0/(m1+m3)
  - イ: 3の速度 (m3−e m1)v0/(m1+m3)
  - ウ: a1 = −{μ1(m1+m2)+μ2 m2}g/m1
  - エ: a2 = μ2 g
  - オ: a' = −μ1 g
  - 問1: 0〜T_B の速度・加速度のグラフ(1は v から傾き a1 で減速、2は 0 から傾き a2 で加速、T_A で v' に一致し、以後傾き a' で T_B に 0。加速度は階段状)
  - カ: T_A = v/(a2−a1)
  - キ: v' = a2 v/(a2−a1)
  - ク: T_B = v(a'−a2)/{a'(a2−a1)}
  - ケ: T_A = m1 v/{(m1+m2)(μ1+μ2)g}
  - コ: T_B = m1 v/{μ1(m1+m2)g}
  - サ: はみ出さない条件 m1 v²/{2(m1+m2)(μ1+μ2)g} ≦ l1−l2
  - シ: x_B = m1 v²{μ1(m1+m2)+μ2 m1}/{2μ1(μ1+μ2)(m1+m2)² g}
  - ス: 衝突直後の運動エネルギーの総和 m1 v²/2
  - セ: E1 = μ1(m1+m2)g x_B
  - ソ: E2 = μ2 m2 g(x1−x2)
  - 問2: T_B が μ2 によらない理由(1と2を一つの系とみると、1・2間の摩擦は内力で系の運動量を変えない。系の運動量 m1 v を 0 にするのは床からの摩擦 μ1(m1+m2)g の力積だけ)
- その場で与えられた知識: なし(L0)。
- 解法の核心・差がつく点: 物体1が受ける摩擦は床からと物体2からの2つで、床からの垂直抗力は (m1+m2)g。シは直接計算すると重いが、エネルギー収支 m1v²/2 = E1+E2 と x1−x2 = vT_A/2 を使うと速い(本文の(2)がその誘導)。
- 作問メモ: 「同じ運動を、運動方程式(時間追跡)→ エネルギー収支 → 運動量(力積)の3視点で順に見直させ、最後に『ある量が特定のパラメータによらない理由』を論述させる」型。文字式を一度 a1、a2、a' のまま書かせ、次に代入させる二段構えで、途中点の階段を作っている。

## 大問II(電磁気/誘電体の入れ替えによる昇圧と、電圧一定の放電)

- 流れ: 同形のコンデンサー A(誘電体入り、容量 ε_r C0)と B(C0)、電源 V0、抵抗 r、スイッチ S1・S2。操作 (i) S1 を閉じて A を充電し開く、(ii) A の誘電体を抜いて B に入れる、(iii) S2 を十分長く閉じる、(iv) S2 を開き誘電体を B から A に戻す。
  - イ: (ii)で誘電体を抜くのに要するエネルギー ε_r(ε_r−1)C0 V0²/2
  - ロ: その後の A の電圧 ε_r V0
  - ハ: (iii)後の B の電圧 ε_r V0/(1+ε_r)
  - ニ: B の電荷 ε_r² C0 V0/(1+ε_r)
  - ホ: 静電エネルギーの和 ε_r² C0 V0²/{2(1+ε_r)}
  - ヘ: (iv)後の B の電圧 ε_r² V0/(1+ε_r)
  - 問1: (ii)と(iii)を逆順にしても同じになる理由(終状態は、保存される総電荷と、最終的な2つの容量、電圧が等しいという条件だけで決まり、途中の順序によらない)
  - 問2: 電荷移動の時間 T = 2ε_r r C0/(1+ε_r)(失う静電エネルギー ε_r³ C0 V0²/{2(1+ε_r)} = r I² T と IT = ニ から)
  - 問3: 繰り返したときの B の電荷の極限 Q0 = ε_r² C0 V0
  - ト: B の誘電体を体積比 (1−x):x まで抜いたときの容量 {ε_r−(ε_r−1)x}C0
  - チ: Δt の間の電荷の減少 VΔt/R
  - リ: 容量の減少 ΔC = (ε_r−1)C0 Δx
  - 問4: Δx/Δt = 1/{(ε_r−1)C0 R}、電圧を保てる時間 (ε_r−1)C0 R
- その場で与えられた知識: なし(L0)。「電流を平均的に一定電流 I が時間 T 続くとみなす」という見積もりの仕方は本文が与えるが、既習量の組み合わせ。
- 解法の核心・差がつく点: 問3は「どの操作でも電荷が動かない」を式にする。(i)で A は ε_r C0 V0、誘電体を抜くと ε_r V0、これが誘電体入りの B の電圧 Q0/(ε_r C0) と等しい。問4は Q = CV で V 一定 → 放電で失う電荷 = VΔC。
- 作問メモ: 「操作列を与えて1周目を空欄で追わせ → 順序交換の不変性を論述 → 無限回繰り返した定常状態を『何も動かなくなる条件』から求めさせる」型。後半は「容量を時間変化させて電圧を一定に保つ」という逆問題で、微小変化の式を自分で立てさせる。時定数を「エネルギー収支+平均電流」で概算させる問2は、微分方程式を使わずに RC の時間スケールを出させる工夫。

## 大問III(力学・波動・相対論/等価原理と重力による時間の遅れ、GPS 衛星の時計)

- 流れ: (1) 宇宙空間で加速度 a で引かれる箱の中、下の光源 A から上の検出器 B(距離 h)へ光を送る。(2) 等価原理で重力中の2点に読み替える。(3) 重力ポテンシャルで書き直し、一様でない重力に拡張。(4) 円軌道上の人工衛星に特殊相対論の効果を加える。
  - あ: f_B/f_A = 1+(あ)/c の あ = v_A−v_B
  - い: v_B−v_A = at
  - う: t = h/c
  - え: Δt_B/Δt_A = 1+ah/c² の ah/c²
  - お: 慣性(力)
  - か: 見かけの重力加速度 −a
  - き: 地球の中心に向かう向き
  - く: GM/r²
  - け: βh/c²
  - 問1: B から A へ送っても同じ比になる理由(光が進む間に受け手 A が ah/c だけ光源に近づく向きの速度を得るので f_A/f_B = 1+ah/c²、すなわち Δt_A/Δt_B = 1−ah/c²。逆数をとると近似の範囲で同じ)
  - こ: φ_B−φ_A = βh
  - さ: (φ_B−φ_A)/c²
  - 問2: N 等分した各区間の式 Δt_{i+1}/Δt_i = 1+(φ_{i+1}−φ_i)/c² を掛け合わせ、積の近似式で 1+(φ_B−φ_A)/c² を示す
  - し: −GMm/r
  - す: φ_A = −gR
  - せ: gRL/{c²(R+L)}
  - そ: −gR²/{2c²(R+L)}
  - 問3: Δt_C/Δt_A = 1+gR(2L−R)/{2c²(R+L)}。数値は Δt_B/Δt_A = 1+5.4×10^-10、Δt_C/Δt_B = 1−5.4×10^-11、Δt_C/Δt_A = 1+4.9×10^-10
- その場で与えられた知識:
  - [L1] 近似式: 冒頭で「1に近い量は、微小量 ε, ε1, …, εk に対して成り立つ近似式 1/(1−ε)≈1+ε および (1+ε1)(1+ε2)…(1+εk)≈1+ε1+ε2+…+εk を用いて、1+(微小量) の形に表せ」。ほぼ全空欄と問2で使う。
  - [L1] 光のドップラー効果と、パルス間隔への読み替え: 「ドップラー効果の公式より」と音の公式をそのまま使わせ(「特殊相対論的な効果は無視してよい」)、「振動数 f の光を、単位時間に f 個のパルスが出るという状況に置き換えてみると明らか」として Δt_B/Δt_A = f_A/f_B を導かせる(え)。
  - [L2] 等価原理: 「このようにして生じる見かけの重力と本物の重力が何ら変わらないというのが、アインシュタインの等価原理である」「任意の点のまわりで十分小さい領域を考えると、その中では重力加速度は一定とみなしてよい。その領域内での物理現象は、上のような等加速度運動をしている観測者が見るものと全く同じである」。け で、加速する箱の結果 ah/c² を、重力加速度 β の場所での結果 βh/c² に読み替えるのに使う。
  - [L2] 重力による時間の進み方の違い: 「この結果は、重力がある場合は、場所によって時間の進み具合が違っていることを示している」「これを『A における時間 Δt_A と B における時間 Δt_B が対応している』ということにしよう」。さらに「実はこの式は、|φ_A−φ_B|/c² が1に比べて十分小さければ、重力加速度が空間的に一定でなくても成り立つ」と一般化を宣言。さ・せ・問2・問3で、時間比を重力ポテンシャル差で書いて合成するのに使う。
  - [L1] 重力ポテンシャル: 「その位置エネルギーは m に比例するので mφ と表せる。φ を粒子が置かれている点における重力ポテンシャルとよぶ」。電位と同じ発想で、こ・さ・す・せ で使う。
  - [L2] 特殊相対論の時計の遅れ: 「特殊相対論によると、B における時間 Δt_B と C における時間 Δt_C の間には、Δt_C/Δt_B = 1−v²/(2c²) という近似式が成り立つ」。そ で円運動の v² = gR²/(R+L) を代入し、問3で重力の効果と掛け合わせる。
- 解法の核心・差がつく点: 光が h 進む時間 h/c の間に箱の速度が ah/c 変わる、という1点からすべてが出る。符号と「どちらが分子か」を最後まで保つこと。問3は2つの比の積を近似式で和にする(1+5.44×10^-10−0.54×10^-10)。重力の効果(進む)が速度の効果(遅れる)の10倍あり、差し引きで衛星の時計が進む。
- 作問メモ: 「既習の現象(ドップラー効果+慣性力)から未習の結論を受験生自身に導かせ → 本文がその物理的解釈と一般原理(等価原理)を宣言 → ポテンシャルで一般化(N 分割と積の近似式で証明させる)→ 未習の式を1本だけ追加して実用例(GPS)の数値評価」という4段構成の L2。未習の式を天下りで与えるのは最後の特殊相対論の1本だけで、主役の結論は誘導で導かせている。冒頭に近似式を置き、全問を「1+(微小量)」の形に統一しているので、答の形が揃い採点もしやすい。本文約80行と京大でも長い部類。
