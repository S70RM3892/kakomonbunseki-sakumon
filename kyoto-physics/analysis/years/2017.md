## 大問I(力学/円弧状二重レール内の球の運動と衝突)

- 流れ: 水平台上にばねの打ち出し装置、質量 m の同一の球①②、半径 r の半円の二重レール(内側・外側、下端 A、上端 B、A と B は同一鉛直線上)。球は内外どちらのレールからも抗力を受けられる。
  - ア: 打ち出し直後の運動エネルギー E のとき、点 B での速さ(√(2E/m − 4gr))
  - イ: B から水平投射され A から左に L = 4r に落下 → B での速さ(2√(gr))
  - ウ: そのときの E(4mgr)
  - エ: 反発係数 0.5 で球②に衝突した直後の球①の運動エネルギー E1(E/16)
  - オ: 球②の E2(9E/16)
  - カ: 途中で速さ 0 になる高さの比 h2/h1(9)
  - キ: ばねを最も縮めた場合(E = 4mgr)の E2((9/4)mgr)
  - ク: 球②が B から水平投射されて落ちる距離 L(√2 r)
  - ケ: 中心方向の運動方程式 m v²/r = F − mg cosθ
  - コ: (1/2)mv² = E2 − mgr(1 − cosθ)
  - サ: 速さ 0 になる角 θV(> 90°)と F = 0 になる角 θF の関係 cosθF/cosθV(2/3)
  - 問1(論述、100字以内): 内側レールを外すと θF でレールを離れ斜方投射になり、最高点が h2 より低くなる理由。二重レールでは最高点で速さが 0 になり運動エネルギーがすべて位置エネルギーに変わるが、内側レールがないと θF で離れた後は水平方向の速度成分が保たれ、最高点でも運動エネルギーが残るので、その分だけ到達高さが低くなる。
- その場で与えられた知識: なし(L0)。「F が正なら外側レールから、負なら内側レールから抗力を受ける」という符号の読み方は説明されるが、既習の円運動の範囲。
- 解法の核心・差がつく点: 同質量・反発係数 e の衝突で速度は (1−e)/2 倍と (1+e)/2 倍、エネルギーは 1/16 と 9/16。二重レールなので B に達する条件は「速さ ≥ 0」でよく、キ・クは B での速さ √(gr/2) でも成立する。サは 2 式から v を消去し、E2 − mgr = −mgr cosθV を代入すると 3cosθF = 2cosθV。
- 作問メモ: 「離れることのできないレール(二重レール)で“糸・片側レールの円運動”の定番を裏返す」型。抗力の符号で内外どちらに押されているかを読ませ、最後に片側レールに戻して違い(最高点の高さ)を論述させる。前半に衝突(反発係数)と水平投射を足して空欄数を稼いでいる。

## 大問II(電磁気/(1) ホール効果、(2) 半導体中の電子群の走行時間測定)

### (1) 導体のホール効果

- 流れ: 奥行き w、高さ d の細長い直方体の導体。電気量 −q の自由電子が数密度 n。面 A(左)、H(右)、D(前)、J(背)、G(上)、K(下)。両端に電池をつなぎ、電子は x 軸正の向きに進む。速さに比例する抵抗力(係数 k)。その後 z 軸正の向きに磁束密度 B を加える。
  - イ: 電気力の大きさ(qE1)
  - ロ: 終端の速さ v1(qE1/k)
  - ハ: ローレンツ力の大きさ(qv1B)
  - ニ: その向き(y 軸の正)
  - ホ: 電子が集まる面(J)
  - ヘ: E2(v1B)
  - ト: 向かい合う面の間の電圧 U(v1Bw)
  - チ: 電流 I(qnv1wd)
  - リ: B = リ × nU/I(qd)
- その場で与えられた知識: なし(L0)。ホール効果は教科書本文。
- 解法の核心・差がつく点: 電子は負電荷で速度が +x、B が +z なので力は +y(背面 J)。図1の y 軸が奥向きであることを読み取る。
- 作問メモ: 面に記号を振って向きを選択させるホール効果の基本形。(2) への導入(キャリアの速さと電流の関係)として置かれている。

### (2) 半導体中を走る電子シートによる誘導電流

- 流れ: 長さ L の半導体の両端面 A、H のすぐ外に面積 S の金属板 a、h を置き、電池(電圧 V)と小さな抵抗をつなぐ。半導体には元々自由電子がなく、全体は平行板コンデンサー(誘電率 ε)として働く。t = 0 に面 A に電子 N 個(電荷 −qN)を一様に注入すると、シート状のまま一定の速さ v2 で H に向かう。これを「−qN に帯電した薄い導体 m」とみなし、さらに短い導線でつないだ金属板 a'、h' に置き換えて、コンデンサー①(間隔 v2t)と②(間隔 L − v2t)の直列として扱う。
  - ヌ: C = εS/L
  - ル: コンデンサー①の容量(CL/(v2t))
  - ヲ: コンデンサー②の容量(CL/(L − v2t))
  - ワ: V1 = (Q − q1)v2t/(CL)
  - カ: V2 = (Q + q2)(L − v2t)/(CL)
  - ヨ: q2 = (qN/L) × v2t、したがって抵抗を流れる電流 Id = (qN/L) × v2
  - タ: 電子群が面 H に到達した後の電流(0)
  - 問1(グラフ): 電流の大きさは 0 < t < L/v2 で一定値 Id、t > L/v2 で 0 の矩形。
- その場で与えられた知識:
  - [L1] 電子シートを薄い導体とみなし、2個のコンデンサーに置き換えるモデル: 「このシート状の電子群は、コンデンサーの極板の間に挿入された十分に薄い導体とみなすことができる」「導体 m を短い導線でつながれた金属板 a'、h' に置き換えて考える」と述べ、図4で各極板の電荷(−Q+q1、Q−q1、−Q−q2、Q+q2)まで与える。ル〜ヨで、V1 + V2 = Q/C と q1 + q2 = qN を連立するのに使う。
- 解法の核心・差がつく点: V1 + V2 = V = Q/C に代入すると Q の項が消え、q2L = (q1 + q2)v2t = qN v2t。電流は q2 の時間変化率なので一定。極板間に帯電した導体板を入れる問題(受験定番)の、板が動く版と見抜けば速い。
- 作問メモ: 「実際の測定法(走行時間法:キャリアの移動による誘導電流を外部回路で測る)を、極板間に帯電導体板を挿入したコンデンサーという既習モデルに落とし、誘導電荷の時間変化から電流を求め、グラフで“何が測れるか”を確認する」型。モデル化の各段階(シート → 導体 → 2コンデンサー、極板の電荷の置き方)をすべて問題文が指定するので、受験生の作業は連立だけ。新しい量や式を与えないまま、見慣れない現象を扱う京大らしい作り。

## 大問III(波動/音速の異なる領域と壁反射を含むドップラー効果)

- 流れ: 薄い壁 M(y 軸上)で隔てられた部屋 R(音速 cR、気温が高く cR > c)と広場 P(音速 c)。広場の車 S が振動数 f の音を出し続ける。音は壁を振動させて部屋に伝わり、また壁で反射する。
  - あ: 広場での波長(c/f)
  - い: 部屋での波長(cR/f)
  - う: 部屋で静止した観測者 Q が聞く振動数(f)
  - え: S が +x に速さ V で動くとき、−x 向きに伝わる音の波長((c+V)/f)
  - お: 壁で反射して戻った音を運転手 D が聞く振動数(f(c−V)/(c+V))
  - か: 部屋の中での波長(cR(c+V)/(cf))
  - き: +x 向きに速さ W で壁に駆け寄る Q が聞く振動数(f·c(cR+W)/(cR(c+V)))
  - く: S が走路 T(x = L)上を −y に速さ U で動くとき、角 θ の向きに進む音について、車の速度の音の進行方向成分(U sinθ)
  - け: 波長は静止時の何倍か(1 − (U/c)sinθ)
  - こ: 音が「S → 壁 M → 走路 T と交差する点」を伝わる間に車が進むべき距離(2L tanθ)
  - さ: sinθ = U/c
  - し: D が聞く反射音の振動数(f)
  - す・せ: 直接音と反射音が弱め合う条件 L = (√(c²−U²)/(2f)) × (n+1)(せは ②)
- その場で与えられた知識:
  - [L1] 斜め方向のドップラー効果: 「車 S が移動する速度には音波が進む方向の成分がある」と誘導し、その成分で波長を求めさせる(く・け・し)。教科書の発展・受験定番。
- 解法の核心・差がつく点: 媒質の境界では振動数が変わらず波長だけ変わる(い、か)。きは「壁を振動数 fc/(c+V) の音源」とみなして部屋側の音速 cR で観測者のドップラーを考える。(3) は音の経路長 2L/cosθ と車の移動 2L tanθ の時間を等置。反射音は音源・観測者とも進行方向成分が U sinθ で打ち消し合い、振動数は f に戻る。(4) は反射音の所要時間 2L/√(c²−U²) の間の位相 2πf·2L/√(c²−U²) に固定端反射の π を加え、弱め合いは f·2L/√(c²−U²) が整数(L > 0 なので n+1)。
- 作問メモ: 「ドップラー効果を、(i) 異なる媒質への透過(波長だけ変化)、(ii) 反射+動く観測者、(iii) 斜め方向で“自分に戻ってくる音の方向”を幾何で決める、(iv) 直接音との干渉」と段階的に積む型。(iii) の「車が動いた先で反射音と出会う条件から sinθ = U/c」は、動く系での光の経路(光行差・光時計)と同じ幾何で、既習事項だけで新鮮な結論を引き出している。
