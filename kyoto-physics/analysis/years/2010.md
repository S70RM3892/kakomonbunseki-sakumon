## 大問I(力学/台車につるした振り子とひも切断後の壁との衝突、系の重心)

- 流れ: 質量 M・全長 2L の台車の中央の支柱から長さ h のひもで質量 m の小球をつるす。最下点 B で小球は台車上面に滑らかに接する。台車の右端に壁 C(反発係数 e)、左端が D。小球をひもが水平な点 A からはなし、最下点でひもを切り、壁 C ではね返って端 D に至るまでを追う。(1) 台車固定、(2) 台車が床上を自由に動く。
  - ア(最下点直前の速さ): √(2gh)
  - イ(張力): 3mg
  - ウ(B から壁を経て D までの時間): L(e+2)/(e√(2gh))
  - エ(台車が動くときの最下点での小球の速さ): √(2Mgh/(M+m))
  - オ(そのときの張力): (3M+2m)mg/M
  - カ(台車に対する相対的な速さ): √(2(M+m)gh/M)
  - キ(B → C の時間): L√(M/(2(M+m)gh))
  - ク(C → D の時間): (2L/e)√(M/(2(M+m)gh))
  - ケ(固定時のウの何倍か): √(M/(M+m))
  - 問1(重心が水平に動かない理由、50字以内): 系に水平方向の外力がはたらかず、はじめ静止していたので、水平方向の運動量が 0 のまま保存されるから。
  - 問2(D 到達時の台車の位置、導出つき): 台車の変位を X とすると、小球の台車中央に対する位置は −h から −L に変わるので小球の変位は X − (L − h)。mX − m(L − h) + MX = 0 より X = m(L − h)/(M + m)。すなわち最初の位置から壁 C の側(x 正の向き)に m(L−h)/(M+m)。
- その場で与えられた知識:
  - [L1] 系の重心(質量中心)の水平位置が不変: 問1で「小球と台車をまとめて一つの系と呼ぶ」「この系の重心(質量中心)は水平方向には動かない」と結果を与え、理由を書かせたうえで、問2で「このことを利用して」台車の位置を求めさせる。2物体の重心は現行教科書本文にあり、重心不動の利用は受験定番。
- 解法の核心・差がつく点: オの張力は、最下点では台車の水平加速度が 0 なので台車から見た円運動(相対速度カ)で mu²/h = T − mg とする。相対速度が √((M+m)/M) 倍になるので時間は √(M/(M+m)) 倍。問2は途中経過(衝突の e)によらず初めと終わりの相対位置だけで決まる。
- 作問メモ: 「同じ操作を、台を固定した場合 → 台が自由に動く場合の順に繰り返し、最後に比(何倍か)を答えさせる」型。締めに「重心不動」を理由説明+応用の2段で問い、途中の衝突の詳細が不要になることに気づかせる。

## 大問II(電磁気/時間的に矩形波状に切り替わる電場・磁場中の荷電粒子)

- 流れ: 質量 m、電荷 q(>0)の粒子 P。(1) 一様電場 E_y が周期 T で前半 +E0、後半 −E0。(1a) 初速 0、(1b) 原点付近にとどまる初速を選ぶ。(2) 前半は電場 +E0 のみ、後半は z 正の向きの磁場 B0 のみ。
  - イ(t = T/2 の v_y): qE0T/(2m)
  - ロ(t = T/2 の y): qE0T²/(8m)
  - ハ(T/2 < t ≦ T の v_y): (qE0/m)(T − t)
  - 問1: v_y は 0 → qE0T/(2m)(t = T/2)→ 0(t = T)の三角波を 2 周期。y は単調増加の S 字(下に凸の放物線 → 上に凸の放物線)の繰り返しで、y(T) = qE0T²/(4m)、y(2T) = qE0T²/(2m)。
  - ニ(とどまるための初速 v_y): −qE0T/(4m)
  - ホ(T/2 < t ≦ T の v_y): (qE0/m)(3T/4 − t)
  - 問2: v_y は −qE0T/(4m) → +qE0T/(4m)(t = T/2)→ −qE0T/(4m)(t = T)の三角波。y は t = T/4 で最小(−qE0T²/(32m))、T/2 で 0、3T/4 で最大(+qE0T²/(32m))、T で 0 の放物線をつないだ波形の繰り返し。
  - ヘ(ローレンツ力の大きさ): q²E0B0T/(4m)
  - ト(円運動の中心の x 座標): E0T/(4B0)
  - チ(後半の軌跡の長さ): qE0T²/(8m)
  - リ(半周で戻る B0): 2πm/(qT)
  - ヌ(t = T での x 座標): qE0T²/(4πm)
  - 問3: 原点から y 軸上を −qE0T²/(32m) まで下がって原点に戻り(+y 向き)、中心 (qE0T²/(8πm), 0) の半円を時計回りに描いて (qE0T²/(4πm), 0) に −y 向きで到達。以後同じ形を x 方向に qE0T²/(4πm) ずつずらして繰り返す(t = 2T で x = qE0T²/(2πm))。t = 3T/4 の y 座標は qE0T²/(8πm)、t = T の x 座標は qE0T²/(4πm)。
- その場で与えられた知識: なし(L0)。等加速度運動とローレンツ力による等速円運動のみ。
- 解法の核心・差がつく点: (1b) は y(T/2) = 0 から初速が決まり、v_y(T/2) = −(初速) となる対称性を押さえる。(2) の磁場区間は速さ一定なので軌跡長は v×T/2 で B0 によらない。半周の条件 πm/(qB0) = T/2。力の向きは +y の速度 × +z の磁場で +x。
- 作問メモ: 「時間的に切り替わる場」を区間ごとに既習の運動(等加速度・円運動)に分け、各区間の終状態を次の初期条件にする型。(1a) 離れていく → (1b) 初速でとどまる → (2) 後半を磁場に置き換えるとドリフトする、と条件を一つずつ変える。グラフ・軌跡の描図が3問あり、式より図で理解を問う。題材は粒子の閉じ込め・ドリフト(novel_context)だが知識は L0。

## 大問III(波動+熱/クント管型の気柱共鳴、変位と密度、音速の温度依存)

- 流れ: 一端が振動板(スピーカー)、他端が外気圧とつり合うように動くふた(音では振動しない)の円筒容器に空気を密閉。内壁の軽い粉が共鳴時に等間隔に集まる。温度 T_A、気柱長 ℓ_A、振動数 f で 3 か所(x = 0、2ℓ_A/5、4ℓ_A/5)に集まった。
  - 問1(変位のグラフ): ふたが固定端(節)なので、粉の位置が節だと等間隔にならず、粉の位置は腹。y = A cos(5πx/(2ℓ_A))(またはその符号反転): x = 0、2ℓ_A/5、4ℓ_A/5 が腹、ℓ_A/5、3ℓ_A/5、ℓ_A が節。
  - あ(λ_A): 4ℓ_A/5
  - い(V_A): 4ℓ_A f/5
  - う(最低の共鳴振動数): f/5
  - え、お(筒領域 II の両端): x + y、x + Δx + y + Δy
  - か(密度の比): 1/(1 + Δy/Δx)
  - き(密度最小の位置): ③ 傾きが最大
  - 問2: 問1で x = 0 の変位を正にとった場合、密度最大(○)は x = ℓ_A/5、密度最小(×)は x = 3ℓ_A/5(符号を逆に描いた場合は入れ替わる)。端点 x = ℓ_A は除外。
  - く(λ_B、粉 4 か所): 4ℓ_B/7
  - け(T_B、定圧変化): T_A ℓ_B/ℓ_A
  - こ(音速一定と仮定したときの ℓ_B/ℓ_A): 7/5(1.4)
  - さ: 7T_A/5
  - し(実際の比): ① より大きくなる
  - 問3(V = V0 + bT の定数): 4ℓ_A f/5 = V0 + bT_A、4ℓ_B f/7 = V0 + bT_A ℓ_B/ℓ_A を連立して b = 4fℓ_A(5ℓ_B − 7ℓ_A)/(35T_A(ℓ_B − ℓ_A))、V0 = 8fℓ_Aℓ_B/(35(ℓ_B − ℓ_A))。
- その場で与えられた知識:
  - [L1] 縦波の変位の勾配と密度の関係: 微小な筒領域 I(x 〜 x+Δx)が x+y 〜 x+Δx+y+Δy に移ることを空欄で誘導し、密度比 1/(1+Δy/Δx) を導かせる。教科書本文は「疎・密」の定性的説明まで。定量化は受験定番(節で密度変化最大)。
  - [L1] 粉の集まりによる定常波の可視化(クントの実験): 教科書の参考・実験扱い。ただし「粉がどちらに集まるか」は知識でなく、固定端条件と等間隔性から決めさせる。
  - [L0 相当、記録のみ] 音速の式 V = V0 + bT(絶対温度の一次式): 式(1)として与える。教科書の V = 331.5 + 0.6t と同じ形なので範囲内。
- 解法の核心・差がつく点: 粉の位置が腹か節かを、ふた = 固定端と目盛り(ℓ_A/5)から論理的に決める(節と仮定すると x = 4ℓ_A/5 と ℓ_A が節どうしで間隔が合わない)。ふたが外気圧とつり合って動く → 定圧変化 → ℓ ∝ T。密度は傾き Δy/Δx が最大で最小、最小(負で絶対値最大)で最大。
- 作問メモ: 「共鳴の測定(腹の数と気柱長)を 2 つの温度で行い、未知の定数 2 個(V0、b)を測定値だけで表させる」実験データ処理型。途中に「音速一定なら」という反実仮想を挟んで比較させる。気柱(波動)にシャルルの法則(熱)を重ねて ℓ と T を結ぶのが融合の要。変位 → 密度の微小量誘導は独立したブロックとして差し込める。
