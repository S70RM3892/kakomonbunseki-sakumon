## 大問I(力学/人工衛星)

### (1) ひもでつないだ小物体と張力

- 流れ: 質量 M の地球のまわりを半径 R、角速度 ω で回る人工衛星 Z に、地球と反対側へ長さ a のひもで小物体 A(質量 m_A)、地球側へ長さ b のひもで小物体 B(質量 m_B)をつなぐ。常に一直線の配置を保ち、Z は元の円軌道を角速度 ω のまま回る。
  - ア: A にはたらく万有引力 GMm_A/(R + a)^2
  - イ: A の遠心力 m_A(R + a)ω^2
  - ウ: B にはたらく万有引力 GMm_B/(R − b)^2
  - エ: B の遠心力 m_B(R − b)ω^2
  - オ: N_A = cN_B の c = 1(Z の軌道が変わらないので、Z にかかる2本の張力がつりあう)
  - カ: m_A/m_B = (a/b)^k の k = −1(m_A a = m_B b)
  - キ: N_A/a = 3m_A ω^2
- その場で与えられた知識:
  - [L1] 近似式 1/(R ± ε)^n ≒ (1/R^n)(1 ∓ nε/R): 本文中で与える。カ・キ で使用。
- 解法の核心・差がつく点: Z 自身の円運動から GM = R^3 ω^2。これで G、M を消し、近似式で1次の項を拾うと N_A ≒ 3m_A ω^2 a、N_B ≒ 3m_B ω^2 b。係数3(遠心力の変化 1 + 万有引力の変化 2)を落とさないこと。
- 作問メモ: 「回転座標系でのつりあいを2物体について立て、基準軌道の条件で定数を消し、微小量の1次で差を取り出す」型。潮汐力という範囲外の概念を、名前を出さずに既習の式の差として計算させている。「軌道が変わらない」という条件から c = 1 を読み取らせる数値空欄が読解の確認になっている。

### (2) 軌道ランデブー

- 流れ: Z から角度 θ 遅れて同じ円軌道を回る宇宙船 U が、点 C で進行方向を変えずに減速して楕円軌道(近地点 D、OD = d)に移り、1周して C に戻ったときに Z に追いつく。
  - ク: V_0 = √(GM/R)
  - ケ: T_1/T_0 = 1 − θ/(2π)
  - コ: d/R = 2(T_1/T_0)^{2/3} − 1
  - サ: V_1/V_0 = √(2d/(R + d))
  - 問1: θ ≪ π のとき d/R ≒ 1 − 2θ/(3π)、V_1/V_0 ≒ 1 − θ/(6π) なので ΔV = −θV_0/(6π)。比例係数 ΔV/(θV_0) = −1/(6π)
- その場で与えられた知識:
  - [L1] 楕円軌道でのケプラーの第2・第3法則とエネルギー保存の連立: 使う法則を名指しで指示(式は与えない)。受験定番。
  - [L1] 近似式 (1 + δ)^x ≒ 1 + xδ: 問1で与える。
- 解法の核心・差がつく点: ケ は Z が (2π − θ) だけ回る時間が楕円の周期に等しいこと。問1は 2/3 乗と平方根の2段の近似を θ の1次で正しくつなぐ。答が負(減速すると追いつく)であることの確認。
- 作問メモ: 「定番の楕円軌道計算(面積速度+エネルギー保存+第3法則)に、追いつくための時間条件を1つ加え、最後に微小量で線形化して比例係数を出させる」型。直観に反する結論(追いつくには減速)が題材の魅力で、物理は増やしていない。最後の記述問で近似の連鎖を書かせるのは京大の定型。

## 大問II(電磁気/円錐形の磁場分布での電磁誘導、ベータトロン条件)

- 流れ: z 軸対称で、z = 0 の面内の磁束密度が軸上で B_0、軸からの距離の1次関数で減少して距離 R で 0 になる磁場。(1) 時間変化しない磁場中で、長さ R の導体棒 OA を角速度 ω で回す。(2) 半径 R、半径 a の円を貫く磁束。(3) B_0 = bt と時間変化させ、距離 a に静止していた電子が半径 a を保って円運動する条件。
  - イ: B(r) = B_0(1 − r/R)
  - ロ: 電子にはたらくローレンツ力 erωB_0(1 − r/R)
  - ハ: 電場 E = rωB_0(1 − r/R)
  - ニ: 両端間の電位差 ωB_0R^2/6
  - ホ: ΔΦ = B_0(1 − r/R)ΔS
  - 問1: 半径 a の内側の磁場を「一様な B_0(1 − a/R)」と「軸上で B_0 a/R、半径 a で 0 になる円錐形」に分けると、Φ_a = πa^2 B_0(1 − a/R) + (1/3)πa^2 B_0 a/R = πB_0a^2(1 − 2a/(3R))
  - ヘ: 誘導電場 E = (ba/2)(1 − 2a/(3R))
  - ト: 速さ v = (ebat/(2m))(1 − 2a/(3R))
  - 問2: 円運動の式 mv^2/a = evB(a) より mv = eabt(1 − a/R)。ト と等置して (1/2)(1 − 2a/(3R)) = 1 − a/R、よって a/R = 3/4
- その場で与えられた知識:
  - [L1] 電位差 = E(r) のグラフの面積: 本文で説明。
  - [L1] 面積公式 (q − p)^3/6: 「用いてよい」。ニ で使用。
  - [L1] 非一様磁場の磁束 = ΔΦ の総和、Φ_R = (1/3)πR^2 B_0: 積分結果を与える。問1で使用。
  - [L1] 誘導電場による電子の加速(ベータトロン): 機構を1文で述べる。条件は問2で自力導出。
- 解法の核心・差がつく点: 問1で、与えられた Φ_R(円錐の体積に当たる)をどう再利用するか。問2で、加速を決めるのは軌道の内側の全磁束、向心力を決めるのは軌道上の磁束密度、という2つの式を連立し、時刻 t が消えることを示す。
- 作問メモ: 「一様磁場の定番(回転棒の起電力、ベータトロン)を、単純な関数形の非一様磁場に置き換え、積分が必要な箇所は図形の面積・体積の結果を与えて回避する」型。磁場分布を1次関数にしたことで、ベータトロン条件が a/R = 3/4 という具体的な数値で出る。受験定番の結論(平均磁束密度が軌道上の2倍)を暗記していても、分布に合わせて計算し直す必要がある。

## 大問III(波動/薄膜の多重反射による干渉)

- 流れ: 大気中の厚さ D、屈折率 n(> 1)の薄膜に、電場 E sin 2π(ft − z/λ) の光を垂直に入射。面での反射で振幅 p 倍、大気から膜への透過で q 倍、膜から大気への透過で q' 倍。反射光 R_0、R_1 の干渉、透過光 T_1、T_2 の干渉、全透過光の干渉、透過スペクトル。
  - あ: 膜中の波長 λ/n
  - い: E_R0 = −pE sin 2π(ft + z/λ)(屈折率の大きい媒質での反射で位相が π ずれる)
  - う: E_T1' = qE sin 2π(ft − nz/λ)
  - え: E' = pqq'E
  - お: φ = −4πnD/λ
  - 問1: A^2 = p^2E^2(1 + q^2q'^2 − 2qq' cos φ)
  - か: 反射光が最大となる D/λ = (2m − 1)/(4n)
  - き: そのときの振幅 pE(1 + qq')
  - く: 透過光 T_1、T_2 が強め合う D/λ = m/(2n)
  - け: 振幅 qq'E(1 + p^2)
  - こ: 最小となる D/λ = (2m − 1)/(4n)
  - さ: 振幅 qq'E(1 − p^2)
  - 問2: 透過光 T_k の振幅は qq'E p^{2(k−1)} で、隣どうしの位相差は φ。く の条件では全部同位相で和は qq'E/(1 − p^2) = E、強度 E^2。こ の条件では符号が交互で和は qq'E/(1 + p^2)、強度 E^2{(1 − p^2)/(1 + p^2)}^2
  - 問3: 薄膜 X。p が 1 に近い膜。強め合う波長では強度が p によらず E^2、それ以外では p が 1 に近いほど強度が 0 に近づくので、ピークが鋭く、特定の波長だけを取り出せる
- その場で与えられた知識:
  - [L1] 光の強度 = 電場の振幅の2乗: 「…を光の強度とよぶことにする」と定義。
  - [L1] 振幅の変化率 p、q、q': 反射で p 倍、透過で q 倍または q' 倍、透過では位相は変化しない、と文章で定義。反射の位相変化は与えられない。
  - [L1] 関係式 p^2 + qq' = 1: 問2で「成り立つものとする」と根拠なしに与え、q と q' を消すのに使う。
  - [L1] 三角関数の合成: 問1で与える。
  - [L1] 無限等比級数の和: 問2で与える。
- 解法の核心・差がつく点: 面 A の外側での反射だけ位相が π ずれ、膜の内側での反射(面 A、面 B とも)はずれない。これを波の式の符号に正しく入れること。反射光が強め合う条件と透過光が弱め合う条件が同じ D になることが確認になる。問2は多重反射の振幅が公比 p^2(または −p^2)の等比数列になることに気づけるか。
- 作問メモ: 「教科書の薄膜干渉(光路差と位相変化の条件だけ)を、波の式と振幅まで含めた定量的な扱いに引き上げ、2光束 → 無限個の光束へ拡張し、最後に測定データ(スペクトル)と対応させて装置の設計指針を論述させる」型。振幅比を文字 p、q、q' で置き、必要な関係式は1本だけ与える。ファブリ・ペロー干渉計という範囲外の装置を、名前を出さずに既習の重ね合わせで組み立てている。L2 の型(未習の量を定義して使わせる)に近いが、新しい量は比例定数の命名にとどまるので L1 とした。
