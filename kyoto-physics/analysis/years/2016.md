## 大問I(力学/なめらかな台上の球とばね:2体系の運動量・エネルギー保存)

- 流れ: 傾斜角 θ の斜面と水平面をもつ質量 M の台 Q(床との摩擦なし、水平面右端にばね定数 k のばね)。(1) 球 P(質量 m)を高さ h に載せ、台を糸で一定の力で引くと P は高さ h にとどまる。(2) 台の速度が V0 のとき糸を切ると P が滑り降りる。(3) P がばねを縮める。(4) P がばねから離れる。最後に「離れた後 P は床に対して静止」の条件。速度は床に対して、右向き正。
  - ア: 抗力と重力の合力が水平となす角(0)
  - イ: 抗力(mg/cosθ)
  - ウ: 合力の大きさ(mg tanθ)
  - エ: P の水平加速度(g tanθ)
  - オ: 台に働く合力(Mg tanθ)
  - カ: 糸の張力((M+m)g tanθ)
  - キ: v1 = V0 + √(2Mgh/(M+m))
  - ク: V1 = V0 − (m/M)√(2Mgh/(M+m)) = V0 − m√(2gh/(M(M+m)))
  - ケ: v2 = V0、コ: V2 = V0
  - サ: X = √(2mgh/k)
  - シ: v3 = V0 − √(2Mgh/(M+m))
  - ス: T = (1/(g tanθ))√(2Mgh/(M+m))
  - セ: V0 = √(2Mgh/(M+m))
  - 問1(グラフ): M = 3m、v3 = 0 のとき、P・Q・重心の速度の時間変化を t1(ばねに到達)、t2(最大縮み)、t3(離れる)の値つきで描く。V0 = √(3gh/2) として、P は 2V0 → V0 → 0、Q は (2/3)V0 → V0 → (4/3)V0、重心は常に V0(水平な直線)。t1 以前と t3 以後は一定。t1〜t3 は相対運動が単振動の半周期なので、P は V0(1+cosφ)(t1〜t2 で上に凸、t2〜t3 で下に凸)、Q は V0(1−(1/3)cosφ)(t1〜t2 で下に凸、t2〜t3 で上に凸)。数値で書けば P: √(6gh) → √(3gh/2) → 0、Q: √(2gh/3) → √(3gh/2) → 2√(2gh/3)。
- その場で与えられた知識:
  - [L1] 重心の速度: 定義は与えず、問1で「球 P と台 Q の重心の速度」を描かせる。運動量保存から一定と判断する(受験定番)。
- 解法の核心・差がつく点: (1) は P が台と同じ加速度で動くことから合力が水平。(2) 以降は水平方向の運動量保存と力学的エネルギー保存で、相対速度 u について (1/2)·(mM/(m+M))·u² = mgh と書くと速い。ばねとの相互作用は弾性衝突と同じで、相対速度が反転する(v3 − V0 = −(v1 − V0))。グラフは重心速度 V0 を軸に対称的に動くことと凹凸の判断で差がつく。
- 作問メモ: 「外力で一体運動(慣性力のつりあい)→ 外力を切って内力だけの2体問題 → ばねによる“ゆっくりした弾性衝突” → 終状態の条件から初期条件を逆算 → 速度–時間グラフで総まとめ」という型。重心速度をグラフに描かせることで、重心系の見方を明示せずに要求している。

## 大問II(電磁気/磁場中の導体棒・抵抗・コイル:終端速度とLC型振動の力学的対応)

- 流れ: 間隔 ℓ のレール上に質量 M の導体棒、鉛直上向き一様磁場 B。回路に抵抗 R(スイッチと並列)と自己インダクタンス L のコイルが直列。棒は質量 m のおもりで右向きに mg で引かれる。前半はスイッチ開(R と L が直列)、後半は糸を切ると同時にスイッチを閉じる(R を短絡、L のみ)。図1の回路は「R とスイッチが並列、それとコイルが直列」と読み取った。
  - イ: 磁場から受ける力(IBℓ、左向き)
  - ロ: Δv/Δt = (mg − IBℓ)/(M+m)
  - ハ: 誘導起電力(vBℓ)
  - ニ: コイルの起電力(−L ΔI/Δt)
  - ホ: ΔI/Δt = (vBℓ − RI)/L
  - ヘ: v0 = mgR/(Bℓ)²
  - ト: I0 = mg/(Bℓ)
  - 問1(論述): ΔEm/Δt = (M+m)v Δv/Δt − mgv = −IBℓv、ΔEc/Δt = LI ΔI/Δt = IBℓv − RI²。和は −RI²。すなわち、力学的エネルギーの減少分(磁場からの力に逆らってした仕事)が回路の電気的エネルギーに移り、その一部がコイルに蓄えられ、残りが抵抗でジュール熱 RI² として失われる。力学的エネルギーとコイルのエネルギーの和の減少率はジュール熱の発生率に等しい。
  - チ: Δv/Δt = −IBℓ/M
  - リ: ΔI/Δt = vBℓ/L
  - ヌ: x = (L/(Bℓ)) × I
  - ル: ばね定数 (Bℓ)²/L
  - ヲ: T = 2π√(ML)/(Bℓ)
  - ワ: 速度の位相は電流より ①(π/2 進んでいる)
  - カ: v1 = √(v0² + L I0²/M)
  - ヨ: I1 = √(I0² + M v0²/L)
  - 問2(グラフ): v0 = 1 m/s、I0 = 1 A、L = 1 H、M = 1 kg では振幅はともに √2。t0 からの経過時間を t' として v = √2 cos(2πt'/T + π/4)、I = √2 sin(2πt'/T + π/4)。v は 1 から減少し T/8 で 0、3T/8 で −√2、5T/8 で 0、7T/8 で +√2、T で 1。I は 1 から増加し T/8 で +√2、3T/8 で 0、5T/8 で −√2、7T/8 で 0、T で 1。
- その場で与えられた知識:
  - [L1] 瞬間的変化率の扱い(数学手法): 「きわめて短い時間 Δt の間の瞬間的変化率」として Δv/Δt、ΔI/Δt を導入し、問1で Δ((1/2)Mv²)/Δt = Mv Δv/Δt を「(Δv)²/Δt = 0 と置ける」ことを明示して示す。Δy/Δt = v も与える。問1で (1/2)mv²、(1/2)LI²、mgy の変化率を同じ要領で計算するのに使う。
  - [L1] 電気振動と単振動の対応(モデル): 式(3)(4)が図2のばね–質点系の運動で理解できると述べ、x = ヌ × I と置けば Δx/Δt = v となることを誘導する。ヌ・ル・ヲ・ワで使う。導体棒+コイルの単振動は受験定番。
- 解法の核心・差がつく点: 終端状態は ΔI/Δt = 0 かつ Δv/Δt = 0。後半は (1/2)Mv² + (1/2)LI² が保存することから振幅を出す(初期条件が v0 と I0 の両方 0 でない点に注意)。問2は初期位相 π/4 を、t0 直後に v が減り I が増えることから正しく決める。
- 作問メモ: 「力学系と回路を微小時間の変化率 2 本で連立させ、(a) 定常解、(b) エネルギー収支の論述、(c) 抵抗を外して保存系にし、変数変換で単振動に写す、(d) 数値を入れてグラフ」という型。微分を使わずに Δ 記法と「2 次の微小量は 0」を問題文で与えるのは京大物理の定番の語り口。

## 大問III(熱/U字管内の気体と液柱:加熱過程とつりあいの安定性)

- 流れ: 断熱材でできた断面積 S の U 字管。左管上端は栓で閉じ、なめらかに動くピストン(質量無視)との間に単原子理想気体 n モル、ヒーターつき。ピストンの下から右管にかけて密度 ρ の液体、右管上端は開放。
  - あ: 外気圧(P1 − ρgh)
  - い: ピストンが x 下がったときの圧力(P1 + 2ρgx)
  - う・え: 気体がした仕事 = P1S × x + ρgS × x²
  - お・か: 内部エネルギー変化 = (3/2)S(P1 + 2ρgℓ) × x + 3ρgS × x²
  - き・く: 加えた熱量 = S((5/2)P1 + 3ρgℓ) × x + 4ρgS × x²
  - け: 液体がすべて右管の直線部分にあるとき、熱 Q を加えたときの温度変化(2Q/(5nR))
  - こ: 気体がした仕事(2Q/5)
  - さ: 液面が上端に達した状態(圧力 P3、体積 V3)でピストンが Δy 上昇したとき、液体がピストンに及ぼす力の変化(+ρgSΔy、上向き正)
  - し: 気体がピストンに及ぼす力の変化(−5P3S²Δy/(3V3))
  - す: つりあいが安定である条件(ρg < 5P3S/(3V3)、すなわち 3ρgV3 < 5P3S)
  - 問1(論述): 熱を加えると液体があふれながら気体が膨張し、圧力 P は液柱が短くなる分だけ下がり、体積 V は増える。安定条件 5PS/(3V) > ρg の左辺は膨張とともに小さくなるので、やがて等号に達し、それ以降はつりあいが不安定になる。その時点で熱を加えなくてもピストンは一気に上昇し、残りの液体を管から押し出す。(液体がなくなるまで条件が保たれる場合は、最後までゆっくり膨張する。)
- その場で与えられた知識:
  - [L1] 近似式 (1+ε)^α ≒ 1+αε(数学手法): 「絶対値が十分小さな実数 ε と任意の実数 α に対して成り立つ近似式」として提示。「微小量 SΔy/V3 に対して (SΔy/V3)² が無視できる」ことも明示。空欄しで P3(1 + SΔy/V3)^(−5/3) の展開に使う。
  - [L1] ポアソンの式: 「断熱変化では(圧力)×(体積)^(5/3) が一定であること」と文中で与える。空欄しで使う。
  - [L1] 力のつりあいの安定・不安定(概念定義): 「変位を打ち消すような向きの力が発生する…このとき、力のつりあいは安定であるという」「変位をさらに増大させるような力が発生する…不安定であるという」と定義。空欄すで条件式にし、問1で膨張に伴う条件の変化を論じる。
- 解法の核心・差がつく点: (2) は圧力が x の 1 次式で増えるので仕事は台形の面積、内部エネルギーは (3/2)Δ(PV)。(3) は液柱の長さが一定なので定圧変化。(4) は液体側の力の変化(液柱が Δy 短くなる)と気体側の断熱的な圧力変化の符号を取り違えないこと。問1は「P が下がり V が増えるので安定条件がいずれ破れる」ことに気づけるか。
- 作問メモ: 「液柱で押さえた気体」という定番装置を、(i) 圧力が体積の 1 次関数で増える過程、(ii) 定圧過程、(iii) 圧力が体積の 1 次関数で減る過程、の 3 段階に使い分け、最後に微小変位の復元力から安定性を判定させる型。安定性の定義を文中で与えて条件式を作らせ、論述で定性的な帰結(不安定化して一気に噴出)を問う。安定条件は、準静的な P–V 直線の傾き −ρg/S と断熱曲線の傾き −(5/3)P/V の比較になっている。
