# 京大物理 2023年度

## 全体

- 冊子 1〜18 ページ。3題100点。試験時間の記載は冊子にない。3題とも単一構成(パート分けなし)。
- I 力学(万有引力・円軌道のまわりの微小振動と安定性)、II 電磁気+原子(同心球コンデンサーと光電子分光)、III 波動(偏光板と複屈折)。
- **L2 は III のみ: 偏光方向で屈折率が異なる透明物体(複屈折・1/2 波長板)による成分間の位相差と偏光方向の変化を、文章と式の誘導で与える。**
- I の関数 V(r)(有効ポテンシャル)は L2 との境界事例だが L1 と判定(下記の注)。
- 近似式の明示は I((1+x)^p ≒ 1+px など)と III(sinθ ≒ θ、(1+a/N²)^N ≒ 1+a/N)。グラフ描図が3題すべてにある。
- 最高レベル: I L1 / II L1 / III L2

## 大問I(力学/万有引力による軌道、円軌道まわりの微小振動と安定性)

- 流れ: (1) 地球(質量 M)のまわりを楕円軌道でまわる宇宙船 U(質量 m)。O に向かう方向の速さ u、垂直方向の速さ v、距離 r。(2) 半径 R の円軌道の U に、半径方向の弱い力が瞬間的に加わったあとの運動。(3) 引力が Am/r^k の天体 X のまわりで同じことを考える。
  - (1) ア: 運動エネルギー((1/2)m(u² + v²))
  - イ: 位置エネルギー(−GMm/r)
  - ウ: E = (1/2)mu² + V(r) と書いたときの V(r) = 2mS²/r² − GMm/r(S は面積速度)
  - 問1: V(r) の概形(r→0 で +∞、r = 2S²/(GM) で 0 を横切り、r = 4S²/(GM) で負の最小値、r→∞ で下から 0 に近づく)
  - (2) エ: 円軌道の周期 T = 2π√(R³/(GM))
  - オ: 面積速度一定から Δv = vΔR/R
  - カ: 万有引力の大きさの増分 = (2GMm/R³) × ΔR
  - キ: 遠心力の大きさの増分 = (3mv²/R²) × ΔR
  - ク: (引力の増分) − (遠心力の増分) = −(GMm/R³) × ΔR
  - ケ: 微小振動の周期 t と T の比 t/T(1)
  - (3) コ: 円運動の速さ = √(A/R^(k−1))
  - サ: 引力の大きさの増分 = (kAm/R^(k+1)) × ΔR
  - シ: (引力の増分) − (遠心力の増分) = −((3−k)Am/R^(k+1)) × ΔR
  - ス: 微小振動になる条件 k < 3
  - セ: t_X/T_X = 1/√(3−k)
  - 問2: k > 3 のとき、合力の増分は内向き(ずれと同じ向き)で、大きさは ΔR に比例して大きくなる。そのため U は元の円軌道に戻らず、ずれが増大して天体 X に向かって落ちていく(外向きにずれた場合は遠ざかっていく)。
- その場で与えられた知識:
  - [L1] 関数 V(r)(有効ポテンシャル): E = (1/2)mu² + V(r) の形を示し、r を含む項を V(r) として自分でまとめさせる。「E ≧ V(r) となる r の範囲が距離の変化する範囲」と読み方を説明。ウと問1で使う。
  - [L1] 近似式: 「|x|, |y| が1より十分小さいときに成り立つ近似式 (1+x)^p ≒ 1+px、(1+x)^p(1+y)^q ≒ 1+px+qy を用いよ」。カ・キ・サ・シで使う。「ΔR×Δv に比例する項を無視」とも指示。
  - [L1] ずれた位置での遠心力の評価: 「遠心力は半径 R−ΔR、速さ v+Δv の円運動と同様に考えることができる」「半径方向の力であるためケプラーの第2法則は常に成立する」。
  - [L1] 一般化した引力 Am/r^k: 「遠心力を表す式とケプラーの第2法則は変わらず成り立つものとする」と前提を明記。
- 解法の核心・差がつく点: キで Δv = vΔR/R を代入して増分を 3mv²ΔR/R² にまとめること。v² を引力の式で消すと k=2 では係数 2−3 = −1、一般には k−3。k=2 で t/T = 1(1周で元に戻る=軌道が閉じる)という結果の意味まで読み取れると問2が書きやすい。
- 作問メモ: 「既知の法則で具体例(k=2)を誘導 → 力の法則を一般化して同じ計算を繰り返させ、パラメータによる定性的な分岐(安定・不安定)を答えさせる」型。大学初年級の題材(円軌道の安定性)を、近似式を与えたうえで遠心力のつり合いからのずれとして処理させる。冒頭の V(r) は以降で使わない独立した導入になっている。
- 注: V(r) は有効ポテンシャルで、コードブックでは L2 の例に挙がる。ここでは名称も式も与えられず、面積速度一定とエネルギー保存から受験生が自分で作る形で、使うのもウと問1だけなので、低い方に倒して L1 とした。L2(軽め)とする判断もありうる。

## 大問II(電磁気・原子/同心球コンデンサーと光電子分光)

- 流れ: (1)(2) 点電荷と導体球 A(半径 a、電気量 Q)の電気力線・電場・電位。(3) 電荷のない中空導体球 B(内半径 b、厚さ d)で囲む。(4) B を接地してコンデンサーとみなす。(5) 半球形の内球・外球の間で電子を円運動させ、運動エネルギーを選別する。(6) 金属内の電子のエネルギー分布と光電効果。
  - イ: 点電荷 Q から出る電気力線の本数(4πkQ)
  - ロ: 導体球の電荷の分布(②球の表面に)
  - ハ: r < a の電場の強さ(0)
  - ニ: r < a の電位(kQ/a)
  - ホ: r = b と r = a の電位差(kQ(1/a − 1/b))
  - 問1: (3)の状態の電位のグラフ。r ≧ b+d で kQ/r、b < r < b+d で一定値 kQ/(b+d)、a < r < b で kQ/(b+d) + kQ(1/r − 1/b)、r ≦ a で一定値 kQ/(b+d) + kQ(1/a − 1/b)
  - ヘ: 接地で地表に流れた電気量(Q)
  - ト: 接地後の A の電位(kQ(b−a)/(ab))
  - チ: 電気容量(ab/(k(b−a)))
  - リ: 電位差 V0 を与えたときの領域 I の電場の強さ(abV0/((b−a)r²))
  - ヌ: 半径 r0 = (a+b)/2 の等速円運動をする電子の運動エネルギー K0 = eabV0/(b² − a²)
  - ル: 金属内でエネルギー Ei の電子が波長 λ の光で放出されたときの運動エネルギー KS = hc/λ − W − (EM − Ei)
  - 問2: 光電子数を KS の関数として描いたグラフの選択(③。KC 以下で分布し KC を超えると 0)、KC = hc/λ − W
- その場で与えられた知識:
  - [L1] 同心球コンデンサー: 電気力線の本数から誘導し、「導体球 A と中空導体球 B の組み合わせは Q の電気量を蓄えたコンデンサーとみなすことができる」と述べる。
  - [L1] 半球形電極によるエネルギー選別: 図2と本文で、特定の運動エネルギーの電子だけが半径 r0 の等速円運動をして出口スリットを通ると説明。端の電場の乱れは無視と明記。
  - [L1] 金属内の電子のエネルギー分布: 「金属内部の自由電子はいろいろなエネルギーをもっている。その最大値を EM とし…EM より低いエネルギーをもつ電子を取り出すには W より大きいエネルギーが必要」。ルと問2で使う。
- 解法の核心・差がつく点: 中空導体球を置いても a < r < b と r ≧ b+d の電場は変わらず、導体内部だけ電場が 0 になる(その分だけ内側の電位が持ち上がる)。リは Q を V0 で書き直す(kQ = abV0/(b−a))。問2は「Ei ≦ EM なので KS には上限がある」ことだけで選べる。
- 作問メモ: 「教科書の基本(電気力線・導体球)から定番(同心球コンデンサー)を経て、実在の測定装置(光電子分光の半球型分析器)の原理に着地させる」型。装置は新しく見えるが、必要なのは 1/r² の電場中の等速円運動だけ。最後に分野をまたいで光電効果に接続し、仕事関数の意味を一歩広げている。
- 注: 図3の ③ は KC 以下で一定の高さに描かれているが、分布の形そのものは問題文からは決まらない。上限の有無だけで判別した。

## 大問III(波動/偏光板による偏光の操作と複屈折)

- 流れ: 光の電場の振動方向を偏光の方向とよぶ。偏光板は透過軸に平行な電場成分だけを通す。検出器の信号強度は振幅の2乗に比例。入射光はあらゆる方向の振動を一様に含み、偏光板 A を通ったあとの強度は I0。(1) 偏光板2枚。(2) 偏光板を多数並べて偏光方向を回す。(3)(4) 偏光方向で屈折率が異なる透明物体を挟む。
  - (1) あ: A を 0、B を θB にしたときの強度(cos²θB × I0)
  - い: A と B を同じ角度にして変化させたときの強度(1 × I0)
  - (2) う: A(0)、C(π/4)、B(π/2)のときの強度(1/4 × I0)
  - え: A と B の間に N−1 枚を等間隔の角度で並べたときの強度(cos^(2N)(π/(2N)) × I0)
  - お: N = 3 のとき(27/64 × I0)
  - か: N が大きいときの近似 (1 − か × 1/N) × I0 の か(π²/4)
  - (3) き: x 方向成分に対する透明物体部分の光路長(nx d)
  - く: y 方向成分に対する光路長(ny d)
  - け: 光路差(|nx − ny| d)
  - こ: 2成分が逆位相になる光路差((m + 1/2)λ1)
  - さ: 最小の厚み d0 = λ1/(2|nx − ny|)
  - 問1: d = d0 で A・B をともに θ にして 0 から π/2 まで変えたときの強度のグラフ。I = I0 cos²2θ。θ = 0 と π/2 で最大値 I0、θ = π/4 で最小値 0。
  - (4) し: d = 20d0、θA = θB = π/4 のときの強度(1 × I0。光路差が 10λ1 で同位相に戻る)
  - 問2: (4)で強度が 0 になる波長 λ2 のうち、Δλ = |λ2 − λ1| の最小値。10λ1 = (m + 1/2)λ2 より λ2 = 20λ1/(2m+1)。m = 10 で λ2 = 20λ1/21、Δλ = λ1/21(m = 9 では λ1/19 でこれより大きい)。
- その場で与えられた知識:
  - [L2] 複屈折する透明物体と成分間の位相差: 「光の偏光の方向によって屈折率が異なる透明な媒質」「電場の振動方向が x 軸方向の場合の屈折率を nx、y 軸方向の場合を ny」と定義し、「光路差が…と表されるとき、x 軸方向成分と y 軸方向成分は逆位相となる。x 成分が Ex のままだとすれば y 成分は符号が反転し −Ey となる。これらがベクトルとして合成される結果、偏光方向が y 軸となす角度は 3π/4 となり、偏光板 B の透過軸と直交し、検出器の出力は 0 となる」と合成の仕方まで示す。き〜さで光路差の条件を立て、問1では任意の θ に自分で拡張し、し・問2では厚みと波長を変えて位相差を数える。
  - [L1] 偏光板と振幅ベクトル(マリュスの法則に相当): 「透過軸と平行に振動する電場成分を損失なく透過し、垂直な成分を完全に遮断する」「信号強度 I は入射する光の電場の振幅の2乗に比例する」。図1(b)で成分分解を図示。cos² の式は与えず、あ〜かで導かせる。
  - [L1] 近似式: 「|θ| ≪ 1 のとき sinθ ≒ θ」「|a|/N² ≪ 1 のとき (1 + a/N²)^N ≒ 1 + a/N」。か で使う。
- 解法の核心・差がつく点: 偏光板は「振幅を透過軸に射影する」操作、複屈折板は「一方の成分の位相をずらす」操作と整理する。問1は振幅ベクトル (sinθ, cosθ) の y 成分を反転して同じ向きの透過軸に射影し、sin²θ − cos²θ = −cos2θ。問2は厚みが 20 倍なので波長のわずかな変化で位相差が半波長ぶん動く。
- 作問メモ: 「既習の定性的な現象(偏光)を振幅ベクトルで定量化 → その道具で極限操作(N→∞)を計算 → 未習の素子(複屈折板)を成分ごとの光路長という既習の量で説明して適用 → 厚み・波長を変えて干渉条件を数えさせる」型。L2 部分は、最初の1例(θ = π/4)を本文で丁寧に解いてみせ、問1で一般の角度に拡張させる与え方。応用先(偏光顕微鏡)を最後に一言添えている。
