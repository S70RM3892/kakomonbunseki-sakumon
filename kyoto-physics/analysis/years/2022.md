## 大問I(力学/壁の半円筒くぼみでの弾性衝突・円運動・放物運動)

- 流れ: 鉛直な壁の、床から高さ R より上に半径 R の半円筒状のくぼみ(中心 O)。下端に静止した小球 A(質量 M)に小球 B(質量 m、速さ v)を水平に弾性衝突させ、A は速さ V でくぼみに沿って運動する。
  - (1) ア: 運動量保存の右辺(MV)
  - イ: エネルギー保存の右辺((1/2)mv'² + (1/2)MV²)
  - ウ: v = (M+m)V/(2m)
  - エ: v' = (M−m)V/(2m)
  - オ: B が左向きに跳ね返る条件(M > m)
  - カ: B の落下点と壁の距離 L_B = {(M−m)V/(2m)}√(2R/g)
  - キ: A がちょうど O の高さまで登る V(√(2gR))
  - ク: V < キ で A が下端に戻って飛び出し、B と同じ点に落ちる条件(M = 3m)
  - (2) ケ: 角度 θ(鉛直上向きから測る)で面から離れるときの速さ Vθ = √(gR cosθ)
  - コ: そのときの V = √(gR(2 + 3cosθ))
  - サ: 離れた A が出発点に落ちる直前の水平左向きの速さ V1 = (1/4)√(2gR)
  - シ: 同じく鉛直下向きの速さ V2 = (3/4)√(6gR)
  - ス: そこで跳ね返ったあとの床への落下点と壁の距離 L_A = V1{V2 + √(V2² + 2gR)}/g
  - 問1: A が出発点に落ちるのは cosθ = 1/2 の場合だけであることを示す(離れた点 (R sinθ, R cosθ) から速度 (−Vθcosθ, Vθsinθ) の斜方投射が (0, −R) を通る条件を整理すると 2cos²θ + cosθ − 1 = 0)
  - (3) 問2: V が十分大きいとき、上端から水平に飛び出したときの落下距離 L1 と、逆向きに投げ返して下端から速さ V で飛び出したときの落下距離 L2 の比が √3 に近づく理由(上端での速さ √(V²−4gR) が V に近づき、落下時間の比 √(6R/g) : √(2R/g) = √3 だけが残る)
- その場で与えられた知識: なし(L0)。近似式の提示もない。
- 解法の核心・差がつく点: 面から離れる条件(垂直抗力 0)と、その後の斜方投射を座標で正確に書けるか。問1は cosθ の 3 次式が (cosθ+1) でくくれて 2 次方程式になる。ス は跳ね返り面が床から高さ R にあることに注意して、上向き初速 V2 の投げ上げとして解く。
- 作問メモ: 「定番の部品(弾性衝突・円筒面・放物運動)を1つの見慣れない地形でつなぎ、V の大きさで場合分けして3通りの運動を順に問う」型。最後に運動の逆行(時間反転)と極限での比を理由説明させて締める。その場学習なしで長さと場合分けだけで難度を出す例。

## 大問II(電磁気/はしご型導体上を動く磁石と無限はしご型回路)

- 流れ: 水平に固定した無限に長いはしご型導体の上を、棒磁石が一定の速さ v で動く。磁石の真下だけ一様な磁束密度 B。はしごを、横木 R1・縦の枠 R2 の無限抵抗回路網とみなす。
  - (1) 磁石の端面が1区画に一致。左右の半無限部分をそれぞれ抵抗 R∞ に置き換える。
  - イ: 左右の閉回路に生じる誘導起電力(vBa)
  - ロ: Q から P に流れる電流(2vBa/(2R1 + R∞))
  - ハ: 磁石を動かすのに必要な単位時間あたりの仕事(2(vBa)²/(2R1 + R∞))
  - (2) 問1: R1 : R2 = 4 : 1 のとき半無限回路の合成抵抗 R∞ が R1 に等しいことを示す(R∞ = 2R2 + R1R∞/(R1+R∞) に代入して確かめる、または解く)
  - (3) R∞ = R1 = R、R2 = R/4、起電力を E とおく。
  - ニ: I0 = 2E/(3R)
  - ホ: K→L の電流 i1 は I0 の何倍か(1/4)
  - ヘ: M→N の電流 i2 は I0 の何倍か(1/8)
  - (4) P・Q 間に発光ダイオード(Vd 未満で抵抗無限大、Vd 以上で抵抗 0)を接続。
  - ト: LED に電流が流れ始める速さ v0 = 3Vd/(Ba)
  - チ: v > v0 での I0 = (E − Vd)/R
  - リ: i1 = Vd/(2R)
  - ヌ: LED の電流 = (E − 3Vd)/R
  - (5) 磁石の端面が3区画に一致(LED なし)。(3)の結果を3つ重ね合わせる。
  - ル: I0 = E/(3R)
  - ヲ: i1 = −5E/(12R)(図の矢印の向きを正として負)
  - ワ: i2 = 7E/(24R)
- その場で与えられた知識:
  - [L1] 無限はしご回路の合成抵抗: 「半無限部分が1つの抵抗 R∞ に置き換えられる」「K と L、あるいは M と N で切り離したものと考えることもできる」と着眼点だけ与え、式は自分で立てさせる(問1)。
  - [L1] 重ね合わせ: (5)で「(3)の結果を3つ重ね合わせることで容易に求めることができる」と指示。
  - [L1] 磁石が動いても導体が動いても同じ: 図2(c)つきで明記。横木を起電力 vBa の電池とみなす根拠になる。
  - [L1] LED の理想化特性: 図5(b)の折れ線で規定。
- 解法の核心・差がつく点: R∞ = R1 のとき、各節点で電流が「横木 R」と「先の半無限回路 R」に等分されるので、横木の電流は 1/4、1/8、1/16…と半減する。LED 点灯後は PQ 間電圧が Vd に固定され、左右の半無限回路にはそれぞれ Vd/R が流れる。(5)は磁束の中にある3本の横木(KL、PQ、K'L')がそれぞれ起電力 E をもつとして、向きに注意して足す。
- 作問メモ: 「物理現象(渦電流)を等価回路に落とし、回路の対称性・自己相似性で解く」型。(1) 1個の起電力 → (2) 無限回路の抵抗 → (3) 電流分布 → (4) 非線形素子の追加 → (5) 重ね合わせで拡張、と1つの道具を使い回して段を上げる。R1 : R2 = 4 : 1 という比を選んで R∞ = R1 ときれいにし、以後の計算を軽くしている。

## 大問III(熱/理想気体のサイクルとゴムひもの熱力学)

- 流れ: (1) シリンダー内の理想気体(断面積 S、長さ L)。定積で加熱、等温で膨張の2つの変化を確認し、等温2本・定積2本のサイクルを考える。(2) ゴムのように伸縮するひもについて同じことを行う。
  - (1) あ: p = nRT/(SL)
  - い: 定積変化の ΔU = nCvΔT
  - う: 等温変化の ΔU(0)
  - え: 等温変化で気体がした仕事 ΔW = (nRT/L) × ΔL
  - お: 吸熱する過程をすべて選ぶ(②過程II、③過程III)
  - か: 1サイクルで気体が外部にする仕事の総量(①正)
  - (2) き: ひもの ΔU を ΔQ などで表す(ΔQ + AT(L−L0)ΔL)
  - く: 断熱的にゆっくり伸ばしたときの ΔT = AT(L−L0)ΔL/K
  - 問1: 過程 α(TA で L1→L2)、β(L2 で TA→TB)、γ(TB で L2→L1)、δ(L1 で TB→TA)を F–L 図に描く。α と γ は点 (L0, 0) を通る直線の一部(傾き ATA と ATB)、β と δ は縦線。(L1, F1) → (L2, ATA(L2−L0)) → (L2, F2) → (L1, ATB(L1−L0)) → (L1, F1) の反時計回り。
  - け: 過程 α でひもがする仕事 W1 = −(ATA/2){(L2−L0)² − (L1−L0)²}
  - こ: W3 = (−TB/TA) × W1
  - さ: W2 = W4 = 0
  - し: 1サイクルでひもが外部にする仕事の総量(①正)
  - 問2: 断熱的に L を大きくするとき、気体は外部に正の仕事をするので内部エネルギーが減り温度が下がる。ひもは外部から仕事をされる(ひもがする仕事は負)ので内部エネルギーが増え温度が上がる。
- その場で与えられた知識:
  - [L2] ゴムひもの状態方程式と内部エネルギー: 「ヒモの張力の大きさ F が絶対温度 T に依存し、長さ L(≧L0)のとき F = AT(L−L0) で表せる場合を考える」「内部エネルギー U は絶対温度 T に比例し、L によらない正の係数 K を用いて U = KT と表せるものとする」。き・くで第1法則に代入し、問1で F–L 図の直線の傾きが温度に比例することに使い、け〜しで仕事を面積として計算する。
  - [L2] ひもの仕事の式: 「ヒモが外部にした仕事は ΔW = −FΔL と書ける」。気体の pΔV と符号が逆であることが、き・く・け・こ・し・問2 のすべてに効く。「問1のグラフにおいて対応する面積を求めることでも計算できる」と面積による計算法も示される。
  - [L1] 微小量の扱い: 「Δ を付した物理量は微小量であり、1次の項までを考える」。
- 解法の核心・差がつく点: 第1法則 ΔU = ΔQ − ΔW の形は気体と同じで、ΔW の中身だけを差し替える。F–L 図では反時計回りのサイクルだが、ΔW = −FΔL なので外部への仕事は正(高温 TB で縮むときに大きな正の仕事、低温 TA で伸ばすときに小さな負の仕事)。
- 作問メモ: 「前半で既習の系(理想気体)の手順を空欄で確認し、後半で状態方程式と内部エネルギーの式を与えた未習の系に同じ手順を適用させ、最後に両者の違いを論述させる」型。与える式は2本+仕事の定義だけで、計算は1次式の積分(台形の面積)にとどめている。p–V 図に対応する F–L 図を描かせるのが要。
