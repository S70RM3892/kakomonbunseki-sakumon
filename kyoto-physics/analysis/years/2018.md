## 全体

- 冊子 1〜16 ページ(6・10 ページは白紙)。3題100点。試験時間の記載は冊子にない。3題とも単一構成(III は (A)(B)(C) に分かれるが同じ設定の発展)。
- I 力学(抵抗力を受ける落下と緩和時間)、II 電磁気(偏向電極、直交電磁場中の電子と電流のしゃ断)、III 熱(重力場中の等温気体柱)。
- **新しい物理量・法則を定義して使わせる純粋な L2 はない。III だけ、差分方程式の指数関数解を問題文が与えて使わせる部分を「数学手法の提示」として L2(境界)と判定した。**
- 3題とも「物理法則は教科書範囲、設定と誘導で見慣れない結論へ」という作り。I はデータ読み取りとグラフ選択、II はグラフ作図があり、定性的な判断の比重が高い。
- 最高レベル: I L1 / II L0 / III L2(境界)

## 大問I(力学/抵抗力を受ける落下、終端速度と緩和時間)

- 流れ: (1) 速さに比例する抵抗力 kv。(2) 速さの2乗に比例する抵抗力 cv^2。どちらも v = v_f + v̄ とおいて、終端速度からのずれ v̄ の式 Δv̄/Δt = −v̄/τ に直し、τ を「緩和時間」とよぶ。(3) 水中落下の実験データ(表1、図2)から抵抗則を判定。(4) 2乗則を水のかたまりとの衝突モデルで導く。
  - ア: 終端速度 v_f = mg/k
  - イ: 緩和時間 τ1 = m/k
  - ウ: v_f = g × τ1 の g
  - エ: 初速度 0 と初速度 2v_f の v-t グラフの選択(③。上下対称に同じ速さで終端速度に近づく)
  - オ: 2乗則の終端速度 v_f = √(mg/c)
  - カ: τ2 = m/(2c v_f) = (1/2)√(m/(gc))
  - キ: v_1 = 5.8 m/s、ク: v_2 = 8.2 m/s(表1で1秒ごとの落下距離の差が一定)
  - 問1: v_2/v_1 ≒ 1.41 ≒ √2。比例則なら v_f ∝ m で比は 2、2乗則なら v_f ∝ √m で比は √2 になるので、2乗則
  - ケ: τ2 = v_1/(2g) ≒ 0.3 s
  - コ: 実験1・2の v-t グラフの選択(④。初期の傾きはどちらも g で共通、実験1は約1 s、実験2は約2 s で終端速度に達し、折れ目がない)
  - サ: Δm = ρ × Sv × Δt
  - シ: m Δv/Δt = −ρS × v^2
- その場で与えられた知識:
  - [L1] 緩和時間: ずれ v̄ の式の係数として定義し「速度が終端速度に近づく時間の目安」と説明。解の関数形は与えない。
  - [L1] 終端速度まわりの1次近似: 「|v̄| ≪ v_f として v̄ の1次までで近似」と手順を指示(公式は与えない)。
  - [L1] 2乗に比例する抵抗力と抵抗係数 c: 運動方程式ごと与える。
  - [L1] 微小量の2次を無視: (4) で「Δt、Δv の1次までを残し、2次は無視」。
- 解法の核心・差がつく点: τ2 を c を使わず v_f/(2g) と書き直すと、測定した終端速度だけで数値が出る。グラフ選択は「ずれに比例して減る → 指数関数的」「t = 0 の加速度は g」「τ が大きい方がゆっくり」を組み合わせて消去する。
- 作問メモ: 「教科書の定番(kv の終端速度)→ 同じ手続きを非線形の場合(cv^2)に拡張 → 平衡点まわりの線形化で特徴的な時間を定義 → 実験データでモデルを判定 → 微視的モデルで式の由来を説明」という5段構成。物理法則は増やさず、「つりあいからのずれの式に直す」という見方だけを教える型。質量だけ変えた2実験の終端速度比でべき指数を判定させるのは再利用しやすい。

## 大問II(電磁気/偏向電極、直交電磁場中の電子と電流のしゃ断)

- 流れ: (1) 対向電極(電圧 V、間隔 d、長さ ℓ)に速さ v_0 で入射した電子の軌道と、距離 L 先での到達位置。(2) 対向電極間に電圧 V と紙面奥向きの磁束密度 B をかけ、陰極表面で静止していた電子・陽極表面で静止していた正イオンの運動。(3) 陰極近くのフィラメントから電子を定常的に供給し、B を増やしたときの電流 I の変化を作図。
  - イ: t = ℓ/v_0
  - ロ: y_P = eVℓ^2/(2mdv_0^2)
  - ハ: 速さ √(v_0^2 + (eVℓ/(mdv_0))^2)
  - ニ: y_Q = eVℓ(ℓ + 2L)/(2mdv_0^2)
  - ホ: 加速電圧 V_p で書くと y_Q = Vℓ(ℓ + 2L)/(4dV_p)(質量・電荷によらない)
  - ヘ: 高さ y での速さ √(2eVy/(md))
  - ト: y_U = 2mV/(eB^2 d)
  - チ: 点 U での y 方向の加速度 −eV/(md)(電気力 eV/d 上向き、磁気力 2eV/d 下向き)
  - リ: 正イオンは ①(x 軸の正の向き)に移動
  - ヌ: ①(y_U < d − y_W。到達距離は質量に比例し、M > m)
  - (3) の作図: B < B_c = (1/d)√(2mV/e) で I = I_0、B > B_c で I = 0 の階段状。B_c の値を図に示す
- その場で与えられた知識: なし(L0)。
- 解法の核心・差がつく点: 磁場は仕事をしないので速さは高さだけで決まる。最上点での x 方向の速さ 2V/(Bd) が問題文で与えられているため、運動方程式を解かずにエネルギー保存だけで y_U が出る。(3) は「y_U ≥ d なら全部届く、y_U < d なら1個も届かない」と二分できるかどうか。イオンの移動の向きは電子と同じ(電場と磁場に垂直な方向への移動は電荷の符号によらない)。
- 作問メモ: 「定番の偏向(1)で肩ならし → 直交電磁場中の運動を、解けない部分(最上点の速さ)だけ与えてエネルギー保存で処理 → 粒子を替えて比較 → 多数の粒子の集団としての測定量(電流)のグラフ」という型。サイクロイドの式を出させずに、到達高さという1つの量だけで装置の特性(しゃ断磁場)まで持っていく。最後を作図にして「特徴的な値を示せ」とするのは、(2) を参照できるかの確認になる。

## 大問III(熱/重力場中の等温気体柱、比熱、分子質量の決定)

- 流れ: (A) 半無限の鉛直円筒(断面積 S)に単原子分子理想気体(分子の質量 m、温度 T は一様)。厚さ Δz の層のつりあいと状態方程式 P = nkT から圧力・数密度の高さ分布を導く。(B) 全エネルギーから1粒子あたりの比熱。(C) ピストンとおもり(質量 M)で高さ h に閉じ込め、底面の圧力 P_B から分子の質量を求める。
  - あ: 層の気体の質量 m n_ℓ S Δz
  - い: P_{ℓ+1} − P_ℓ = −m n_ℓ g Δz
  - う: mg/(kT)
  - え: P(z) = P_0 e^{−mgz/(kT)}
  - お: n(z) = (P_0/(kT)) e^{−mgz/(kT)}
  - 問1: 位置エネルギーの総和 Σ mg(ℓΔz) n(z_ℓ) SΔz に α = mgΔz/(kT) とおいて級数公式を使うと、mg(P_0/(kT))S Δz^2/α^2 = (P_0 S/(mg)) kT
  - か: N = P_0 S/(mg)
  - き: (3/2)kT
  - く: kT
  - け: (5/2)kT
  - こ: (5/2)k
  - さ: ①(大きい。重力がない定積の場合は (3/2)k)
  - し: P(h) = Mg/S
  - す: m = (kT/(gh)) log_e(P_B S/(Mg))
  - せ: m ≒ 7×10^-26 kg(log(1.005) ≒ 0.005 を使う)
- その場で与えられた知識:
  - [L2(境界)] 差分方程式の指数関数解: 式(3) P_{ℓ+1} − P_ℓ = −(mg/(kT)) Δz P_ℓ を導かせた直後に、「定数 a と十分に小さい Δz に関する方程式 {f(z+Δz) − f(z)}/Δz = −a f(z) の解は f(z) = f(0)e^{−az} で与えられる。これを用いれば」と解を与える。受験生は式(3)をこの形に読み替えて a = mg/(kT) と対応させ、え・お を書く。以降の問1、(B) の全空欄、(C) の す・せ はすべてこの分布に依存する。
  - [L1] 級数の公式 Σ ℓ e^{−ℓα} = e^α/(e^α − 1)^2 ≒ 1/α^2: 問1で「用いてもよい」として与える。
  - [L1] 近似式 e^{±x} ≒ 1 ± x、log_e(1 ± x) ≒ ±x: (C) の数値計算用に与える。
  - [L1] 1粒子あたりの比熱: かっこ書きで定義。
  - [L1] 数密度と P = nkT: 定義と式を与える。
- 解法の核心・差がつく点: 底面の圧力が気体の全重量を支える(N = P_0 S/(mg))ことと、位置エネルギーの総和が NkT になること。問1は和を公式の形に合わせ、Δz^2/α^2 で Δz が消えることを示す。(C) は「h より上の気体をおもりに置き換える」という問題文の読み替えを、P(h) = P_B e^{−mgh/(kT)} = Mg/S に落とす。
- 作問メモ: 「薄い層のつりあい → 自分自身に比例して減る式 → 解の関数形だけ与える → 分布を使って総量(粒子数、エネルギー)を求める → 比熱という既知の量と比較 → 実験データから微視的な量(分子の質量)を逆算」という型。微積分を使わせず、差分の式と与えた公式(解、級数、近似)だけで大学初年級の結果(等温大気、重力場中の比熱 (5/2)k)に到達させる。数学の道具を3つ与えて物理は既習だけ、という配分が特徴。L2 判定は「範囲外の数学手法をその場で与えて適用させる」点によるもので、L1 と判定する余地がある。
