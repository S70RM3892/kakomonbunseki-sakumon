# 京大物理 過去問分析コードブック

各年度の問題を同じ物差しで記録するための基準。年度別ファイル(`years/YYYY.md`, `data/YYYY.json`)はすべてこの基準で書く。
化学(`kyoto-chemistry/analysis/CODEBOOK.md`)と同じ考え方を、物理向けに調整したもの。

## 分析単位

大問(I〜III)。大問が (1)(2) や (A)(B) など、設定が独立した前後半に分かれる場合は、その各パートを 1 単位(part)とする。
同じ設定を発展させていくだけの場合は分けない(京大物理はこちらが多い)。

## 「高校範囲」の基準

**現行課程(2022年度入学生〜の学習指導要領「物理基礎」「物理」)の検定教科書本文**を基準にする。
出題当時の課程ではなく、いま受験する人の目線で判定する。

- 本文に載っている事項 → 範囲内
- 教科書の「発展」「参考」コラムや、標準的な受験参考書(名問の森・難問題の系統とその解き方・標準問題精講レベル)で定番化している事項 → L1
- それらにも通常載らない事項(大学初年級以降の概念・式・モデル・数学手法) → L2 / L3

## 範囲外度レベル(その場学習の判定)

| レベル | 定義 | 例 |
|---|---|---|
| L0 | 教科書本文の知識だけで閉じている | 斜面上の単振動、コンデンサーの極板間引力、気体の状態変化 |
| L1 | 教科書の発展・受験定番の準範囲外事項。問題文で説明される場合も、されない場合も含む | 微小量の近似 (1+x)^n ≈ 1+nx、ポアソンの式 pV^γ=一定、重心系・換算質量、ケプラー運動の面積速度と力学的エネルギー、慣性力の遠心力ポテンシャル、ベータトロン、気体分子運動論による断熱変化、単振動の微分方程式の読み替え |
| L2 | 高校範囲外の概念・式・モデル・数学手法を、**問題文がその場で定義・説明し、それを使って解かせる** | 「〜を〜とよぶ。これは次式で表される」と未習の物理量(角運動量、慣性モーメント、ポインティングベクトル、エントロピー、群速度、有効ポテンシャル、相対論的エネルギーなど)や未習の式を与えて計算させる/未習の物理モデル(ドルーデ模型の拡張、プラズマ振動、超伝導、量子化条件の新しい適用先)を与える |
| L3 | 高校範囲外の知識を**説明なしに前提**とする(知らないと解けない) | まれ |

判定で迷ったら低い方に倒し、`note` に迷った理由を書く。
L2 の本質は「読解して新しいルール・量・モデルを把握 → 既習の法則と組み合わせて適用」という作業が要求されること。
単に見慣れない装置や現象名が題材になっているだけで、解くのに既習の法則しか使わないものは L0/L1 とする(題材は `novel_context` に記録)。
京大物理は「既習法則だけで、見慣れない設定を長い誘導で解かせる」問題が多いので、**L2 と「設定が新しいだけ」を厳密に区別する**こと。

## その場で与えられる知識(beyond_items)の型

`kind` に次のいずれかを付ける。

- `概念定義` : 新しい用語・物理量を定義する(例: 角運動量、慣性モーメント、エントロピー、電気双極子モーメント)
- `式の提示` : 未習の関係式・法則を与える(例: ストークスの法則、シュテファン・ボルツマン則、相対論的エネルギー、ローレンツ変換)
- `モデルの提示` : 現象を説明する仮定・モデルを与える(例: 自由電子模型、プラズマ、結晶中の電子、連成振動のモード)
- `数学手法の提示` : 近似式・微分方程式の解・積分結果などを与えて使わせる(例: 近似式、減衰振動の解、対数・指数の関係、微小量の扱い)
- `装置・実験の提示` : 未習の装置・測定法の原理を与える(例: サイクロトロン以外の加速器、干渉計の変種、質量分析、トラップ)
- `データ読解` : 未習の量を含む図表を与え読み取らせる

## 難易度

京大受験生(工学部合格ライン付近)目線の 4 段階: `易` / `標準` / `やや難` / `難`。理由を一言添える。

## JSON スキーマ(`data/YYYY.json`)

```json
{
  "year": 2026,
  "phys_pages_in_booklet": "1-18",
  "exam_format": {"num_problems": 3, "time_note": "冊子から読み取れる範囲", "points": 100},
  "parts": [
    {
      "problem": "I",
      "part": "",
      "field": "力学 | 電磁気 | 熱 | 波動 | 原子 のいずれか。複合は主たるものを書き sub_fields に残りを書く",
      "sub_fields": [],
      "topics": ["単振動", "衝突"],
      "theme": "一文で何の問題か",
      "novel_context": ["題材として新しいもの(装置名・現象名)"],
      "lead_text_lines": 60,
      "num_figures_tables": 3,
      "num_questions": 18,
      "answer_types": {"空欄補充(式)": 12, "空欄補充(数値)": 1, "選択": 2, "論述・導出": 2, "図示・グラフ": 1},
      "beyond_items": [
        {
          "concept": "…",
          "kind": "概念定義",
          "level": "L1",
          "how_given": "どう与えられたか(要旨)",
          "used_in": "空欄 ク〜サ、問2",
          "essential": true,
          "booklet_page": 3
        }
      ],
      "max_level": "L1",
      "math_load": "軽 | 中 | 重(文字式の処理量・近似の段数)",
      "difficulty": "標準",
      "difficulty_reason": "…",
      "key_idea": "解法の核心を1〜2文",
      "note": ""
    }
  ],
  "overall_note": "その年度全体の特徴を2〜4文"
}
```

- 京大物理は本文中の空欄(ア、イ、…/あ、い、…)を埋める形式が主体。`lead_text_lines` は**大問全体の本文行数**(空欄を含む文章全体。図・設問の「問1」本文は除く)を数える。
- `num_questions` は採点上の最小単位(空欄 1 個、問 1 つ)の数。
- `answer_types`: `空欄補充(式)` は文字式を書く空欄、`空欄補充(数値)` は数値を書く空欄、`選択` は選択肢から選ぶ空欄(京大では { } で選択肢を示すことが多い)、`論述・導出` は「問1」などで理由説明や導出過程を書かせるもの、`図示・グラフ` はグラフや図を描かせるもの。合計は `num_questions` と一致させる。
- `beyond_items` は L1 以上のみ列挙。なければ空配列で `max_level` は `L0`。
- 近似式(|x|≪1 のとき (1+x)^a ≈ 1+ax など)が問題文で与えられた場合は、`数学手法の提示` L1 として記録する(頻度を数えたいので省略しない)。

## Markdown(`years/YYYY.md`)

人間が読む用。構成は以下。

```
# 京大物理 YYYY年度
## 全体
(冊子ページ、題数、各大問の分野、L2 の有無、最高レベルの一覧)
## 大問I(分野/テーマ)
- 流れ: 設定を1〜3行で述べ、空欄・問ごとに何を求めるかと答(自力で解いた結果)を1行ずつ
- その場で与えられた知識: レベル付きで列挙。L2 以上は問題文の言い回しの要旨と、それをどの空欄・問でどう使うかを具体的に
- 解法の核心・差がつく点
- 作問メモ: この問題の「型」(作問時に再利用できる構造)を1〜3行
## 大問II …
```

問題文の逐語的な長い転記はしない(要旨と構造を書く)。答は自力で解いた結果を書き、自信がないものは「(要検証)」を付ける。
